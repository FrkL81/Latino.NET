## 9.13 Librería `archivo` (File I/O)

La librería `archivo` proporciona funciones para interactuar con el sistema de archivos del sistema operativo, permitiendo lectura, escritura y gestión de directorios.

### 📖 Lectura

| Función | Parámetros | Descripción |
| :--- | :--- | :--- |
| `archivo.existe(ruta)` | `ruta` | Verifica si existe un archivo o directorio en la ruta especificada. |
| `archivo.leer(ruta)` | `ruta` | Lee el contenido completo de un archivo como texto (UTF-8). |
| `archivo.leerJson(ruta)` | `ruta` | Lee un archivo JSON y lo convierte automáticamente en un `diccionario` o `lista`. |
| `archivo.lineas(ruta)` | `ruta` | Lee un archivo y retorna una lista de sus líneas. |

🎯 **Ejemplo: Creación, lectura estructurada y limpieza de archivos**

```latino
# 1. Preparación de archivos de prueba (Autosuficiencia)
archivo.escribir("datos.txt", "Línea 1: Alfa\nLínea 2: Beta")
archivo.escribirJson("config.json", {"version": "1.0.81"})

# leer - Contenido completo
contenido = archivo.leer("datos.txt")
escribir(contenido)

# lineas - Como lista
lineas = archivo.lineas("datos.txt")
para linea en lineas
    escribir("→ " .. linea)
fin

# leerJson - Deserialización automática
config = archivo.leerJson("config.json")
escribir("Versión: " .. config.version)

# existe - Verificación de presencia
si archivo.existe("config.json")
    escribir("✅ Config encontrado")
fin

# Higiene de recursos: borrado de archivos temporales
archivo.borrar("datos.txt")
archivo.borrar("config.json")
```

### ✍️ Escritura

| Función | Parámetros | Descripción |
| :--- | :--- | :--- |
| `archivo.anexar(ruta, texto)` | `ruta, contenido` | Añade texto al final de un archivo existente (útil para logs). |
| `archivo.crear(ruta)` | `ruta` | Crea un archivo vacío. Lanza error si ya existe. |
| `archivo.escribir(ruta, texto)` | `ruta, contenido` | Crea o sobrescribe un archivo con el texto proporcionado. |
| `archivo.escribirJson(ruta, datos, [pretty])` | `ruta, datos, pretty` | Escribe un objeto Latino como JSON. `pretty` (lógico) activa indentación. |

🎯 **Ejemplos: Pruebas de Humo (Escritura)**

```latino
# escribir - Crear o sobrescribir
archivo.escribir("saludo.txt", "Hola Mundo")

# anexar - Añadir al final
archivo.anexar("log.txt", "Evento 1\n")

# escribirJson - Serialización
datos = { "id": 1, "nombre": "Test" }
archivo.escribirJson("data.json", datos, verdadero) # JSON indentado

# Limpieza de archivos temporales
archivo.borrar("saludo.txt")
archivo.borrar("log.txt")
archivo.borrar("data.json")
```

> ℹ️ **Solo acepta un diccionario o una lista en la raíz:** escribir un número, una cadena, un booleano o `nulo` directamente falla con `archivo.escribirJson() requiere un diccionario o lista.` Envuélvelos: `{"x": 42}` sí se serializa.  
>
> **Anidados, la Tolerancia es mayor:** una tupla, un conjunto, una pila o una cola **dentro** de un diccionario o lista sí se escriben —la tupla como arreglo y el conjunto como objeto—, y una función anónima se serializa como `<fn anonima>`. Solo se rechazan cuando son el valor de la raíz. Verificado ejecutando en v1.0.81.

### 📊 Formato CSV (Datos Estructurados)

Latino.NET permite trabajar con archivos CSV de forma nativa, convirtiéndolos en listas de diccionarios para facilitar su procesamiento de datos.

| Función | Parámetros | Descripción |
| :--- | :--- | :--- |
| `archivo.escribirCsv(r, l, [s])` | `ruta, lista, [sep]` | Escribe una lista de diccionarios en formato CSV. |
| `archivo.leerCsv(r, [s])` | `ruta, [sep]` | Lee un CSV y retorna una lista de diccionarios. |

🎯 **Ejemplo: Procesar Datos CSV**

```latino
# Crear archivo CSV de ejemplo
archivo.escribir("ventas.csv", "producto;precio;cantidad\nManzana;1.50;100\nPera;2.00;75")

# Leer CSV (cada fila será un diccionario)
ventas = archivo.leerCsv("ventas.csv", ";")
para venta en ventas
    escribirf("Producto: {0} | Total: {1}\n", venta.producto, venta.precio * venta.cantidad)
fin

# Guardar lista de diccionarios a CSV
datos = [
    { "id": 1, "usuario": "Edison" },
    { "id": 2, "usuario": "Franklin" }
]
archivo.escribirCsv("usuarios.csv", datos)

# Limpieza de archivos temporales
archivo.borrar("ventas.csv")
archivo.borrar("usuarios.csv")
```

### 🗂️ Gestión de Archivos

| Función | Parámetros | Descripción |
| :--- | :--- | :--- |
| `archivo.borrar(ruta)` | `ruta` | Elimina un archivo o directorio de forma permanente. |
| `archivo.duplicar(orig, dest)` | `origen, destino` | Copia un archivo a una nueva ubicación. |
| `archivo.renombrar(orig, dest)` | `origen, destino` | Mueve o renombra un archivo o directorio. |

### 📂 Directorios

| Función | Parámetros | Descripción |
| :--- | :--- | :--- |
| `archivo.buscar(dir, patron)` | `dir, patrón` | Busca archivos recursivamente usando glob (ej: `*.lat`). |
| `archivo.crearCarpeta(ruta)` | `ruta` | Crea un directorio, incluyendo carpetas padres si no existen. |
| `archivo.esArchivo(ruta)` | `ruta` | Retorna `verdadero` si la ruta apunta a un archivo regular. |
| `archivo.esCarpeta(ruta)` | `ruta` | Retorna `verdadero` si la ruta apunta a un directorio. |
| `archivo.listar(ruta)` | `ruta` | Retorna una lista con los nombres de archivos y carpetas en la ruta. |

### 🔍 Información de Archivos

| Función | Parámetros | Descripción |
| :--- | :--- | :--- |
| `archivo.extension(ruta)` | `ruta` | Obtiene la extensión del archivo (incluyendo el punto). |
| `archivo.fechaModificacion(ruta)` | `ruta` | Obtiene la fecha de la última modificación (como cadena). |
| `archivo.nombre(ruta)` | `ruta` | Obtiene el nombre del archivo con su extensión. |
| `archivo.rutaAbsoluta(ruta)` | `ruta` | Convierte una ruta relativa en una ruta absoluta completa. |
| `archivo.tamaño(ruta)` | `ruta` | Obtiene el tamaño del archivo en bytes. |

### 🚀 Ejecución de Scripts

| Función | Parámetros | Descripción |
| :--- | :--- | :--- |
| `archivo.ejecutar(ruta)` | `ruta` | Ejecuta un script `.lat` en un entorno aislado (sandbox). |

> **⚠️ Seguridad:** `archivo.ejecutar()` no comparte variables con el script llamador. Es ideal para cargar configuraciones o plugins de terceros de forma segura.

### 🔧 Manejo de Errores

Es vital usar bloques `intentar/atrapar` para operaciones de archivo, ya que pueden fallar por permisos denegados, falta de espacio o archivos bloqueados.

```latino
    intentar
        archivo.borrar("./sistema_protegido/archivo_bloqueado.sys")
    atrapar (err)
        escribir("Error capturado: " .. err)
    fin
```
