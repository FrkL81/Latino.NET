## 9.22 Plugin env (Variables de Entorno)

El plugin `env` permite leer, manipular y cargar variables de entorno (`Environment Variables`). Es esencial para evitar guardar contraseñas, URLs y tokens de APIs (hardcoding) directamente en los scripts.

Adicionalmente, incorpora un **Parser Inteligente de archivos `.env`**, el estándar de la industria para configuración de aplicaciones.

> **Requiere carga explícita:** `incluir("env")`

### 🌍 Manejo del Entorno del Proceso

| Función | Parámetros | Descripción |
| :--- | :--- | :--- |
| `env.escribir(nombre, valor)` | `var, valor` | Define una variable para el proceso actual. Si `valor` es `nulo`, se elimina la variable. |
| `env.existe(nombre)` | `var` | Retorna `verdadero` si la variable existe. |
| `env.leer(nombre, [defecto])` | `var, [def]` | Lee el valor de una variable. Retorna el valor `defecto` (o `nulo`) si no existe. |
| `env.todas()` | - | Retorna un `diccionario` con todas las variables del proceso. |

### 📁 Manejo de Archivos `.env`

| Función | Parámetros | Descripción |
| :--- | :--- | :--- |
| `env.leerArchivo(ruta, [prefijo])` | `ruta, [pref]` | Parsea un archivo `.env` y lo inyecta al entorno. Retorna un diccionario con lo cargado. |

#### El Parser `.env` de Latino.NET soporta

* Líneas en blanco y comentarios de línea (`#`).
* Comentarios en línea (`PUERTO=8080 # Comentario`).
* Valores encerrados en comillas simples y dobles.
* URLs y valores que contienen signos de igual adicionales.
* Formatos compatibles con shell de Linux (`export VAR=valor`).

🎯 **Ejemplo: Configuración Profesional**

```latino
incluir("env")

# Preparación autosuficiente: el ejemplo crea su propio archivo .env
# (si lo copias, no necesitas tener ningún archivo previo en disco)
contenido = "# Entorno de base de datos\n" ..
            "DB_HOST=127.0.0.1\n" ..
            "DB_USUARIO=admin\n" ..
            "DB_PASSWORD=clave_super_secreta # No subir a repositorios\n"
archivo.escribir("config.env", contenido)

# Cargar el archivo .env al entorno
env.leerArchivo("config.env")

# Usar las variables
host = env.leer("DB_HOST", "localhost") # Default a localhost
user = env.leer("DB_USUARIO")
pass = env.leer("DB_PASSWORD")

escribirf("Conectando a {0} como {1}...\n", host, user)
escribirf("Contrasena leida: {0}\n", pass)

# Higiene: limpiar la variable sensible y borrar el archivo temporal
env.escribir("DB_PASSWORD", nulo)
archivo.borrar("config.env")
```

```text
Conectando a 127.0.0.1 como admin...
Contrasena leida: clave_super_secreta
```

>💡 Nota: Las variables establecidas con env.escribir o env.leerArchivo solo viven en la memoria del programa actual (Proceso). No alteran permanentemente el sistema operativo.

🎯 **Ejemplo: Pruebas de humo rápidas de `env`**

```latino
incluir("env")

# El archivo se crea y se borra dentro del propio bloque
archivo.escribir("humo.env", "MI_VAR=valor")

env.escribir("OTRA_VAR", "otro")
env.leer("OTRA_VAR")
env.existe("OTRA_VAR")
env.leerArchivo("humo.env")
env.leer("MI_VAR")

archivo.borrar("humo.env")
env.escribir("OTRA_VAR", nulo)  # Eliminar del proceso
```
