## 9.7 Librería `pila` (Stack)

La librería `pila` implementa la estructura de datos **LIFO** (Last-In-First-Out), donde el último elemento en entrar es el primero en salir. Es fundamental para algoritmos de recursión, deshacer borradores e historiales.

### 📤 Operaciones Básicas

| Función | Parámetros | Descripción |
| :--- | :--- | :--- |
| `pila.alista(p)` | `pila` | Convierte la pila en una `lista` (Fondo → Cima). |
| `pila.apilar(p, item)` | `pila, valor` | Agrega un elemento al tope de la pila (Push). |
| `pila.cima(p)` | `pila` | Retorna el elemento del tope sin extraerlo (Peek). |
| `pila.crear()` | - | Crea una pila nueva y vacía. |
| `pila.desapilar(p)` | `pila` | Extrae y retorna el elemento del tope (Pop). |
| `pila.limpiar(p)` | `pila` | Vacía la pila por completo. |
| `pila.longitud(p)` | `pila` | Retorna el número de elementos en la pila. |
| `pila.vacia(p)` | `pila` | Retorna `verdadero` si la pila no tiene elementos. |

🎯 **Ejemplos: Pruebas de Humo (Operaciones Básicas)**

```latino
historial = pila.crear()

# Apilar páginas
pila.apilar(historial, "google.com")
pila.apilar(historial, "github.com")
pila.apilar(historial, "latino-lang.org")

escribir("Viendo actualmente: " .. pila.cima(historial)) # → latino-lang.org

# Retroceder (desapilar)
pila.desapilar(historial)
escribir("Volviste a: " .. pila.cima(historial)) # → github.com
```

🎯 **Ejemplo: Validador de Paréntesis**

```latino
funcion ValidarBalance(texto)
    p = pila.crear()
    chars = rango(texto)
    
    para c en chars
        si c == "("
            pila.apilar(p, "(")
        osi c == ")"
            si pila.vacia(p) retornar falso fin
            pila.desapilar(p)
        fin
    fin
    
    retornar pila.vacia(p)
fin

escribir(ValidarBalance("(())")) # → cierto
escribir(ValidarBalance("(()"))  # → falso
```

🎯 **Ejemplo: Sistema de "Deshacer" (Undo) en un editor**

```latino
acciones = pila.crear()

funcion RegistrarAccion(historial, accion)
    pila.apilar(historial, accion)
    escribir("✔ Acción realizada: " .. accion)
fin

funcion Deshacer(historial)
    si pila.vacia(historial)
        escribir("⚠ Nada que deshacer.")
        retornar
    fin
    ultima = pila.desapilar(historial)
    escribir("↩ Deshaciendo: " .. ultima)
fin

# Simulación de trabajo
RegistrarAccion(acciones, "Escribir título")
RegistrarAccion(acciones, "Insertar imagen")
RegistrarAccion(acciones, "Cambiar tipografía")

Deshacer(acciones) # Deshace: Cambiar tipografía
Deshacer(acciones) # Deshace: Insertar imagen
```

🎯 **Ejemplo: Conversión de Decimal a Binario por divisiones sucesivas**

```latino
funcion DecimalABinario(numero)
    si numero == 0 retornar "0" fin
    
    restos = pila.crear()
    n = numero
    
    # Apilamos los residuos de dividir entre 2
    mientras n > 0
        pila.apilar(restos, n % 2)
        n = mate.piso(n / 2)
    fin
    
    # Al desapilar, obtenemos el binario en orden correcto
    binario = ""
    mientras no pila.vacia(restos)
        binario ..= acadena(pila.desapilar(restos))
    fin
    
    retornar binario
fin

escribir("42 en binario:  " .. DecimalABinario(42))  # 101010
escribir("255 en binario: " .. DecimalABinario(255)) # 11111111
```

> **💡 Diferencia con Cola:** Mientras que una `pila` es LIFO (el último en llegar se atiende primero), una `cola` es FIFO (el primero en llegar se atiende primero).
