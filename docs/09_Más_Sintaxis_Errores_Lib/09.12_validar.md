## 9.12 Librería `validar` (Validation)

La librería `validar` ofrece un conjunto de herramientas para verificar formatos de texto comunes (Email, URL, IP, etc.) y tipos de datos, utilizando expresiones regulares optimizadas.

### 📧 Validaciones de Formato

| Función | Parámetros | Descripción |
| :--- | :--- | :--- |
| `validar.email(texto)` | `cadena` | Verifica si el texto tiene un formato de correo válido. |
| `validar.ipv4(texto)` | `cadena` | Verifica si el texto es una dirección IPv4 válida. |
| `validar.telefono(texto)` | `cadena` | Valida formatos telefónicos internacionales. |
| `validar.url(texto)` | `cadena` | Verifica si el texto es una URL válida (http/https). |

### 🔢 Validaciones de Tipo y Contenido

| Función | Parámetros | Descripción |
| :--- | :--- | :--- |
| `validar.alfanumerico(t)` | `cadena` | Verifica si solo contiene letras y números. |
| `validar.entero(texto)` | `cadena` | Verifica si el texto representa un número entero. |
| `validar.esPalindromo(v)` | `valor` | Verifica si el texto/número se lee igual al revés. |
| `validar.longitud(t,m,M)` | `t, min, max` | Verifica si la longitud está en el rango [m, M]. |
| `validar.numero(texto)` | `cadena` | Verifica si el texto representa cualquier número. |

*El siguiente ejemplo muestra cómo se combinan las funciones de ambas tablas (formato + tipo y longitud) en un flujo real de validación de datos antes de procesar una petición.*

🎯 **Ejemplo: Validación de Formulario de Registro**

```latino
peticion = {
    "usuario":   "devlatino",
    "correo":    "soporte@latino.org",
    "sitio_web": "https://latino-lang.org",
    "ip_origen": "192.168.1.100",
    "edad":      "25"
}

# Validación combinada de tipo, longitud y formato
usuario_valido = validar.alfanumerico(peticion.usuario) ý validar.longitud(peticion.usuario, 4, 15)

escribir("¿Usuario alfanumérico (4 a 15 caracteres)?: " .. usuario_valido)   # → cierto
escribir("¿Correo electrónico válido?: " .. validar.email(peticion.correo))   # → cierto
escribir("¿Sitio web HTTPS válido?: " .. validar.url(peticion.sitio_web))   # → cierto
escribir("¿Dirección IPv4 válida?: " .. validar.ipv4(peticion.ip_origen))   # → cierto
escribir("¿Edad numérica entera?: " .. validar.entero(peticion.edad))   # → cierto
```

### 🇵🇦 Validaciones Regionales (Panamá)

La librería `validar` incluye funciones especializadas para el ecosistema panameño, cumpliendo con los estándares estructurales del Registro Civil y la DGI.

| Función | Parámetros | Descripción | Retorna |
| :--- | :--- | :--- | :--- |
| `validar.analizarCedula(t)` | `cadena` | Desglosa una cédula en sus componentes (provincia, tomo, asiento) y determina su tipo. | `diccionario` |
| `validar.cedula(texto)` | `cadena` | Valida formato estructural de cédula (personal, extranjero PE, naturalizado E/N). Acepta con o sin guiones. | `logico` |
| `validar.ruc(texto)` | `cadena` | Valida formato básico de RUC (9 a 15 caracteres alfanuméricos). | `logico` |

#### 🔎 Análisis de Cédula Panameña

La función `validar.analizarCedula` permite no solo validar, sino también catalogar la procedencia de la identificación.

**Retorno de `validar.analizarCedula`:**

| Clave | Tipo | Descripción |
| :--- | :--- | :--- |
| `asiento` | `cadena` | El número de asiento (máximo 6 dígitos). |
| `normalizada` | `cadena` | La cédula reconstruida en formato estandarizado `PROV-TOMO-ASIENTO`. |
| `provincia` | `cadena` | El número de provincia (1-13) o el prefijo especial (PE, E, N). |
| `tipo` | `cadena` | Descripción textual: "Panameño", "Panameño nacido en el extranjero" (PE), "Extranjero naturalizado" (E), etc. |
| `tomo` | `cadena` | El número de tomo (máximo 4 dígitos). |
| `valida` | `logico` | Indica si la estructura es válida según las reglas del Registro Civil (3 partes con guiones o 7-12 dígitos). |

🎯 **Ejemplo: Análisis y Desglose de Cédula Panameña**

```latino
info = validar.analizarCedula("PE-12-3456")

si info["valida"]
    escribir("Tipo de registro: " .. info["tipo"])        # → Panameño nacido en el extranjero
    escribir("Provincia / Pref: " .. info["provincia"])   # → PE
    escribir("Tomo registral:   " .. info["tomo"])        # → 12
    escribir("Asiento:          " .. info["asiento"])     # → 3456
    escribir("Cédula oficial:   " .. info["normalizada"]) # → PE-12-3456
sino
    escribir("❌ La cédula no cumple el formato legal.")
fin
```

### 🛡️ Seguridad y Contraseñas

| Función | Parámetros | Descripción |
| :--- | :--- | :--- |
| `validar.contrasenaSegura(t)` | `cadena` | Verifica si cumple: 8+ carac, may, min, núm y símbolo. |

🎯 **Ejemplo: Validación interactiva de credenciales de usuario**

```latino
email = leer("Introduce tu email: ")     # Entrada simulada: usuario@empresa.com

si validar.email(email)
    escribir("✅ Email correcto")
sino
    escribir("❌ Formato de email inválido")
fin

pass = leer("Crea una contraseña: ")   # Entrada simulada: Clave#2026Segura
si !validar.contrasenaSegura(pass)
    escribir("⚠ La contraseña es muy débil")
fin
```

🎯 **Ejemplo: Validación Defensiva de Conexión de Red**

```latino
host_ip     = "192.168.1.1"
puerto_texto = "8080"
api_url     = "https://api.servidor.local"

# Comprobación de integridad antes de iniciar el socket
si validar.ipv4(host_ip) ý validar.entero(puerto_texto)
    puerto = anumero(puerto_texto)
    escribirf("Conexión autorizada hacia {0}:{1}\n", host_ip, puerto)
sino
    escribir("❌ Host o puerto con formato inválido.")
fin

escribir("¿Endpoint seguro disponible? " .. validar.url(api_url))
```
