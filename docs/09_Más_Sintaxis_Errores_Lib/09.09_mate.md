## 9.9 Librería `mate` (Matemáticas)

Funciones aritméticas, trigonométricas, constantes y cálculos financieros.

### 📏 Constantes

| Constante | Valor Aproximado | Descripción |
| :--- | :--- | :--- |
| `mate.e` | 2.71828182... | Base de los logaritmos naturales. |
| `mate.epsilonMaquina()` | ~2.22e-16 | El número más pequeño tal que `1 + eps > 1`. |
| `mate.pi` | 3.14159265... | Relación circunferencia/diámetro. |
| `mate.tau` | 6.28318530... | 2 × PI (Una vuelta completa). |

`mate.pi`, `mate.e` y `mate.tau` son **constantes numéricas de solo lectura**, no funciones: se usan sin paréntesis. `mate.epsilonMaquina()` es la única que se invoca como función.

### 📐 Trigonometría

Todas las funciones trigonométricas utilizan **radianes**.

| Función | Descripción | Función | Descripción |
| :--- | :--- | :--- | :--- |
| `mate.cos(x)` | Coseno | `mate.acos(x)` / `mate.arco(x)` | Arcocoseno |
| `mate.sen(x)` | Seno | `mate.asen(x)` / `mate.asin(x)` | Arcoseno |
| `mate.tan(x)` | Tangente | `mate.atan(x)` | Arcotangente |
| `mate.atan2(y, x)` | Arcotangente de 2 argumentos. | | |

### 🌐 Funciones Hiperbólicas

Funciones hiperbólicas directas e inversas. Su argumento es un número real, no un ángulo: no opera en radianes como las trigonométricas.

| Función | Descripción | Función | Descripción |
| :--- | :--- | :--- | :--- |
| `mate.senh(x)` | Seno hiperbólico | `mate.asenh(x)` | Arcoseno hiperbólico |
| `mate.cosh(x)` | Coseno hiperbólico | `mate.acosh(x)` | Arcocoseno hiperbólico |
| `mate.tanh(x)` | Tangente hiperbólica | `mate.atanh(x)` | Arcotangente hiperbólica |

```latino
# Identidad hiperbólica fundamental: cosh²(x) - senh²(x) = 1
x = 1.5
identidad = mate.cosh(x) ^ 2 - mate.senh(x) ^ 2
escribir(identidad)   # → 1.0000000000000009 (1 en aritmética exacta)

# Las funciones inversas deshacen a las directas
escribir(mate.asenh(mate.senh(x)))   # → 1.5
```

### ⚙️ Manipulación de Punto Flotante

Descomposición y reconstrucción de números en mantisa y exponente base 2, heredadas de la librería estándar de C:

| Función | Parámetros | Descripción |
| :--- | :--- | :--- |
| `mate.frexp(x)` | `num` | Descompone un número en `[mantisa, exponente]` tal que `x = mantisa × 2^exponente`. |
| `mate.ldexp(x, exp)` | `num, exp` | Calcula `x × 2^exp`. Es la inversa de `frexp`. |

```latino
# Descomponer y reconstruir un número
numero = 12
par = mate.frexp(numero)
escribir(par[0])   # → 0.75  (mantisa: índice 0)
escribir(par[1])   # → 4     (exponente: índice 1)

# ldexp deshace la descomposición
escribir(mate.ldexp(par[0], par[1]))   # → 12
```

### 🔢 Teoría de Números

| Función | Parámetros | Descripción |
| :--- | :--- | :--- |
| `mate.esPrimo(n)` | `num` | Retorna `verdadero` si el número es primo. |
| `mate.factorial(n)` | `num` | Calcula el factorial de un número (n!). |
| `mate.mcd(a, b, ...)` | `nums \| list` | Calcula el Máximo Común Divisor. |
| `mate.mcm(a, b, ...)` | `nums \| list` | Calcula el Mínimo Común Múltiplo. |

```latino
# 1. Primalidad y factorial
escribir(mate.esPrimo(97))          # cierto
escribir(mate.factorial(5))         # 120

# 2. Máximo Común Divisor y Mínimo Común Múltiplo
# Aceptan argumentos sueltos o una lista completa:
escribir(mate.mcd(48, 64, 96))      # 16
escribir(mate.mcm([12, 18, 24]))    # 72
```

> ⚠️ **Límites defensivos y algoritmos:**
>
> - **`mate.esPrimo(n)`:** Aplica un algoritmo determinista optimizado ($6k \pm 1$). Tiene un **límite superior de seguridad de $10^{12}$ (1 billón)** y exige un número entero; valores superiores o decimales lanzan `RuntimeError` para evitar congelamientos de CPU. Los números menores a 2 (negativos, 0 y 1) devuelven `falso` sin error. No está diseñada para cribas criptográficas masivas por fuerza bruta.
>  
> - **`mate.factorial(n)`:** Admite enteros entre 0 y 170 inclusive ($0! = 1$). Valores a partir de 171 lanzan `RuntimeError` defensivo, ya que $171!$ excede el límite de representación de punto flotante de 64 bits en .NET (`Infinity`).

### 📏 Conversión de Unidades

La función `mate.convertir` permite realizar transformaciones precisas entre diversos sistemas de medida, incluyendo unidades científicas e históricas.

| Función | Parámetros | Descripción |
| :--- | :--- | :--- |
| `mate.convertir(v, d, h)` | `val, desde, hacia` | Convierte entre más de 60 unidades en 10 categorías. |

#### 🗂️ Categorías y Unidades Soportadas

| Categoría | Unidades Principales |
| :--- | :--- |
| **Astronómica** | `ua` (unidad astronómica), `anio_luz` |
| **Digital** | `bit`, `byte`, `kb`, `mb`, `gb`, `tb` |
| **Energía** | `joule`, `caloria`, `kcal`, `btu`, `ev` |
| **Histórica** | `vara`, `legua`, `codo`, `palmo`, `fanega` |
| **Longitud** | `m`, `km`, `cm`, `mm`, `pulgadas`, `pies`, `yardas`, `millas` |
| **Masa/Peso** | `kg`, `g`, `mg`, `libras`, `onzas`, `tonelada`, `arroba`, `quintal` |
| **Presión** | `pascal`, `psi`, `bar`, `atm`, `torr` |
| **Temperatura** | `celsius`, `fahrenheit`, `kelvin` |
| **Velocidad** | `kmh`, `mph`, `nudo`, `mach`, `ms` |
| **Volumen** | `litro`, `ml`, `galon`, `pinta`, `barril`, `taza` |
| **Área** | `m2`, `km2`, `hectarea`, `acre`, `fanega` |

```latino
# Física y Cocina
tazas = mate.convertir(1, "litro", "taza")
escribir(tazas)     # → 4.166666666666667
energia = mate.convertir(100, "caloria", "joule")
escribir(energia)   # → 418.40000000000003

# Historia y Geografía
distancia = mate.convertir(10, "legua", "km")
escribir(distancia) # → 55.727
terreno = mate.convertir(2, "hectarea", "fanega")
escribir(terreno)   # → 3.096166945321692

# Informática
tamArchivo = mate.convertir(1, "gb", "mb")
escribir(tamArchivo) # → 1024
```

> **💡 Tip:** Usa el autocompletado inteligente escribiendo `@unidad:` dentro de una cadena para ver la lista completa en tu editor.

### 💰 Cálculos de Porcentaje y Finanzas

| Función | Descripción |
| :--- | :--- |
| `mate.base(parte, p%)` | El total original sabiendo que una parte es el P%. |
| `mate.compuesto(p, r, n)` | Interés compuesto (Capital Final). |
| `mate.parte(t, p)` | El valor que corresponde al P% de un total. |
| `mate.porc(p, t)` / `mate.porcentaje(p, t)` | Proporción decimal que representa una parte sobre un total (ej: 25, 100 → 0.25). |

```latino
# Pitágoras
res = mate.pitagorica(3, 4, "h")

precio = 100
final = precio - mate.parte(precio, 15)
escribir(final) # → 85
```

### 📐 Álgebra y Ecuaciones

| Función | Parámetros | Descripción |
| :--- | :--- | :--- |
| `mate.resolverPolinomio(...)` | `coefs...` | Resuelve polinomios de grado 1 a 4 usando fórmulas exactas. |
| `mate.resolverPol(...)` | `coefs...` | Alias corto de `resolverPolinomio`. |

#### 🛠️ Uso de `mate.resolverPolinomio`

Esta función acepta una lista variable de coeficientes, ordenados de **mayor a menor grado** (nota: en `interpolacion.evaluarPolinomio` el orden es **ascendente**: c₀ + c₁x + c₂x² + ...). Retorna un diccionario con el grado detectado, los coeficientes normalizados, una descripción del tipo de raíces y los valores de las raíces (`x1`, `x2`, etc.).

```latino
# Resolver x² - 5x + 6 = 0
res = mate.resolverPolinomio(1, -5, 6)
escribir(res)
# → {grado: 2, coeficientes: [1, -5, 6], descripcion: Raíces reales distintas (discriminante > 0), x1: 2, x2: 3}

# Resolver x³ - 1 = 0
res = mate.resolverPol(1, 0, 0, -1)
escribir("x1: " .. res.x1) # → x1: 1
escribir("Descripción: " .. res.descripcion)
```

> **💡 Nota:** `mate.parsearNumero` es inteligente y detecta automáticamente separadores decimales (punto o coma) basándose en el contexto del string.
