## 9.21 Plugin cripto (Seguridad y Cifrado)

El plugin `cripto` dota a Latino.NET de cifrado simétrico de nivel militar (AES-256-GCM) y firmas HMAC-SHA256 para proteger información sensible y garantizar su integridad.

El diseño sigue el principio de **caja negra segura por defecto**: los vectores de inicialización (IV), los *salts* y los *tags* de autenticación se generan automáticamente y se empaquetan en el resultado Base64.

> **Requiere carga explícita:** `incluir("cripto")`

### 🔐 Cifrado AES-256-GCM

| Función | Parámetros | Descripción |
| :--- | :--- | :--- |
| `cripto.claveAleatoria()` | - | Genera una clave segura de 256 bits (en Base64) para uso en cifrado. |
| `cripto.desencriptar(cifrado, clv)` | `b64, pwd` | Descifra el bloque. Lanza error si la clave es errónea o el mensaje fue alterado. |
| `cripto.encriptar(texto, clave)` | `txt, pwd` | Cifra el texto y retorna un bloque Base64 seguro y autenticado. |

### ✍️ Autenticación de Mensajes (HMAC)

| Función | Parámetros | Descripción |
| :--- | :--- | :--- |
| `cripto.firmar(texto, clave)` | `txt, clv` | Genera una firma HMAC-SHA256 del texto en Base64. |
| `cripto.verificar(txt, firma, clv)` | `txt, b64, clv` | Verifica que el texto no haya sido alterado (comparación constante contra ataques de timing). |

🎯 **Ejemplo: Guardar datos sensibles**

```latino
incluir("cripto")

llave_maestra = "SuperSecreto2026!"
datos_privados = "Número de Tarjeta: 4111-XXXX-XXXX-1111"

# Encriptar (cada llamada genera un cifrado distinto por seguridad)
paquete_seguro = cripto.encriptar(datos_privados, llave_maestra)
archivo.escribir("boveda.dat", paquete_seguro)

# Desencriptar y limpiar archivo residual
intentar
    boveda = archivo.leer("boveda.dat")
    datos_recuperados = cripto.desencriptar(boveda, llave_maestra)
    escribir("Datos desencriptados con éxito.")
atrapar (e)
    escribir("🚨 Intrusión detectada: Clave incorrecta o archivo corrupto.")
fin

archivo.borrar("boveda.dat")
```

🎯 **Ejemplo: Pruebas de Humo Rápidas**

```latino
incluir("cripto")

clave = cripto.claveAleatoria()
cifrado = cripto.encriptar("Texto secreto", "mi_clave")
descifrado = cripto.desencriptar(cifrado, "mi_clave")
firma = cripto.firmar("mensaje", "clave_firma")
cripto.verificar("mensaje", firma, "clave_firma")
```
