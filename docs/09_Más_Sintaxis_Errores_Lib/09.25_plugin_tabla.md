## 9.25 Plugin de Tabla Periódica `tabla`

### Instalación y activación

El plugin se carga automáticamente cuando el ensamblado `tabla.dll` está presente en el directorio de plugins de Latino.NET. No requiere configuración adicional.

Para verificar que está disponible, escribe en cualquier script:

```latino
incluir("tabla")

escribir(tabla.datos("H")["nombre"])   # → Hidrógeno
```

Si el intérprete lanza `función no encontrada: tabla.datos`, confirma que `tabla.dll` se encuentra en la carpeta `plugins/` del proyecto.

### Referencia de funciones

#### `tabla.datos`

Devuelve todos los datos registrados de un elemento, buscando por nombre o por símbolo. La búsqueda no distingue mayúsculas de minúsculas.

📌 **Sintaxis:**

```latino
tabla.datos(elemento)
```

| Parámetro | Tipo | Descripción |
| :--- | :--- | :--- |
| `elemento` | cadena | Nombre completo (`"Oro"`) o símbolo (`"Au"`) |

**Retorna** — diccionario con los siguientes campos:

| Campo | Tipo | Ejemplo |
| :--- | :--- | :--- |
| `numero` | número | `79` |
| `simbolo` | cadena | `"Au"` |
| `nombre` | cadena | `"Oro"` |
| `masa` | número | `196.97` |
| `categoria` | cadena | `"Metal de transición"` |
| `configuracion` | cadena | `"[Xe] 4f14 5d10 6s1"` |

🎯 **Ejemplo: Consulta de propiedades atómicas de elementos**

```latino
incluir("tabla")

# Buscar por símbolo
au = tabla.datos("Au")
escribir(au["nombre"])        # → Oro
escribir(au["masa"])          # → 196.97
escribir(au["categoria"])     # → Metal de transición

# Buscar por nombre completo
h = tabla.datos("Hidrógeno")
escribir(h["numero"])         # → 1
escribir(h["configuracion"])  # → 1s1

# Búsqueda insensible a mayúsculas
fe = tabla.datos("hierro")
escribir(fe["simbolo"])       # → Fe
```

#### `tabla.masaMolar`

Calcula la masa molar de una fórmula química sumando las masas atómicas de todos sus átomos.

📌 **Sintaxis:**

```latino
tabla.masaMolar(formula)
```

| Parámetro | Tipo | Descripción |
| :--- | :--- | :--- |
| `formula` | cadena | Fórmula química estándar, ej. `"H2O"` o `"C6H12O6"` |

**Retorna** — diccionario:

| Campo | Tipo | Ejemplo |
| :--- | :--- | :--- |
| `formula` | cadena | `"H2O"` |
| `masa_molar_g_mol` | número | `18.015` |

🎯 **Ejemplos: Cálculo de la masa molar de un compuesto**

```latino
incluir("tabla")

agua = tabla.masaMolar("H2O")
escribir(agua["masa_molar_g_mol"])    # → 18.015

co2 = tabla.masaMolar("CO2")
escribir(co2["masa_molar_g_mol"])     # → 44.009

glucosa = tabla.masaMolar("C6H12O6")
escribir(glucosa["masa_molar_g_mol"]) # → 180.156
```

> **Nota:** La fórmula distingue mayúsculas. `"co2"` fallará; usa `"CO2"`.
> Los subíndices se escriben como números directamente después del símbolo.
> Fórmulas con paréntesis como `"Ca(OH)2"` no son soportadas en esta versión.

#### `tabla.estado`

Determina el estado de agregación físico (sólido, líquido o gaseoso) de un elemento a una temperatura dada en grados Celsius.

📌 **Sintaxis:**

```latino
tabla.estado(elemento, temperatura_celsius)
```

| Parámetro | Tipo | Descripción |
| :--- | :--- | :--- |
| `elemento` | cadena | Nombre o símbolo del elemento |
| `temperatura_celsius` | número | Temperatura en °C |

**Retorna** — diccionario:

| Campo | Tipo | Descripción |
| :--- | :--- | :--- |
| `elemento` | cadena | Nombre completo |
| `simbolo` | cadena | Símbolo |
| `temperatura` | número | Temperatura consultada |
| `estado` | cadena | `"Sólido"`, `"Líquido"`, `"Gaseoso"` o `"Desconocido"` |
| `fusion_c` | número o nulo | Punto de fusión en °C |
| `ebullicion_c` | número o nulo | Punto de ebullición en °C |

- **Lógica de decisión**

```text
temperatura >= ebullicion_c  →  "Gaseoso"
temperatura >= fusion_c      →  "Líquido"
temperatura <  fusion_c      →  "Sólido"
fusión o ebullición = nulo   →  "Desconocido"
```

🎯 **Ejemplos: Estado del elemento a una temperatura dada**

```latino
incluir("tabla")

# Mercurio a temperatura ambiente
hg = tabla.estado("Hg", 25)
escribir(hg["estado"])       # → Líquido
escribir(hg["fusion_c"])     # → -38.83

# Agua hirviendo sobre hierro
fe = tabla.estado("Fe", 100)
escribir(fe["estado"])       # → Sólido  (Fe funde a 1538 °C)

# Oxígeno a temperatura ambiente
o = tabla.estado("O", 25)
escribir(o["estado"])        # → Gaseoso  (O hierve a -182.96 °C)

# Galio en la palma de la mano (~37 °C)
ga = tabla.estado("Ga", 37)
escribir(ga["estado"])       # → Líquido  (Ga funde a 29.76 °C)

# Elemento superheavy sin datos
rf = tabla.estado("Rf", 25)
escribir(rf["estado"])       # → Desconocido
```

#### `tabla.filtrar`

Devuelve una lista de elementos que coinciden con un criterio de búsqueda. Útil para explorar grupos, períodos o bloques completos.

📌 **Sintaxis:**

```latino
tabla.filtrar(campo, valor)
```

| Parámetro | Tipo | Descripción |
| :--- | :--- | :--- |
| `campo` | cadena | Campo por el que filtrar: `"categoria"`, `"periodo"` o `"bloque"` |
| `valor` | cadena | Valor buscado (insensible a mayúsculas) |

- **Valores válidos por campo**

| Campo | Valores posibles |
| :--- | :--- |
| `"categoria"` | `"Gas noble"`, `"Halógeno"`, `"Metal alcalino"`, `"Metal alcalinotérreo"`, `"Metal de transición"`, `"Metal del bloque p"`, `"Metaloide"`, `"No metal"`, `"Lantánido"`, `"Actínido"` |
| `"periodo"` | `"1"` a `"7"` |
| `"bloque"` | `"s"`, `"p"`, `"d"`, `"f"` |

**Retorna** — lista de diccionarios, cada uno con la misma estructura que `tabla.datos`.
La lista está ordenada por número atómico creciente.

🎯 **Ejemplos: Filtrado de elementos por categoría**

```latino
incluir("tabla")

# Gases nobles
nobles = tabla.filtrar("categoria", "Gas noble")
para elemento en nobles
    escribir(elemento["simbolo"] .. " - " .. elemento["nombre"])
fin
# → He - Helio
# → Ne - Neón
# → Ar - Argón
# → Kr - Kriptón
# → Xe - Xenón
# → Rn - Radón
# → Og - Oganesón

# Elementos del período 2
p2 = tabla.filtrar("periodo", "2")
escribir(lista.longitud(p2))   # → 8

# Metales de transición del bloque d
d = tabla.filtrar("bloque", "d")
escribir(lista.longitud(d))    # → 40

# Contar lantánidos
lant = tabla.filtrar("categoria", "Lantánido")
escribir(lista.longitud(lant)) # → 15
```

#### `tabla.compararMasas`

Compara las masas atómicas de varios elementos, identificando el más pesado, el más liviano y calculando estadísticas básicas.

📌 **Sintaxis:**

```latino
tabla.compararMasas(lista_elementos)
```

| Parámetro | Tipo | Descripción |
| :--- | :--- | :--- |
| `lista_elementos` | lista | Lista de cadenas con nombres o símbolos |

**Retorna** — diccionario:

| Campo | Tipo | Descripción |
| :--- | :--- | :--- |
| `elementos` | lista | Elementos ordenados de mayor a menor masa, cada uno con `nombre`, `simbolo` y `masa` |
| `mas_pesado` | diccionario | Elemento de mayor masa |
| `mas_liviano` | diccionario | Elemento de menor masa |
| `masa_total` | número | Suma de todas las masas |
| `promedio` | número | Promedio aritmético de masas |

🎯 **Ejemplos: Comparación de masas entre dos elementos**

```latino
incluir("tabla")

comp = tabla.compararMasas(["H", "C", "O", "Fe", "Au"])
escribir(comp["mas_pesado"]["nombre"])   # → Oro
escribir(comp["mas_liviano"]["nombre"])  # → Hidrógeno
escribir(comp["promedio"])               # → ~92.4

# Recorrer de mayor a menor
para e en comp["elementos"]
    escribir(e["simbolo"] .. ": " .. e["masa"])
fin
# → Au: 196.97
# → Fe: 55.845
# → O:  15.999
# → C:  12.011
# → H:  1.008
```

#### `tabla.configuracionDetalle`

Expande la configuración electrónica abreviada de un elemento a su forma completa y la desglosa por capa.

📌 **Sintaxis:**

```latino
tabla.configuracionDetalle(elemento)
```

| Parámetro | Tipo | Descripción |
| :--- | :--- | :--- |
| `elemento` | cadena | Nombre o símbolo del elemento |

**Retorna** — diccionario:

| Campo | Tipo | Descripción |
| :--- | :--- | :--- |
| `simbolo` | cadena | Símbolo del elemento |
| `abreviada` | cadena | Configuración tal como está en la base de datos |
| `expandida` | cadena | Configuración completamente expandida sin notación de gas noble |
| `total_electrones` | número | Igual al número atómico Z |
| `por_capa` | diccionario | Claves `"1"`, `"2"`, ... con el total de electrones en esa capa |

🎯 **Ejemplos: Configuración detallada de un elemento**

```latino
incluir("tabla")

# Cromo — caso especial con excepción de llenado
cr = tabla.configuracionDetalle("Cr")
escribir(cr["abreviada"])          # → [Ar] 3d5 4s1
escribir(cr["expandida"])          # → 1s2 2s2 2p6 3s2 3p6 3d5 4s1
escribir(cr["total_electrones"])   # → 24
escribir(cr["por_capa"]["3"])      # → 13  (3s2 + 3p6 + 3d5)

# Sodio
na = tabla.configuracionDetalle("Na")
escribir(na["expandida"])          # → 1s2 2s2 2p6 3s1
escribir(na["por_capa"]["2"])      # → 8

# Helio
he = tabla.configuracionDetalle("He")
escribir(he["expandida"])          # → 1s2
escribir(he["por_capa"]["1"])      # → 2
```

#### `tabla.isotopos`

Devuelve los isótopos estables conocidos de un elemento, identificados por su número de masa A.

📌 **Sintaxis:**

```latino
tabla.isotopos(elemento)
```

| Parámetro | Tipo | Descripción |
| :--- | :--- | :--- |
| `elemento` | cadena | Nombre o símbolo del elemento |

**Retorna** — diccionario:

| Campo | Tipo | Descripción |
| :--- | :--- | :--- |
| `elemento` | cadena | Nombre completo |
| `simbolo` | cadena | Símbolo |
| `numero_atomico` | número | Z |
| `isotopos_estables` | lista | Números de masa A de cada isótopo estable |
| `n_isotopos` | número | Cantidad de isótopos en la lista |
| `nota` | cadena | Presente solo si el elemento no tiene datos registrados |

> **Alcance:** Los isótopos estables están registrados para los elementos Z = 1 al 36 (Hidrógeno hasta Kriptón). Para elementos más pesados, la función retorna lista vacía con una nota informativa.

🎯 **Ejemplos: Isótopos de un elemento y su abundancia**

```latino
incluir("tabla")

# Carbono
c = tabla.isotopos("C")
escribir(c["isotopos_estables"])   # → [12, 13]
escribir(c["n_isotopos"])          # → 2

# Cloro
cl = tabla.isotopos("Cl")
escribir(cl["isotopos_estables"])  # → [35, 37]

# Calcular diferencia de neutrones entre isótopos del hierro
fe = tabla.isotopos("Fe")
escribir(fe["isotopos_estables"])  # → [54, 56, 57, 58]
# Fe-54 tiene 54-26=28 neutrones, Fe-58 tiene 58-26=32 neutrones

# Elemento sin datos
au = tabla.isotopos("Au")
escribir(au["nota"])               # → Isótopos estables no registrados para este elemento.
```

#### `tabla.balancear`

Balancea automáticamente una ecuación química por conservación de masa, resolviendo el sistema lineal de coeficientes estequiométricos.

📌 **Sintaxis:**

```latino
tabla.balancear(ecuacion)
```

| Parámetro | Tipo | Descripción |
| :--- | :--- | :--- |
| `ecuacion` | cadena | Ecuación en formato `"reactivo1 + reactivo2 = producto1 + producto2"` |

**Formato de entrada:**

- Los reactivos y productos se separan con `+` (con o sin espacios).
- El separador entre reactivos y productos es `=`.
- Cada término es una fórmula química estándar: letras y números, sin paréntesis.

**Retorna** — diccionario:

| Campo | Tipo | Descripción |
| :--- | :--- | :--- |
| `entrada` | cadena | Ecuación tal como fue recibida |
| `balanceada` | cadena | Ecuación con coeficientes mínimos enteros |
| `coeficientes` | diccionario | Mapa de cada fórmula a su coeficiente entero |
| `verificado` | booleano | `cierto` si la verificación átomo a átomo pasa |

🎯 **Ejemplos: Balanceo de una ecuación química**

```latino
incluir("tabla")

# Combustión del hidrógeno
r = tabla.balancear("H2 + O2 = H2O")
escribir(r["balanceada"])         # → 2H2 + O2 = 2H2O
escribir(r["verificado"])         # → cierto
escribir(r["coeficientes"]["H2"]) # → 2
escribir(r["coeficientes"]["O2"]) # → 1

# Óxido de hierro
r = tabla.balancear("Fe + O2 = Fe2O3")
escribir(r["balanceada"])         # → 4Fe + 3O2 = 2Fe2O3

# Combustión del metano
r = tabla.balancear("CH4 + O2 = CO2 + H2O")
escribir(r["balanceada"])         # → CH4 + 2O2 = CO2 + 2H2O

# Neutralización ácido-base
r = tabla.balancear("Al + HCl = AlCl3 + H2")
escribir(r["balanceada"])         # → 2Al + 6HCl = 2AlCl3 + 3H2

# Recorrer todos los coeficientes
r = tabla.balancear("C + O2 = CO2")
claves = dic.llaves(r["coeficientes"])

para formula en claves
    coef = r["coeficientes"][formula]
    escribir(formula .. " × " .. coef)
fin
# → C × 1
# → O2 × 1
# → CO2 × 1
```

> **Limitaciones:**
>
> - No soporta fórmulas con paréntesis (`Ca(OH)2`). En ese caso la función lanza un error descriptivo.
> - Funciona con ecuaciones que tengan solución entera con coeficientes positivos. Reacciones de desproporción u otras topologías complejas pueden no resolverse.

### Recetas rápidas

#### Calcular la masa molar del ácido sulfúrico

```latino
incluir("tabla")

h2so4 = tabla.masaMolar("H2SO4")
escribir(h2so4["masa_molar_g_mol"])   # → 98.072
```

#### Encontrar todos los metales líquidos a 30 °C

```latino
incluir("tabla")

metales = tabla.filtrar("categoria", "Metal del bloque p")
para m en metales
    est = tabla.estado(m["simbolo"], 30)
    si est["estado"] == "Líquido"
        escribir(m["nombre"] .. "  (funde a " .. est["fusion_c"] .. " °C)")
    fin
fin
# → Galio  (funde a 29.76 °C)
```

#### Verificar la configuración completa del Uranio

```latino
incluir("tabla")

u = tabla.configuracionDetalle("U")
escribir(u["expandida"])
# → 1s2 2s2 2p6 3s2 3p6 3d10 4s2 4p6 4d10 4f14 5s2 5p6 5f3 6s2 6p6 6d1 7s2
escribir(u["total_electrones"])   # → 92
```

#### Construir una mini tabla de masas molares de moléculas comunes

```latino
incluir("tabla")

moleculas = ["H2O", "CO2", "NH3", "CH4", "NaCl", "H2SO4", "C6H12O6"]
para m en moleculas
    r = tabla.masaMolar(m)
    escribir(r["formula"] .. ": " .. r["masa_molar_g_mol"] .. " g/mol")
fin
```

#### Estequiometría básica con balanceo automático

```latino
incluir("tabla")

# ¿Cuántos gramos de O2 se necesitan para quemar 16 g de CH4?
r    = tabla.balancear("CH4 + O2 = CO2 + H2O")
# → CH4 + 2O2 = CO2 + 2H2O

mCH4 = tabla.masaMolar("CH4")["masa_molar_g_mol"]   # 16.043
mO2  = tabla.masaMolar("O2")["masa_molar_g_mol"]    # 31.998

coefCH4 = r["coeficientes"]["CH4"]   # 1
coefO2  = r["coeficientes"]["O2"]    # 2

# Regla de tres: 16 g CH4 × (2 mol O2 / 1 mol CH4) × (31.998 g/mol)
masaO2 = 16 / mCH4 * coefO2 * mO2
escribir(masaO2)   # → ~63.96 g de O2
```

#### Listar isótopos del hidrógeno y su significado

```latino
incluir("tabla")

h = tabla.isotopos("H")
# Isótopos: [1, 2]
# A=1 → Protio (1 protón, 0 neutrones)
# A=2 → Deuterio (1 protón, 1 neutrón)
z = tabla.datos("H")["numero"]
para a en h["isotopos_estables"]
    neutrones = a - z
    escribir("H-" .. a .. ": " .. neutrones .. " neutrones")
fin
# → H-1: 0 neutrones
# → H-2: 1 neutrones
```

### Manejo de errores

Todas las funciones lanzan un error de tiempo de ejecución con un mensaje descriptivo cuando los parámetros son inválidos. Los casos más comunes:

| Situación | Mensaje de error |
| :--- | :--- |
| Elemento no existe | `Elemento químico no encontrado: 'Xy'` |
| Símbolo desconocido en fórmula | `Símbolo desconocido en la fórmula: 'Xy'` |
| Fórmula vacía o sin elementos | `La fórmula '' no contiene elementos químicos válidos.` |
| Campo inválido en `filtrar` | `Campo no reconocido: 'xyz'. Usa: categoria, periodo, bloque.` |
| Lista vacía en `compararMasas` | `Se requiere al menos un elemento en la lista.` |
| Ecuación sin `=` en `balancear` | `La ecuación debe contener '=' para separar reactivos de productos.` |
| Fórmula con paréntesis en `balancear` | `tabla.balancear no soporta fórmulas con paréntesis.` |

**Ejemplo de captura de errores:**

```latino
intentar
    datos = tabla.datos("Xx")
atrapar (error)
    escribir("Error: " .. error)
    # → Error: Elemento químico no encontrado: 'Xx'
fin
```

🎯 **Ejemplo: Pruebas de Humo Rápidas**

```latino
incluir("tabla")

tabla.datos("Oro")
tabla.datos("Au")
tabla.masaMolar("H2O")
tabla.estado("Oro", 25)
tabla.estado("Mercurio", 25)
tabla.filtrar("categoria", "Metal de transición")

tabla.filtrar("bloque", "d")

```
