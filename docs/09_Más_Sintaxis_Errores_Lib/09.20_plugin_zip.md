## 9.20 Plugin zip (Compresión y Fragmentación)

El plugin `zip` proporciona herramientas nativas y ultra-rápidas para comprimir, extraer y fragmentar archivos grandes a nivel de bytes, ideal para scripts de automatización, respaldos y transferencia de datos.

> **Requiere carga explícita:** `incluir("zip")`

### 🗜️ Compresión y Descompresión

| Función | Parámetros | Descripción |
| :--- | :--- | :--- |
| `zip.comprimir(orig, dest)` | `carpeta, zip` | Comprime una carpeta completa en un archivo `.zip`. |
| `zip.comprimirArchivo(orig, dest)` | `archivo, zip` | Comprime un solo archivo en un `.zip`. |
| `zip.descomprimir(zip, dest)` | `zip, carpeta` | Extrae el contenido del zip en el directorio de destino. |

### 🔍 Manipulación Interna

| Función | Parámetros | Descripción |
| :--- | :--- | :--- |
| `zip.agregar(zip, orig, [ruta])` | `zip, arc, [int]` | Añade o reemplaza un archivo dentro de un zip existente. |
| `zip.contiene(zip, ruta)` | `zip, ruta_interna` | Verifica si un archivo específico existe dentro del zip. |
| `zip.listar(zip)` | `archivo_zip` | Retorna una `lista` con las rutas internas de los archivos. |

### ✂️ Fragmentación de Archivos (Split & Join)

| Función | Parámetros | Descripción |
| :--- | :--- | :--- |
| `zip.cortar(arc, tam, [uni], [dir])` | `arc, num, ...` | Divide por tamaño. Unidad opcional: `"B"`, `"KB"`, `"MB"` (default), `"GB"`. |
| `zip.cortarPartes(arc, num, [dir])` | `arc, num, ...` | Divide equitativamente en un número exacto de partes. |
| `zip.unir(lista_partes, dest)` | `lista, dest` | Une fragmentos restaurando el archivo original. |

> ⚠️ **Precondiciones:** todas estas operaciones actúan sobre archivos que **deben existir en disco**. Si `zip.comprimir` recibe una carpeta inexistente, o `zip.comprimirArchivo` / `zip.cortar` / `zip.cortarPartes` un archivo inexistente, el intérprete lanza `RuntimeError`. Los ejemplos siguientes crean sus propios datos de trabajo con la librería `archivo` y **eliminan todo al final** (higiene), de modo que puedas copiarlos y ejecutarlos tal cual sin dejar residuos.

🎯 **Ejemplo Completo y Autocontenido**

```latino
incluir("zip")

# --- Preparación: los archivos de trabajo se crean aquí mismo ---
archivo.crearCarpeta("mis_datos")
archivo.escribir("mis_datos/1.txt", "Contenido del archivo uno.")
archivo.escribir("mis_datos/2.txt", "Contenido del archivo dos.")
archivo.escribir("config.json", "{\"version\": \"1.0.81\"}")

# --- Compresión y Descompresión ---
escribir("comprimir: " .. zip.comprimir("mis_datos", "backup.zip"))
escribir("comprimirArchivo: " .. zip.comprimirArchivo("config.json", "datos.zip"))
escribir("descomprimir: " .. zip.descomprimir("backup.zip", "extraccion"))

# --- Manipulación Interna ---
# OJO: comprimir una carpeta NO antepone su nombre a las rutas internas.
escribir("listar: " .. acadena(zip.listar("backup.zip")))          # [1.txt, 2.txt]
escribir("contiene 1.txt: " .. zip.contiene("backup.zip", "1.txt")) # cierto

archivo.escribir("nuevo.txt", "Archivo agregado.")
escribir("agregar: " .. zip.agregar("backup.zip", "nuevo.txt", "datos/nuevo.txt"))
escribir("listar tras agregar: " .. acadena(zip.listar("backup.zip")))

# --- Fragmentación (Ideal para límites de envío) ---
archivo.escribir("datos.sql", "CREATE TABLE ejemplo (id INT); -- relleno")

# Cortar en pedazos de 25 MB (la unidad es el 3.er argumento)
partes_mb = zip.cortar("datos.sql", 25, "MB")
escribir("cortar: " .. acadena(partes_mb))

# Cortar exactamente en 3 partes equitativas
partes_eq = zip.cortarPartes("datos.sql", 3)
escribir("cortarPartes: " .. partes_eq)

# Restaurar el archivo original a partir de sus fragmentos
escribir("unir: " .. zip.unir(partes_eq, "datos_restaurados.sql"))
escribir("Restaurado: " .. archivo.leer("datos_restaurados.sql"))

# --- Higiene: no dejar residuos en el disco ---
archivo.borrar("mis_datos")
archivo.borrar("backup.zip")
archivo.borrar("datos.zip")
archivo.borrar("extraccion")
archivo.borrar("config.json")
archivo.borrar("nuevo.txt")
archivo.borrar("datos.sql")
archivo.borrar("datos_restaurados.sql")
para p en partes_eq
    archivo.borrar(p)
fin
escribir("Higiene completada.")
```

**Salida verificada** (ejecutado con `latino zip_demo.lat`):

```text
comprimir: cierto
comprimirArchivo: cierto
descomprimir: cierto
listar: [1.txt, 2.txt]
contiene 1.txt: cierto
agregar: cierto
listar tras agregar: [1.txt, 2.txt, datos/nuevo.txt]
cortar: [<ruta-absoluta>/datos.sql.part001]
cortarPartes: [<ruta-absoluta>/datos.sql.part001, <ruta-absoluta>/datos.sql.part002, <ruta-absoluta>/datos.sql.part003]
unir: cierto
Restaurado: CREATE TABLE ejemplo (id INT); -- relleno
Higiene completada.
```

> 💡 **Las rutas de los fragmentos son absolutas.** `zip.cortar` y `zip.cortarPartes` resuelven el directorio destino con `Path.GetFullPath()`, por eso las listas que retornan contienen la ruta completa. Pasa un 3.er/4.er argumento para controlar dónde se escriben.
>
> 💡 **Comprimir una carpeta no incluye su nombre en las rutas internas.** `zip.comprimir` usa `includeBaseDirectory: false`: si comprimes `mis_datos/`, dentro del zip los archivos quedan como `1.txt`, no como `datos/1.txt`. Usa `zip.agregar` con `ruta_interna` explícita si necesitas una estructura de carpetas dentro del zip.
>
>💡 **Normalización multiplataforma:** El plugin convierte automáticamente los separadores de directorio (`\ de Windows) al formato estándar interno de ZIP (`/`), asegurando que los archivos comprimidos en un Sistema Operativo funcionen perfectamente al extraerlos en otro.

🎯 **Ejemplo: Pruebas de humo rápidas de `zip`**

```latino
incluir("zip")

# Creamos los datos de trabajo: el ejemplo debe correr en una instalación limpia
archivo.crearCarpeta("mi_carpeta")
archivo.escribir("mi_carpeta/archivo.txt", "contenido de prueba")
archivo.escribir("archivo.txt", "contenido de prueba")
archivo.escribir("archivo_grande.zip", "contenido de prueba")
archivo.escribir("datos.sql", "SELECT 1; -- relleno")
archivo.escribir("nuevo.txt", "contenido nuevo")

# Compresión y descompresión
escribir(zip.comprimir("mi_carpeta", "backup.zip"))
escribir(zip.comprimirArchivo("archivo.txt", "datos.zip"))
escribir(zip.descomprimir("backup.zip", "extraccion"))

# Manipulación interna
escribir(zip.listar("backup.zip"))
escribir(zip.contiene("backup.zip", "archivo.txt"))
escribir(zip.agregar("backup.zip", "nuevo.txt", "carpeta/nuevo.txt"))

# --- Fragmentación y restauración ---
# OJO: los fragmentos se nombran "{archivo}.part001", así que usa archivos
# base DISTINTOS para cada operación o una sobrescribirá a la otra.
partes = zip.cortar("archivo_grande.zip", 10, "MB")
partes2 = zip.cortarPartes("datos.sql", 3)
escribir(partes2)
escribir(zip.unir(partes2, "restaurado.sql"))

# Higiene
archivo.borrar("mi_carpeta")
archivo.borrar("backup.zip")
archivo.borrar("datos.zip")
archivo.borrar("extraccion")
archivo.borrar("archivo.txt")
archivo.borrar("archivo_grande.zip")
archivo.borrar("datos.sql")
archivo.borrar("nuevo.txt")
archivo.borrar("restaurado.sql")
para p en partes
    archivo.borrar(p)
fin
para p en partes2
    archivo.borrar(p)
fin
```

> ⚠️ **Los fragmentos comparten nombre base con su archivo de origen.** `zip.cortar` y `zip.cortarPartes` nombran las partes como `{archivo}.part001`, `002`, `003`… Si aplicas ambas operaciones al **mismo** archivo, la segunda sobrescribe los fragmentos de la primera y quedarán partes huérfanas en disco. Usa archivos base distintos, y borra las listas de rutas que devuelve cada llamada.
