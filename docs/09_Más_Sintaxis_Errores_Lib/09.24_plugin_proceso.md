## 9.24 Plugin proceso (Ejecución del OS)

Este es uno de los plugins más potentes del lenguaje. Convierte a Latino.NET en una herramienta de *OS Scripting* capaz de reemplazar a Bash o PowerShell. Permite ejecutar programas de tu computadora de forma sincrónica o asincrónica.

> **Requiere carga explícita:** `incluir("proceso")`

### ⚙️ Ejecución Sincrónica (Bloqueante)

| Función | Parámetros | Descripción |
| :--- | :--- | :--- |
| `proceso.ejecutar(cmd,[args], [t_ms])` | `cmd, args, timeout` | Ejecuta un binario del sistema operativo directamente. |
| `proceso.listar()` | - | Retorna una lista con todos los procesos corriendo en el SO. |
| `proceso.matar(pid)` | `numero` | Termina el proceso del sistema operativo con ese PID. Usa un PID propio; finalizar procesos de otros programas requiere privilegios elevados y no es portable. |
| `proceso.shell(cmd, [t_ms])` | `cadena, timeout` | Ejecuta un comando en el Shell del OS (`cmd.exe` o `/bin/bash`). Soporta tuberías `\|` y redirecciones `>`. |

#### Estructura de Respuesta

`ejecutar` y `shell` retornan un diccionario con el resultado de la ejecución:

- `salida`: Texto impreso en consola (`stdout`).
- `error`: Mensajes de error impresos (`stderr`).
- `codigo`: Entero (0 es éxito, diferente de 0 es fallo).
- `timeout`: Booleano (si fue `verdadero`, el proceso fue abortado por tardar demasiado).

🎯 **Ejemplo: Ejecución Sincrónica**

```latino
incluir("proceso")

cmd = sis.operativo("WIN") ? "echo %USERNAME%" : "echo $USER | tr a-z A-Z"
res = proceso.shell(cmd)
escribir("Usuario en mayúsculas: " .. res["salida"])

# Modo Binario con Lista de Argumentos (Seguro para espacios)
res_git = proceso.ejecutar("git", ["commit", "-m", "Mensaje con espacios"])
si res_git["codigo"] == 0
    escribir("Commit exitoso")
fin
```

### ⏱️ Ejecución Asíncrona (Background)

Para ejecutar programas sin congelar el script de Latino.NET.

| Función | Parámetros | Descripción |
| :--- | :--- | :--- |
| `proceso.ejecutarAsync(cmd,[args])` | `cmd, args` | Lanza el proceso en segundo plano y retorna un ID numérico (interno del plugin). |
| `proceso.esperar(id, [t_ms])` | `id_interno, [timeout]` | Bloquea y espera el resultado final. |
| `proceso.resultado(id)` | `id_interno` | Extrae el diccionario de resultados. Retorna `nulo` si sigue corriendo. |
| `proceso.terminado(id)` | `id_interno` | Retorna `verdadero` si el proceso finalizó. No bloquea. |

🎯 **Ejemplo: Orquestación Asíncrona**

```latino
incluir("proceso")

# ⚠️ Puerto de la plataforma: 'ping' usa -n en Windows y -c en Unix, y los
# flags no son intercambiables. Este patrón evita ambos problemas y no
# requiere conexión a internet (usa el loopback 127.0.0.1).
esWindows = sis.operativo("WINDOWS")
comando   = esWindows ? "ping" : "sleep"
argumentos = esWindows ? ["-n", "3", "127.0.0.1"] : ["2"]

# Lanzar una tarea pesada en segundo plano
escribir("Iniciando tarea pesada...")
id_tarea = proceso.ejecutarAsync(comando, argumentos)

# Nuestro programa es libre de hacer otras cosas
mientras no proceso.terminado(id_tarea)
    escribir("Trabajando...")
    sis.dormir(1)
fin

# Extraer el resultado
resultado = proceso.resultado(id_tarea)
escribir("Comando terminado con código: " .. resultado["codigo"])
```

🎯 **Ejemplo: Pruebas de humo rápidas de `proceso`**

```latino
incluir("proceso")

# Ejecución sincrónica
esWindows = sis.operativo("WINDOWS")
res = proceso.shell(esWindows ? "dir /B" : "ls -1", 10000)
escribir("directorio: " .. res["codigo"])

# `proceso.ejecutar` despacha binarios reales del sistema. Los comandos internos
# del shell (`dir`, `ls`) NO son binarios: despachar "dir" por `ejecutar` falla
# con `cannot access '/B'` en Unix y con Win32Exception en Windows. Para ellos,
# usa `proceso.shell` como en la línea anterior.

# Ejecución asíncrona: retorna un ID INTERNO (no es el PID del sistema).
# ⚠️ esperar() y resultado() consumen el resultado del proceso: recupéralo
# solo una vez, o retornará nulo.
# Usa el loopback y los flags de la plataforma (-n en Windows, -c en Unix):
# no requiere conexión a internet.
comando   = esWindows ? "ping" : "sleep"
argumentos = esWindows ? ["-n", "2", "127.0.0.1"] : ["1"]
id = proceso.ejecutarAsync(comando, argumentos)
proceso.esperar(id)
escribir("proceso async terminado: " .. proceso.terminado(id))

# Gestión de procesos: listar devuelve todos los procesos del sistema
escribir("procesos activos: " .. lista.longitud(proceso.listar()))

# ⚠️ proceso.matar() recibe un PID REAL del sistema operativo, NO el ID
# interno de ejecutarAsync. Para matar algo en una prueba, obtén antes un PID
# que te pertenezca y nunca uses un número inventado: si ese PID existe y es de
# otro programa, lo estarías terminando.
intentar
    proceso.matar(999999)
atrapar (e)
    # Es la forma segura: el error se captura y el script sigue
    escribir("PID inexistente: " .. e)
fin
```
