## 9.23 Plugin log (Registro y Bitácoras)

Para programas en producción, los comandos `escribir()` no son suficientes. Si un script de automatización falla a las 3:00 AM, necesitas un historial. El plugin `log` proporciona registro estructurado, niveles de severidad y rotación automática de archivos (Thread-Safe).

> **Requiere carga explícita:** `incluir("log")`

### 🎛️ Configuración y Niveles

Existen 4 niveles de verbosidad. Un mensaje solo se escribe si su nivel es igual o mayor al nivel mínimo configurado: `depurar` < `info` < `advertencia` < `error`.

| Función | Parámetros | Descripción |
| :--- | :--- | :--- |
| `log.advertencia(msg)` | `texto` | Nivel 2: Situaciones extrañas pero no fatales. |
| `log.configurar(dest, [nvl], [mb])` | `ruta, nivel, maxMb` | Configura el archivo destino, el nivel mínimo y tamaño máximo en MB (default 10MB). |
| `log.depurar(msg)` | `texto` | Nivel 0: Mensajes de diagnóstico profundo. |
| `log.error(msg)` | `texto` | Nivel 3: Fallos críticos en la ejecución. |
| `log.info(msg)` | `texto` | Nivel 1 (Default): Mensajes de estado general. |
| `log.limpiar()` | - | Cierra y libera el archivo actual, retornando al uso de la consola. |

🎯 **Ejemplo: Registro en Archivo Rotativo**

```latino
incluir("log")

# Configurar escritura en archivo. 
# Solo guardará niveles 'advertencia' o superiores. Rotará a los 5 MB.
log.configurar("produccion.log", "advertencia", 5)

# Este mensaje será silenciado (info < advertencia)
log.info("Iniciando servicio...") 

intentar
    x = 10 / 0
atrapar (e)
    # Este sí se escribe
    log.error("Fallo crítico matemático: " .. e) 
fin

# Liberar el archivo si necesitamos enviarlo por red o borrarlo
log.limpiar()

# Higiene: log.limpiar() cierra el handle, pero NO borra el archivo del disco
archivo.borrar("produccion.log")
```

>💡 Por defecto: Si llamas a log.info() sin llamar a log.configurar() primero, el plugin escribirá los mensajes formateados directamente en la consola (Console.Error).

🎯 **Ejemplo: Pruebas de Humo Rápidas**

```latino
incluir("log")

log.configurar("app.log", "info", 10)
log.depurar("Mensaje de depuración")
log.info("Información general")
log.advertencia("Advertencia")
log.error("Error crítico")
log.limpiar()

# Higiene: log.limpiar() cierra el handle, pero NO borra el archivo del disco
archivo.borrar("app.log")
```

#### **Formato de Salida**

Cada línea generada incluirá la marca temporal exacta (hasta milisegundos), el nivel y tu mensaje, perfectamente alineados:

 ```text
[2026-03-03 10:45:01.123] [INFO ] Iniciando conexión a BD...
[2026-03-03 10:45:01.999] [ERROR ] El servidor no respondió.
```
