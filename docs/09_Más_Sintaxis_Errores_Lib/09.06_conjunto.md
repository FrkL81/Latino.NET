## 9.6 Librería `conjunto` (Sets)

La librería `conjunto` implementa colecciones de elementos **únicos**. No garantiza un orden específico, pero asegura que no existan duplicados, basándose en la Teoría de Conjuntos.

### 🔧 Operaciones Básicas

| Función | Parámetros | Descripción |
| :--- | :--- | :--- |
| `conjunto.agregar(s, e)` | `set, valor` | Agrega un elemento si no existe previamente. |
| `conjunto.contiene(s, e)` | `set, valor` | Verifica si el elemento pertenece al conjunto. |
| `conjunto.crear(...)` | `items...` | Crea un conjunto. Los duplicados se eliminan automáticamente. |
| `conjunto.eliminar(s, e)` | `set, valor` | Remueve un elemento del conjunto. |
| `conjunto.longitud(s)` | `set` | Retorna la cantidad de elementos únicos. |

🎯 **Ejemplos: Pruebas de Humo (Operaciones Básicas)**

```latino
# Crear con duplicados
numeros = conjunto.crear(1, 2, 2, 3, 3, 3)
escribir(numeros) # → {1, 2, 3}

# Agregar
conjunto.agregar(numeros, 4)
conjunto.agregar(numeros, 1) # No hace nada, 1 ya existe

# Verificar
si conjunto.contiene(numeros, 3)
    escribir("3 está presente")
fin
```

### 🔀 Teoría de Conjuntos

Permite realizar operaciones matemáticas entre múltiples conjuntos:

| Función | Parámetros | Descripción |
| :--- | :--- | :--- |
| `conjunto.diferencia(a, b)` | `set, set` | **A - B**: Elementos en A que NO están en B. |
| `conjunto.interseccion(a,b)` | `set, set` | **A ∩ B**: Solo los elementos presentes en ambos. |
| `conjunto.union(a, b)` | `set, set` | **A ∪ B**: Elementos de A, de B o de ambos. |

🎯 **Ejemplo: Filtrado de Intereses**

```latino
grupo_a = conjunto.crear("latino", "c#", "python")
grupo_b = conjunto.crear("python", "java", "javascript")

# Unión (Todos los lenguajes sin repetir)
todos = conjunto.union(grupo_a, grupo_b) 
# → {latino, c#, python, java, javascript}

# Intersección (Lenguajes en común)
comunes = conjunto.interseccion(grupo_a, grupo_b)
# → {python}

# Diferencia (¿Qué tiene A que no tenga B?)
solo_a = conjunto.diferencia(grupo_a, grupo_b)
# → {latino, c#}
```

🎯 **Ejemplo: Auditoría de Altas y Bajas de Usuarios**

```latino
ayer = conjunto.crear("carlos", "ana", "marcos", "lucia")
hoy  = conjunto.crear("ana", "lucia", "elena", "pedro")

# 1. Nuevos usuarios registrados hoy (Altas: hoy - ayer)
altas = conjunto.diferencia(hoy, ayer)
escribir("Nuevos usuarios hoy: " .. altas) # {elena, pedro}

# 2. Usuarios que cancelaron su cuenta (Bajas: ayer - hoy)
bajas = conjunto.diferencia(ayer, hoy)
escribir("Usuarios dados de baja: " .. bajas) # {carlos, marcos}

# 3. Usuarios que se mantienen activos (Recurrentes: ayer ∩ hoy)
permanecen = conjunto.interseccion(ayer, hoy)
escribir("Usuarios recurrentes: " .. permanecen) # {ana, lucia}
```

🎯 **Ejemplo: Validación de Roles y Permisos (RBAC)**

```latino
permisos_usuario = conjunto.crear("leer", "escribir", "exportar")
permisos_criticos = conjunto.crear("eliminar", "administrar")

# Verificación de un permiso específico en O(1)
si conjunto.contiene(permisos_usuario, "escribir")
    escribir("✅ Acceso concedido para modificar el registro.")
fin

# Verificar si el usuario posee al menos un privilegio de administración
coincidentes = conjunto.interseccion(permisos_usuario, permisos_criticos)

si conjunto.longitud(coincidentes) > 0
    escribir("Acceso de superusuario habilitado.")
sino
    escribir("🔒 Acción denegada: carece de permisos de administración.")
fin
```

> **💡 Caso de Uso:** Úsalo para eliminar duplicados de una `lista` rápidamente o para gestionar permisos y etiquetas (tags) de forma eficiente.
