## 9.18 Plugin `formulas`

### 9.18.12 Librería `estructuras`

La librería `estructuras` proporciona funciones esenciales para el análisis estructural, incluyendo cálculos de tensiones, deformaciones, estabilidad de columnas y criterios de falla. Las funciones devuelven diccionarios con el resultado, unidad, diagnóstico y fórmula aplicada según corresponda.

#### Referencia de Funciones

| Función | Argumentos | Descripción |
| :--- | :--- | :--- |
| `estructuras.factorSeguridad` | `(resistencia_material, tension_aplicada)` | Factor de seguridad estructural. Mínimo recomendado: 1.5 (estático), 3.0 (dinámico). Fórmula: $FS = \sigma_{resistencia} / \sigma_{aplicada}$ |
| `estructuras.moduloYoung` | `(diccionario_variables)` | Módulo de Young (elasticidad). Omni-Solver: pasa 2 de 'E', 'sigma', 'epsilon'. Fórmula: $E = \sigma / \varepsilon$ |
| `estructuras.momentoInerciaRectangulo` | `(base, altura)` | Momento de inercia de una sección rectangular respecto al eje centroidal. Fórmula: $I = \frac{b h^3}{12}$ |
| `estructuras.pandeoEuler` | `(modulo_young_Pa, inercia_m4, longitud_m, condicion_apoyo)` | Carga crítica de pandeo de Euler para columnas. `condicion_apoyo`: 'pp' (ambos articulados, Le=L), 'ef' (empotrado-libre, Le=2L), 'ep' (empotrado-articulado, Le=0.7L), 'ee' (ambos empotrados, Le=0.5L). Fórmula: $P_{cr} = \frac{\pi^2 E I}{L_e^2}$ |
| `estructuras.tensionNormal` | `(fuerza_N, area_m2)` | Tensión (esfuerzo) normal en una sección transversal. Fórmula: $\sigma = F / A$ |
| `estructuras.vigaFlechaMax` | `(carga_distribuida_N_m, longitud_m, modulo_young_Pa, inercia_m4)` | Flecha máxima de una viga simplemente apoyada con carga distribuida uniforme. Fórmula: $\delta_{max} = \frac{5 w L^4}{384 E I}$ |
| `estructuras.vonMises` | `(sigma_x_Pa, sigma_y_Pa, tau_xy_Pa)` | Criterio de falla de Von Mises para materiales dúctiles (estado plano de tensiones). Fórmula: $\sigma_v = \sqrt{\sigma_x^2 - \sigma_x \sigma_y + \sigma_y^2 + 3\tau_{xy}^2}$ |

🎯 **Ejemplo: estructuras.tensionNormal**

Calcula la tensión normal (esfuerzo) en una sección transversal sometida a una fuerza axial.

```latino
incluir("formulas")

# Columna de acero sometida a compresión
fuerza = 50000  # 50 kN en Newtons
area = 0.01     # 100 cm² en m²

tension = estructuras.tensionNormal(fuerza, area)
escribir("Tensión normal: " .. tension["resultado"] .. " " .. tension["unidad"])
escribir("Fórmula: " .. tension["formula"])
# Salida:
# Tensión normal: 5000000 Pa
# Fórmula: σ = F / A

# Convertir a MPa para mejor lectura
escribir("Tensión: " .. (tension["resultado"] / 1e6) .. " MPa")
# Salida: Tensión: 5 MPa
```

🎯 **Ejemplo: estructuras.moduloYoung**

Calcula el módulo de Young (elasticidad) resolviendo la ecuación $E = \sigma / \varepsilon$. Permite pasar dos de las tres variables para calcular la incógnita.

```latino
incluir("formulas")

# Calcular E a partir de σ y ε
variables1 = {"sigma": 200e6, "epsilon": 0.001}  # 200 MPa, 0.001 deformación
res1 = estructuras.moduloYoung(variables1)
escribir("Módulo de Young: " .. (res1["resultado"] / 1e9) .. " GPa")
escribir("Incógnita calculada: " .. res1["incognita"])
# Salida:
# Módulo de Young: 200 GPa
# Incógnita calculada: E

# Calcular deformación a partir de E y σ
variables2 = {"E": 210e9, "sigma": 150e6}  # 210 GPa, 150 MPa
res2 = estructuras.moduloYoung(variables2)
escribir("Deformación unitaria: " .. res2["resultado"])
escribir("Incógnita calculada: " .. res2["incognita"])
# Salida:
# Deformación unitaria: 0.00071428571428571
# Incógnita calculada: epsilon
```

🎯 **Ejemplo: estructuras.factorSeguridad**

Calcula el factor de seguridad como la relación entre la resistencia del material y la tensión aplicada, incluyendo un diagnóstico sobre su adecuación.

```latino
incluir("formulas")

# Acero estructural A36 (resistencia 250 MPa) con tensión aplicada de 100 MPa
resistencia = 250e6  # 250 MPa en Pa
tension = 100e6      # 100 MPa en Pa

fs = estructuras.factorSeguridad(resistencia, tension)
escribir("Factor de seguridad: " .. fs["resultado"])
escribir("Diagnóstico: " .. fs["diagnostico"])
# Salida:
# Factor de seguridad: 2.5
# Diagnóstico: Aceptable para cargas estáticas

# Caso con factor de seguridad insuficiente
fs_bajo = estructuras.factorSeguridad(250e6, 200e6)
escribir("FS: " .. fs_bajo["resultado"] .. " - " .. fs_bajo["diagnostico"])
# Salida: FS: 1.25 - Insuficiente (riesgo de falla)

# Aluminio (resistencia 200 MPa) con tensión dinámica
fs_dinamico = estructuras.factorSeguridad(200e6, 80e6)
escribir("FS: " .. fs_dinamico["resultado"] .. " - " .. fs_dinamico["diagnostico"])
# Salida: FS: 2.5 - Aceptable para cargas estáticas
```

🎯 **Ejemplo: estructuras.vigaFlechaMax**

Calcula la flecha máxima en una viga simplemente apoyada con carga uniformemente distribuida.

```latino
incluir("formulas")

# Viga de acero IPE 200
carga = 5000      # 5 kN/m en N/m
longitud = 5      # 5 metros
modulo = 210e9    # 210 GPa
inercia = 19.4e-6 # 1940 cm⁴ en m⁴

flecha = estructuras.vigaFlechaMax(carga, longitud, modulo, inercia)
escribir("Flecha máxima: " .. flecha["resultado"] .. " " .. flecha["unidad"])
escribir("Fórmula: " .. flecha["formula"])
# Salida:
# Flecha máxima: 0.009987752618229422 m
# Fórmula: δ_max = (5·w·L⁴) / (384·E·I)

# Verificar si cumple L/300 (límite típico)
limite = longitud / 300
escribir("Límite L/300: " .. limite .. " m")
escribir("¿Cumple? " .. (flecha["resultado"] < limite ? "Sí" : "No"))
# Salida:
# Límite L/300: 0.016666666666666666 m
# ¿Cumple? Sí
```

# Viga de sección rectangular 20cm x 30cm

🎯 **Ejemplo: estructuras.pandeoEuler**

Calcula la carga crítica de pandeo de Euler para columnas según sus condiciones de apoyo, incluyendo la longitud efectiva y advertencias si es necesario.

```latino
incluir("formulas")

# Columna de acero con ambos extremos articulados
modulo = 210e9        # 210 GPa
inercia = 8.33e-6     # 833 cm⁴ en m⁴
longitud = 4          # 4 metros
apoyo = "pp"          # articulado-articulado

pandeo = estructuras.pandeoEuler(modulo, inercia, longitud, apoyo)
escribir("CARGA CRÍTICA DE PANDEO")
escribir("Resultado: " .. (pandeo["resultado"] / 1000) .. " kN")
escribir("Longitud efectiva: " .. pandeo["longitud_efectiva_m"] .. " m")
escribir("Condición: " .. pandeo["condicion"])
# Salida:
# CARGA CRÍTICA DE PANDEO
# Resultado: 1078.5 kN
# Longitud efectiva: 4 m
# Condición: Ambos extremos articulados (Le = L)

# Columna empotrada en base y libre en extremo (mástil)
apoyo_libre = "ef"    # empotrado-libre
pandeo_mastil = estructuras.pandeoEuler(modulo, inercia, longitud, apoyo_libre)
escribir("Mástil - Carga crítica: " .. (pandeo_mastil["resultado"] / 1000) .. " kN")
escribir("Longitud efectiva: " .. pandeo_mastil["longitud_efectiva_m"] .. " m")
escribir("Advertencia: " .. pandeo_mastil["advertencia"])
# Salida:
# Mástil - Carga crítica: 269.6 kN
# Longitud efectiva: 8 m
# Advertencia: La columna es muy esbelta, verificar pandeo

# Comparar diferentes condiciones de apoyo
apoyos = [
    {"cod": "pp", "nom": "Articulado-Articulado"},
    {"cod": "ep", "nom": "Empotrado-Articulado"},
    {"cod": "ee", "nom": "Empotrado-Empotrado"}
]

para apoyo en apoyos
    res = estructuras.pandeoEuler(modulo, inercia, longitud, apoyo["cod"])
    escribir(apoyo["nom"] .. ": " .. (res["resultado"] / 1000) .. " kN")
fin
# Salida:
# Articulado-Articulado: 1078.5 kN
# Empotrado-Articulado: 2201.1 kN
# Empotrado-Empotrado: 4314.1 kN
```

🎯 **Ejemplo: estructuras.vonMises**

Calcula la tensión equivalente de Von Mises para estado plano de tensiones, utilizada como criterio de falla en materiales dúctiles.

```latino
incluir("formulas")

# Punto crítico en una viga sometida a flexión y cortante
sigma_x = 120e6    # 120 MPa por flexión
sigma_y = 0        # Tensión en y despreciable
tau_xy = 40e6      # 40 MPa por cortante

vm = estructuras.vonMises(sigma_x, sigma_y, tau_xy)
escribir("Tensión de Von Mises: " .. (vm["resultado"] / 1e6) .. " MPa")
escribir("Fórmula: " .. vm["formula"])
# Salida:
# Tensión de Von Mises: 138.6 MPa
# Fórmula: σ_v = √(σx² - σx·σy + σy² + 3·τxy²)

# Comparar con límite elástico del material (acero A36: 250 MPa)
limite_elastico = 250e6
si vm["resultado"] < limite_elastico
    escribir("El material no falla (FS = " .. (limite_elastico / vm["resultado"]) .. ")")
sino
    escribir("¡FALLA! La tensión supera el límite elástico")
fin
# Salida: El material no falla (FS = 1.88)

# Estado de corte puro
vm_corte = estructuras.vonMises(0, 0, 80e6)
escribir("Corte puro (80 MPa): " .. (vm_corte["resultado"] / 1e6) .. " MPa")
# Salida: Corte puro (80 MPa): 138.6 MPa (equivale a √3·τ)
```
