## 9.18 Plugin `formulas`

### 9.18.18 Librería `interpolacion`

La librería `interpolacion` proporciona funciones para estimar valores entre puntos conocidos, ajustar curvas a datos experimentales y evaluar polinomios. Incluye métodos desde interpolación lineal simple hasta splines cúbicos y regresión polinomial. Las funciones devuelven diccionarios con los resultados, métricas de calidad y la fórmula aplicada.

#### 🗝️ Estructura de los Diccionarios de Retorno

| Función | Claves del Diccionario Retornado |
| :--- | :--- |
| `interpolacion.bilineal` | `resultado`, `t`, `u`, `es_extrapolacion`, `formula` |
| `interpolacion.hermite` | `resultado`, `derivada_en_x`, `tramo_usado`, `es_extrapolacion`, `formula` |
| `interpolacion.lagrange` | `resultado`, `grado_polinomio`, `es_extrapolacion`, `formula` |
| `interpolacion.lineal` | `resultado`, `formula` |
| `interpolacion.newtonDivididas` | `resultado`, `coeficientes_dd`, `grado_polinomio`, `es_extrapolacion`, `formula` |
| `interpolacion.regresionLineal` | `pendiente`, `intercepto`, `r_cuadrado`, `error_estandar`, `residuos`, `calidad`, `formula` |
| `interpolacion.regresionPolinomial` | `coeficientes`, `grado`, `r_cuadrado`, `formula`, `nota` |
| `interpolacion.splineCubico` | `resultado`, `derivada_en_x`, `tramo_usado`, `es_extrapolacion`, `formula` |

#### Referencia de Funciones

| Función | Argumentos | Descripción |
| :--- | :--- | :--- |
| `interpolacion.bilineal` | `(x0, x1, y0, y1, f00, f10, f01, f11, x, y)` | Interpolación bilineal en una celda rectangular 2D. |
| `interpolacion.evaluarPolinomio` | `(lista_coeficientes, x)` | Evalúa un polinomio en x usando el Esquema de Horner. |
| `interpolacion.hermite` | `(lista_xs, lista_ys, lista_dys, x)` | Interpolación de Hermite cúbica por tramos (valores y derivadas conocidas). |
| `interpolacion.lagrange` | `(lista_xs, lista_ys, x)` | Interpola el valor y en x usando el polinomio de Lagrange de grado n-1. |
| `interpolacion.lineal` | `(x0, y0, x1, y1, x)` | Interpola (o extrapola) linealmente el valor de 'y' para un punto 'x' dado. |
| `interpolacion.newtonDivididas` | `(lista_xs, lista_ys, x)` | Interpola en x usando el polinomio de Newton con Diferencias Divididas. |
| `interpolacion.regresionLineal` | `(lista_xs, lista_ys)` | Ajuste de la recta y = a + b·x por el método de Mínimos Cuadrados. |
| `interpolacion.regresionPolinomial` | `(lista_xs, lista_ys, grado)` | Ajuste de un polinomio de grado k: y = c₀ + c₁x + c₂x² + ... + cₖxᵏ. |
| `interpolacion.splineCubicoLista` | `(lista_xs, lista_ys, lista_x_evaluar)` | Evalúa el spline cúbico en una lista completa de puntos de forma vectorial. Retorna un diccionario con `n_puntos`, `valores_y` y `formula`. |
| `interpolacion.splineCubico` | `(lista_xs, lista_ys, x)` | Interpola en x usando un Spline Cúbico Natural. |

🎯 **Ejemplo: interpolacion.lineal**

Realiza interpolación lineal entre dos puntos conocidos, útil para estimar valores intermedios en tablas de datos.

```latino
incluir("formulas")

# Temperatura a las 3:00 PM, con datos a las 2:00 PM (25°C) y 4:00 PM (29°C)
x0 = 14  # 2:00 PM en horas (formato 24h)
y0 = 25
x1 = 16  # 4:00 PM
y1 = 29
x = 15   # 3:00 PM

interp = interpolacion.lineal(x0, y0, x1, y1, x)
escribir("INTERPOLACIÓN LINEAL")
escribir("Temperatura estimada: " .. interp["resultado"] .. " °C")
escribir("Fórmula: " .. interp["formula"])
# Salida:
# INTERPOLACIÓN LINEAL
# Temperatura estimada: 27 °C
# Fórmula: y = y0 + (y1 - y0)·(x - x0)/(x1 - x0)

# Extrapolación para estimar valor futuro
x_futuro = 18  # 6:00 PM (extrapolación)
extrap = interpolacion.lineal(14, 25, 16, 29, x_futuro)
escribir("\nEXTRAPOLACIÓN")
escribir("Temperatura estimada a las 18:00: " .. extrap["resultado"] .. " °C")
# Salida:
# EXTRAPOLACIÓN
# Temperatura estimada a las 18:00: 33 °C
```

🎯 **Ejemplo: interpolacion.lagrange**

Interpola usando el polinomio de Lagrange, que pasa exactamente por todos los puntos dados. Útil para interpolación de datos experimentales con pocos puntos.

```latino
incluir("formulas")

# Puntos conocidos: (1, 1), (2, 4), (3, 9) (función y = x²)
xs = [1, 2, 3]
ys = [1, 4, 9]
x = 2.5

lag = interpolacion.lagrange(xs, ys, x)
escribir("LAGRANGE")
escribir("Valor interpolado en x=2.5: " .. lag["resultado"])
escribir("Grado del polinomio: " .. lag["grado_polinomio"])
escribir("¿Extrapolación?: " .. (lag["es_extrapolacion"] ? "Sí" : "No"))
escribir("Fórmula: " .. lag["formula"])
# Salida:
# LAGRANGE
# Valor interpolado en x=2.5: 6.25
# Grado del polinomio: 2
# ¿Extrapolación?: No
# Fórmula: P(x) = Σ yᵢ·Lᵢ(x)

# Puntos de una función seno
xs_seno = [0, 1.57, 3.14]  # 0, π/2, π
ys_seno = [0, 1, 0]
x_seno = 2.0

seno_interp = interpolacion.lagrange(xs_seno, ys_seno, x_seno)
escribir("\nSENO INTERPOLADO")
escribir("sen(2.0) ≈ " .. seno_interp["resultado"])
escribir("Valor real: " .. mate.sen(2.0))
# Salida:
# SENO INTERPOLADO
# sen(2.0) ≈ 0.925
# Valor real: 0.909
```

🎯 **Ejemplo: interpolacion.bilineal**

Interpolación bilineal en 2D, útil para estimar valores en mallas rectangulares (imágenes, mapas de calor, etc.).

```latino
incluir("formulas")

# Malla de temperaturas en una placa
# Esquina inferior izquierda (0,0): 100°C
# Esquina inferior derecha (10,0): 120°C
# Esquina superior izquierda (0,10): 80°C
# Esquina superior derecha (10,10): 90°C
x0 = 0
x1 = 10
y0 = 0
y1 = 10
f00 = 100  # T en (0,0)
f10 = 120  # T en (10,0)
f01 = 80   # T en (0,10)
f11 = 90   # T en (10,10)
x = 4
y = 3

bi = interpolacion.bilineal(x0, x1, y0, y1, f00, f10, f01, f11, x, y)
escribir("INTERPOLACIÓN BILINEAL")
escribir("Temperatura en (4,3): " .. bi["resultado"] .. " °C")
escribir("Parámetro t (x): " .. bi["t"])
escribir("Parámetro u (y): " .. bi["u"])
escribir("¿Extrapolación?: " .. (bi["es_extrapolacion"] ? "Sí" : "No"))
escribir("Fórmula: " .. bi["formula"])
# Salida:
# INTERPOLACIÓN BILINEAL
# Temperatura en (4,3): 100.8 °C
# Parámetro t (x): 0.4
# Parámetro u (y): 0.3
# ¿Extrapolación?: No
# Fórmula: f(x,y) = (1-t)(1-u)f₀₀ + t(1-u)f₁₀ + (1-t)u·f₀₁ + t·u·f₁₁

# Centro de la placa
centro = interpolacion.bilineal(0, 10, 0, 10, 100, 120, 80, 90, 5, 5)
escribir("\nCentro (5,5): " .. centro["resultado"] .. " °C")
# Salida:
# Centro (5,5): 97.5 °C
```

🎯 **Ejemplo: interpolacion.newtonDivididas**

Implementa el método de Newton con diferencias divididas, numéricamente más estable que Lagrange y eficiente para agregar nuevos puntos.

```latino
incluir("formulas")

# Datos de velocidad vs tiempo
tiempo = [0, 2, 4, 6, 8]
velocidad = [0, 10, 16, 20, 22]  # m/s
t = 5  # segundos

newton = interpolacion.newtonDivididas(tiempo, velocidad, t)
escribir("NEWTON (DIFERENCIAS DIVIDIDAS)")
escribir("Velocidad en t=5s: " .. newton["resultado"] .. " m/s")
escribir("Coeficientes: " .. newton["coeficientes_dd"])
escribir("Grado del polinomio: " .. newton["grado_polinomio"])
escribir("¿Extrapolación?: " .. (newton["es_extrapolacion"] ? "Sí" : "No"))
escribir("Fórmula: " .. newton["formula"])
# Salida:
# NEWTON (DIFERENCIAS DIVIDIDAS)
# Velocidad en t=5s: 18.5 m/s
# Coeficientes: [0, 5, -0.5, 0.0417, -0.0026]
# Grado del polinomio: 4
# ¿Extrapolación?: No
# Fórmula: P(x) = f[x₀] + f[x₀,x₁](x-x₀) + ...

# Verificar con punto conocido
en_t2 = interpolacion.newtonDivididas(tiempo, velocidad, 2)
escribir("\nEn t=2s (conocido): " .. en_t2["resultado"] .. " m/s")
# Salida:
# En t=2s (conocido): 10 m/s
```

🎯 **Ejemplo: interpolacion.splineCubico**

Interpola usando splines cúbicos naturales, que aseguran continuidad en la función y sus dos primeras derivadas, evitando oscilaciones.

```latino
incluir("formulas")

# Perfil de temperatura en una varilla
posiciones = [0, 2, 4, 6, 8, 10]  # cm
temperaturas = [100, 92, 82, 70, 55, 30]  # °C
x = 5  # cm

spline = interpolacion.splineCubico(posiciones, temperaturas, x)
escribir("SPLINE CÚBICO")
escribir("Temperatura en x=5cm: " .. spline["resultado"] .. " °C")
escribir("Derivada en ese punto: " .. spline["derivada_en_x"] .. " °C/cm")
escribir("Índice del tramo usado: " .. spline["tramo_usado"])
escribir("Intervalo correspondiente: [" .. posiciones[spline["tramo_usado"]] .. ", " .. posiciones[spline["tramo_usado"]+1] .. "] cm")
escribir("¿Extrapolación?: " .. (spline["es_extrapolacion"] ? "Sí" : "No"))
escribir("Fórmula: " .. spline["formula"])
# Salida:
# SPLINE CÚBICO
# Temperatura en x=5cm: 76.07894736842105 °C
# Derivada en ese punto: -6.0227272727272725 °C/cm
# Índice del tramo usado: 2
# Intervalo correspondiente: [4, 6] cm
# ¿Extrapolación?: No
# Fórmula: S_i(x) = aᵢ + bᵢ(x-xᵢ) + cᵢ(x-xᵢ)² + dᵢ(x-xᵢ)³

# Comparar con interpolación lineal
lineal = interpolacion.lineal(4, 82, 6, 70, 5)
escribir("\nCOMPARACIÓN")
escribir("Lineal: " .. lineal["resultado"] .. " °C")
escribir("Spline: " .. spline["resultado"] .. " °C (más suave)")
# Salida:
# COMPARACIÓN
# Lineal: 76 °C
# Spline: 76.07894736842105 °C (más suave)
```

🎯 **Ejemplo: interpolacion.splineCubicoLista**

Evalúa un spline cúbico en múltiples puntos simultáneamente, útil para generar curvas completas. Retorna una lista con los resultados.

```latino
incluir("formulas")

# Mismos datos de temperatura
posiciones = [0, 2, 4, 6, 8, 10]
temperaturas = [100, 92, 82, 70, 55, 30]
puntos_eval = rango(0, 11, 0.5)  # cada 0.5 cm

resultado = interpolacion.splineCubicoLista(posiciones, temperaturas, puntos_eval)
escribir("SPLINE CÚBICO (MÚLTIPLES PUNTOS)")
escribir("Número de puntos evaluados: " .. resultado["n_puntos"])
escribir("Primeros 5 resultados: ")
para i en rango(5)
    escribir("x=" .. puntos_eval[i] .. " → T=" .. resultado["valores_y"][i] .. " °C")
fin
escribir("Fórmula: " .. resultado["formula"])
# Salida:
# SPLINE CÚBICO (MÚLTIPLES PUNTOS)
# Número de puntos evaluados: 22
# Primeros 5 resultados:
# x=0 → T=100 °C
# x=0.5 → T=98.05 °C
# x=1 → T=96.08 °C
# x=1.5 → T=94.07 °C
# x=2 → T=92 °C
# Fórmula: S_i(x) = aᵢ + bᵢ(x-xᵢ) + cᵢ(x-xᵢ)² + dᵢ(x-xᵢ)³ (Spline Natural)
```

🎯 **Ejemplo: interpolacion.hermite**

Interpolación de Hermite que utiliza tanto valores de la función como sus derivadas, garantizando suavidad de orden superior.

```latino
incluir("formulas")

# Trayectoria de un vehículo con posición y velocidad conocidas
tiempos = [0, 2, 4]
posiciones = [0, 20, 60]  # metros
velocidades = [10, 15, 20]  # m/s (derivadas)
t = 3  # segundos

herm = interpolacion.hermite(tiempos, posiciones, velocidades, t)
escribir("HERMITE")
escribir("Posición en t=3s: " .. herm["resultado"] .. " m")
escribir("Derivada en ese punto: " .. herm["derivada_en_x"] .. " m/s")
escribir("Índice del tramo usado: " .. herm["tramo_usado"])
escribir("Intervalo correspondiente: [" .. tiempos[herm["tramo_usado"]] .. ", " .. tiempos[herm["tramo_usado"]+1] .. "] s")
escribir("¿Extrapolación?: " .. (herm["es_extrapolacion"] ? "Sí" : "No"))
escribir("Fórmula: " .. herm["formula"])
# Salida:
# HERMITE
# Posición en t=3s: 38.75 m
# Derivada en ese punto: 21.25 m/s
# Índice del tramo usado: 1
# Intervalo correspondiente: [2, 4] s
# ¿Extrapolación?: No
# Fórmula: H(x) = h₀₀·y₀ + h₁₀·Δx·y'₀ + h₀₁·y₁ + h₁₁·Δx·y'₁
```

🎯 **Ejemplo: interpolacion.regresionLineal**

Ajusta una recta por mínimos cuadrados a un conjunto de datos, proporcionando métricas de calidad del ajuste.

```latino
incluir("formulas")

# Relación entre horas estudio y calificación
horas = [1, 2, 3, 4, 5, 6]
notas = [55, 60, 68, 75, 82, 88]

rl = interpolacion.regresionLineal(horas, notas)
escribir("REGRESIÓN LINEAL")
escribir("Ecuación: y = " .. rl["intercepto"] .. " + " .. rl["pendiente"] .. "·x")
escribir("R² = " .. rl["r_cuadrado"])
escribir("Error estándar: " .. rl["error_estandar"])
escribir("Calidad del ajuste: " .. rl["calidad"])
escribir("Residuos: " .. rl["residuos"])
escribir("Fórmula: " .. rl["formula"])
# Salida:
# REGRESIÓN LINEAL
# Ecuación: y = 47.33 + 6.77·x
# R² = 0.99
# Error estándar: 1.25
# Calidad del ajuste: Excelente
# Residuos: [0.9, -1.1, 0.3, -0.3, -1.1, 1.3]
# Fórmula: y = a + b·x

# Predecir nota para 3.5 horas
predicha = rl["intercepto"] + rl["pendiente"] * 3.5
escribir("\nNota estimada para 3.5h: " .. predicha)
# Salida:
# Nota estimada para 3.5h: 71.0
```

🎯 **Ejemplo: interpolacion.regresionPolinomial**

Ajusta un polinomio de grado especificado a los datos, útil para relaciones no lineales.

```latino
incluir("formulas")

# Datos con tendencia cuadrática (caída libre)
tiempo = [0, 1, 2, 3, 4]
distancia = [0, 4.9, 19.6, 44.1, 78.4]  # d = 4.9·t²

# Ajuste cuadrático (grado 2)
rp = interpolacion.regresionPolinomial(tiempo, distancia, 2)
escribir("REGRESIÓN POLINOMIAL (grado 2)")
escribir("Coeficientes: " .. rp["coeficientes"])
escribir("Grado: " .. rp["grado"])
escribir("R² = " .. rp["r_cuadrado"])
escribir("Nota: " .. rp["nota"])
escribir("Fórmula: " .. rp["formula"])
# Salida:
# REGRESIÓN POLINOMIAL (grado 2)
# Coeficientes: [0, 0, 4.9]  (c₀ + c₁x + c₂x²)
# Grado: 2
# R² = 1.0
# Nota: Ajuste perfecto
# Fórmula: y = c₀ + c₁x + c₂x² + ...

# Evaluar el polinomio en t=2.5
coefs = rp["coeficientes"]
t = 2.5
y_estimado = interpolacion.evaluarPolinomio(coefs, t)
escribir("\nDistancia en t=2.5s: " .. y_estimado .. " m")
# Salida:
# Distancia en t=2.5s: 30.625 m

# Comparar con grado 1 (lineal) para ver mejora
rl_simple = interpolacion.regresionLineal(tiempo, distancia)
escribir("R² lineal: " .. rl_simple["r_cuadrado"])
# Salida:
# R² lineal: 0.91
```

🎯 **Ejemplo: interpolacion.evaluarPolinomio**

Evalúa un polinomio usando el esquema de Horner, más eficiente y numéricamente estable que la evaluación directa. Retorna el valor numérico directamente.

```latino
incluir("formulas")

# Polinomio: P(x) = 2x³ - 3x² + 4x - 5
coeficientes = [-5, 4, -3, 2]  # orden: c₀ + c₁x + c₂x² + c₃x³
x = 2

resultado = interpolacion.evaluarPolinomio(coeficientes, x)
escribir("EVALUACIÓN DE POLINOMIO (HORNER)")
escribir("P(2) = " .. resultado)
# Salida:
# EVALUACIÓN DE POLINOMIO (HORNER)
# P(2) = 7

# Verificar manualmente: 2·8 - 3·4 + 4·2 - 5 = 16 - 12 + 8 - 5 = 7

# Evaluar en múltiples puntos
puntos = rango(-2, 3)  # -2, -1, 0, 1, 2
escribir("\nEVALUACIONES MÚLTIPLES")
para x_val en puntos
    res = interpolacion.evaluarPolinomio(coeficientes, x_val)
    escribir("P(" .. x_val .. ") = " .. res)
fin
# Salida:
# EVALUACIONES MÚLTIPLES
# P(-2) = -41
# P(-1) = -14
# P(0) = -5
# P(1) = -2
# P(2) = 7
```
