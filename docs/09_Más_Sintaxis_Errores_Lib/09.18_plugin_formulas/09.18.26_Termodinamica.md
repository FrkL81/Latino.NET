## 9.18 Plugin `formulas`

### 9.18.26 Librería `termodinamica`

La librería `termodinamica` proporciona funciones esenciales para el estudio de los fenómenos térmicos, incluyendo la ley de gases ideales, cambios de estado, transferencia de calor, radiación y dilatación. Las funciones devuelven diccionarios con los resultados, diagnóstico del estado, y la fórmula aplicada.

#### 🗝️ Estructura de los Diccionarios de Retorno

| Función | Claves del Diccionario Retornado |
| :--- | :--- |
| **Todas** | `resultado`, `unidad`, `formula` |
| `termodinamica.calorEspecifico` | `resultado`, `unidad`, `proceso`, `formula` |
| `termodinamica.cicloCarnot` | `eficiencia_porcentaje` |
| `termodinamica.dilatacionLineal` | `longitud_final` |
| `termodinamica.estadoAgua` | `estado_fisico` |
| `termodinamica.gasIdeal` | `incognita` |

#### Referencia de Funciones

| Función | Argumentos | Descripción |
| :--- | :--- | :--- |
| `termodinamica.calorEspecifico` | `(masa, calorEspecifico, deltaTemperatura)` | Calor absorbido o cedido por una sustancia. Fórmula: $Q = m \cdot c \cdot \Delta T$ |
| `termodinamica.cicloCarnot` | `(temperaturaCalienteK, temperaturaFriaK)` | Eficiencia máxima teórica del ciclo de Carnot. Fórmula: $\eta = 1 - \frac{T_{fría}}{T_{caliente}}$ |
| `termodinamica.conduccionCalor` | `(conductividad, area, deltaTemperatura, espesor)` | Flujo de calor por conducción (Ley de Fourier). Fórmula: $\frac{Q}{t} = \frac{k \cdot A \cdot \Delta T}{d}$ |
| `termodinamica.dilatacionLineal` | `(longitudInicial, coefDilatacion, deltaTemperatura)` | Dilatación lineal de un sólido. Fórmula: $\Delta L = L_0 \cdot \alpha \cdot \Delta T$ |
| `termodinamica.entropiaCambio` | `(calorJ, temperaturaK)` | Cambio de entropía en un proceso reversible isotérmico. Fórmula: $\Delta S = \frac{Q}{T}$ |
| `termodinamica.estadoAgua` | `(temperaturaCelsius)` | Determina el estado del agua a 1 atm. Diagnóstico: Sólido, Líquido, Gaseoso |
| `termodinamica.gasIdeal` | `(diccionarioVariables)` | Ley de gases ideales. Pasa 3 de: 'P', 'V', 'n', 'T'. Fórmula: $P \cdot V = n \cdot R \cdot T$ |
| `termodinamica.stefanBoltzmann` | `(temperaturaK, [emisividad], [areaM2])` | Potencia radiada por un cuerpo. $\sigma = 5.6704 \times 10^{-8}$ W/(m²·K⁴). Fórmula: $P = \varepsilon \cdot \sigma \cdot A \cdot T^4$ |

🎯 **Ejemplo: Ecuación de estado de gases ideales con termodinamica.gasIdeal**

Resuelve la ecuación de los gases ideales $PV = nRT$ permitiendo calcular cualquiera de las cuatro variables (presión, volumen, moles o temperatura) con la constante $R = 0.082057$ L·atm/(mol·K) o $R = 8.314$ J/(mol·K) según las unidades.

```latino
incluir("formulas")

# 🔹 CASO 1: Calcular volumen con unidades SI consistentes
# P = 1 atm = 101325 Pa, resultado en m³ → luego convertir a L si se desea
vars1 = {"n": 2, "T": 300, "P": 101325}  # P en Pa (SI)

gas = termodinamica.gasIdeal(vars1)  # R por defecto = 8.314... (SI)

escribir("GAS IDEAL - Unidades SI")
escribir("n = " .. vars1["n"] .. " mol")
escribir("T = " .. vars1["T"] .. " K")
escribir("P = " .. vars1["P"] .. " Pa (≈ 1 atm)")
escribir("Volumen calculado: " .. gas["resultado"] .. " m³")
escribir("Volumen en litros: " .. (gas["resultado"] * 1000) .. " L")  # Conversión manual
escribir("Incógnita: " .. gas["incognita"])
escribir("Fórmula: " .. gas["formula"])

# 🔹 CASO 2: Calcular temperatura con unidades SI
vars2 = {"P": 101325, "V": 0.02447, "n": 1}  # V = 24.47 L = 0.02447 m³
gas2 = termodinamica.gasIdeal(vars2)

escribir("\nTEMPERATURA - Unidades SI")
escribir("T calculada: " .. gas2["resultado"] .. " K")
escribir("T esperada (25°C): 298.15 K")
escribir("Diferencia: " .. mate.abs(gas2["resultado"] - 298.15) .. " K")

# GAS IDEAL - Unidades SI
# n = 2 mol
# T = 300 K
# P = 101325 Pa (≈ 1 atm)
# Volumen calculado: 0.0492344196476684 m³
# Volumen en litros: 49.234419647668396 L
# Incógnita: V
# Fórmula: P · V = n · R · T
#
# TEMPERATURA - Unidades SI
# T calculada: 298.20601329450824 K
# T esperada (25°C): 298.15 K
# Diferencia: 0.056013294508261424 K
```

🎯 **Ejemplo: termodinamica.estadoAgua**

Determina el estado físico del agua a presión atmosférica normal (1 atm) según su temperatura: sólido (hielo), líquido o gaseoso (vapor).

```latino
incluir("formulas")

# Hielo a -10°C
t1 = -10

estado1 = termodinamica.estadoAgua(t1)
escribir("ESTADO DEL AGUA")
escribir("Temperatura: " .. t1 .. " °C")
escribir("Resultado: " .. estado1["resultado"])
escribir("Estado físico: " .. estado1["estado_fisico"])
escribir("Fórmula: " .. estado1["formula"])
# Salida:
# ESTADO DEL AGUA
# Temperatura: -10 °C
# Resultado: Sólido
# Estado físico: Sólido (hielo)
# Fórmula: H₂O State @ 1 atm

# Agua líquida a 25°C
t2 = 25
estado2 = termodinamica.estadoAgua(t2)
escribir("\nAGUA A 25°C")
escribir("Estado: " .. estado2["estado_fisico"])
# Salida:
# AGUA A 25°C
# Estado: Líquido

# Vapor a 120°C
t3 = 120
estado3 = termodinamica.estadoAgua(t3)
escribir("\nVAPOR SOBRECALENTADO")
escribir("Estado: " .. estado3["estado_fisico"])
# Salida:
# VAPOR SOBRECALENTADO
# Estado: Gaseoso
```

🎯 **Ejemplo: termodinamica.calorEspecifico**

Calcula la cantidad de calor absorbida o cedida por una sustancia cuando su temperatura cambia, usando la ecuación fundamental de la calorimetría.

```latino
incluir("formulas")

# 🔹 Calentar 2 kg de agua de 20°C a 100°C
masa = 2  # kg
c_agua = 4186  # J/(kg·K)
delta_t = 80  # K

calor = termodinamica.calorEspecifico(masa, c_agua, delta_t)

escribir("🔥 CALOR ESPECÍFICO")
escribir("════════════════════════════")
escribir("Masa: " .. masa .. " kg")
escribir("Calor específico: " .. c_agua .. " J/(kg·K)")
escribir("ΔT: " .. delta_t .. " K")
escribir("")
escribir("Resultados:")
escribir("  • Calor calculado: " .. calor["resultado"] .. " " .. calor["unidad"])
escribir("  • Proceso: " .. calor["proceso"])
escribir("  • Fórmula: " .. calor["formula"])

# 🔹 Enfriar una pieza de aluminio
c_aluminio = 900  # J/(kg·K)
masa_al = 0.5
delta_t_al = -50  # se enfría 50°C → ΔT negativo

calor_al = termodinamica.calorEspecifico(masa_al, c_aluminio, delta_t_al)

escribir("")
escribir("❄️ ALUMINIO ENFRIÁNDOSE")
escribir("════════════════════════════")
escribir("Masa: " .. masa_al .. " kg")
escribir("Calor específico: " .. c_aluminio .. " J/(kg·K)")
escribir("ΔT: " .. delta_t_al .. " K")
escribir("")
escribir("Resultados:")
escribir("  • Calor calculado: " .. calor_al["resultado"] .. " " .. calor_al["unidad"])
escribir("  • Proceso: " .. calor_al["proceso"])
escribir("  • Magnitud del calor cedido: " .. mate.abs(calor_al["resultado"]) .. " " .. calor_al["unidad"])
escribir("  • Fórmula: " .. calor_al["formula"])

# 🔹 Interpretación pedagógica del signo
escribir("")
escribir("💡 Interpretación del signo:")
si calor["resultado"] > 0
    escribir("  • Q > 0 → El sistema ABSORBE calor (endotérmico)")
sino
    escribir("  • Q < 0 → El sistema CEDE calor (exotérmico)")
fin

# Salida:
# 🔥 CALOR ESPECÍFICO
# ════════════════════════════
# Masa: 2 kg
# Calor específico: 4186 J/(kg·K)
# ΔT: 80 K
#
# Resultados:
#   • Calor calculado: 669760 J
#   • Proceso: Absorcion de calor (calentamiento)
#   • Fórmula: Q = m·c·ΔT
#
# ❄️ ALUMINIO ENFRIÁNDOSE
# ════════════════════════════
# Masa: 0.5 kg
# Calor específico: 900 J/(kg·K)
# ΔT: -50 K
#
# Resultados:
#   • Calor calculado: -22500 J
#   • Proceso: Cesion de calor (enfriamiento)
#   • Magnitud del calor cedido: 22500 J
#   • Fórmula: Q = m·c·ΔT
#
# 💡 Interpretación del signo:
#   • Q > 0 → El sistema ABSORBE calor (endotérmico)
```

🎯 **Ejemplo: termodinamica.cicloCarnot**

Calcula la eficiencia máxima teórica de una máquina térmica que opera entre dos focos de temperatura, según el ciclo de Carnot.

```latino
incluir("formulas")

# Máquina térmica entre 500K y 300K
t_caliente = 500
t_fria = 300

carnot = termodinamica.cicloCarnot(t_caliente, t_fria)
escribir("CICLO DE CARNOT")
escribir("T fuente caliente: " .. t_caliente .. " K")
escribir("T fuente fría: " .. t_fria .. " K")
escribir("Eficiencia: " .. carnot["resultado"])
escribir("Eficiencia porcentaje: " .. carnot["eficiencia_porcentaje"] .. "%")
escribir("Fórmula: " .. carnot["formula"])
# Salida:
# CICLO DE CARNOT
# T fuente caliente: 500 K
# T fuente fría: 300 K
# Eficiencia: 0.4
# Eficiencia porcentaje: 40%
# Fórmula: η = 1 - (T_fría / T_caliente)

# Central térmica típica (600K y 300K)
central = termodinamica.cicloCarnot(600, 300)
escribir("\nCENTRAL TÉRMICA")
escribir("Eficiencia máxima teórica: " .. central["eficiencia_porcentaje"] .. "%")
# Salida:
# CENTRAL TÉRMICA
# Eficiencia máxima teórica: 50%
```

🎯 **Ejemplo: termodinamica.conduccionCalor**

Calcula la tasa de transferencia de calor por conducción a través de un material, según la ley de Fourier.

```latino
incluir("formulas")

# Pared de ladrillo: k=0.8 W/(m·K), área 10 m², ΔT=20°C, espesor 0.2 m
k = 0.8
area = 10
delta_t = 20
espesor = 0.2

conduccion = termodinamica.conduccionCalor(k, area, delta_t, espesor)
escribir("CONDUCCIÓN DE CALOR")
escribir("Conductividad: " .. k .. " W/(m·K)")
escribir("Área: " .. area .. " m²")
escribir("ΔT: " .. delta_t .. " K")
escribir("Espesor: " .. espesor .. " m")
escribir("Flujo de calor: " .. conduccion["resultado"] .. " W")
escribir("Fórmula: " .. conduccion["formula"])
# Salida:
# CONDUCCIÓN DE CALOR
# Conductividad: 0.8 W/(m·K)
# Área: 10 m²
# ΔT: 20 K
# Espesor: 0.2 m
# Flujo de calor: 800 W
# Fórmula: Q/t = k·A·ΔT / d

# Ventana de vidrio simple
k_vidrio = 0.96
area_ventana = 2
delta_t_ventana = 15
espesor_vidrio = 0.004
ventana = termodinamica.conduccionCalor(k_vidrio, area_ventana, delta_t_ventana, espesor_vidrio)
escribir("\nVENTANA DE VIDRIO")
escribir("Pérdida de calor: " .. ventana["resultado"] .. " W")
# Salida:
# VENTANA DE VIDRIO
# Pérdida de calor: 7200 W
```

🎯 **Ejemplo: termodinamica.stefanBoltzmann**

Calcula la potencia radiada por un cuerpo negro o cuerpo gris según la ley de Stefan-Boltzmann, fundamental en transferencia de calor por radiación.

```latino
incluir("formulas")

# Cuerpo negro perfecto (ε=1) de área 1 m² a 300K
t = 300
emisividad = 1.0
area = 1.0

radiacion = termodinamica.stefanBoltzmann(t, emisividad, area)
escribir("RADIACIÓN (STEFAN-BOLTZMANN)")
escribir("Temperatura: " .. t .. " K")
escribir("Emisividad: " .. emisividad)
escribir("Área: " .. area .. " m²")
escribir("Potencia radiada: " .. radiacion["resultado"] .. " W")
escribir("Fórmula: " .. radiacion["formula"])
# Salida:
# RADIACIÓN (STEFAN-BOLTZMANN)
# Temperatura: 300 K
# Emisividad: 1.0
# Área: 1 m²
# Potencia radiada: 459.3 W
# Fórmula: P = ε·σ·A·T⁴

# Filamento de bombilla (T≈2500K, ε≈0.3, área pequeña)
t_filamento = 2500
e_filamento = 0.3
a_filamento = 0.0001  # 1 cm²
bombilla = termodinamica.stefanBoltzmann(t_filamento, e_filamento, a_filamento)
escribir("\nFILAMENTO DE BOMBILLA")
escribir("Potencia radiada: " .. bombilla["resultado"] .. " W")
# Salida:
# FILAMENTO DE BOMBILLA
# Potencia radiada: 66.4 W

# Sol (superficie a 5778K)
t_sol = 5778
e_sol = 1.0  # aproximación de cuerpo negro
a_sol = 6.09e18  # área superficial del Sol en m²
sol = termodinamica.stefanBoltzmann(t_sol, e_sol, a_sol)
escribir("\nSUPERFICIE SOLAR")
escribir("Potencia total: " .. sol["resultado"] / 1e26 .. " × 10²⁶ W")
# Salida:
# SUPERFICIE SOLAR
# Potencia total: 3.83 × 10²⁶ W
```

🎯 **Ejemplo: termodinamica.dilatacionLineal**

Calcula el cambio de longitud y la longitud final de un material sólido cuando experimenta un cambio de temperatura, según el coeficiente de dilatación lineal.

```latino
incluir("formulas")

# Riel de acero de 20 m, α=1.2e-5 /°C, ΔT=30°C
l0 = 20
alpha = 1.2e-5
delta_t = 30

dilatacion = termodinamica.dilatacionLineal(l0, alpha, delta_t)
escribir("DILATACIÓN LINEAL")
escribir("Longitud inicial: " .. l0 .. " m")
escribir("Coef. dilatación: " .. alpha .. " /°C")
escribir("ΔT: " .. delta_t .. " °C")
escribir("Cambio de longitud: " .. dilatacion["resultado"] .. " m")
escribir("Longitud final: " .. dilatacion["longitud_final"] .. " m")
escribir("Fórmula: " .. dilatacion["formula"])
# Salida:
# DILATACIÓN LINEAL
# Longitud inicial: 20 m
# Coef. dilatación: 1.2e-5 /°C
# ΔT: 30 °C
# Cambio de longitud: 0.0072 m
# Longitud final: 20.0072 m
# Fórmula: ΔL = L₀·α·ΔT

# Puente de acero en invierno/verano
l_puente = 100
delta_t_inv_ver = 40  # diferencia entre invierno y verano
puente = termodinamica.dilatacionLineal(l_puente, 1.2e-5, delta_t_inv_ver)
escribir("\nPUENTE DE ACERO")
escribir("Variación estacional: " .. (puente["resultado"]*1000) .. " mm")
# Salida:
# PUENTE DE ACERO
# Variación estacional: 48 mm

# Comparar diferentes materiales
materiales = [
    {"nombre": "Acero", "alpha": 1.2e-5},
    {"nombre": "Aluminio", "alpha": 2.3e-5},
    {"nombre": "Concreto", "alpha": 1.0e-5},
    {"nombre": "Vidrio", "alpha": 0.8e-5}
]

l_ref = 10
dt_ref = 50

escribir("\nCOMPARACIÓN DE MATERIALES (L=10m, ΔT=50°C)")
para mat en materiales
    d = termodinamica.dilatacionLineal(l_ref, mat["alpha"], dt_ref)
    escribir(mat["nombre"] .. ": ΔL=" .. (d["resultado"]*1000) .. " mm")
fin
# Salida:
# COMPARACIÓN DE MATERIALES (L=10m, ΔT=50°C)
# Acero: ΔL=6 mm
# Aluminio: ΔL=11.5 mm
# Concreto: ΔL=5 mm
# Vidrio: ΔL=4 mm
```

🎯 **Ejemplo: termodinamica.entropiaCambio**

Calcula el cambio de entropía en un proceso reversible isotérmico, una medida del desorden o la energía no disponible para realizar trabajo.

```latino
incluir("formulas")

# Fusión de hielo: Q = 334000 J/kg para 1 kg, T = 273 K
calor = 334000  # J
temperatura = 273  # K

entropia = termodinamica.entropiaCambio(calor, temperatura)
escribir("CAMBIO DE ENTROPÍA")
escribir("Calor transferido: " .. calor .. " J")
escribir("Temperatura: " .. temperatura .. " K")
escribir("ΔS = " .. entropia["resultado"] .. " J/K")
escribir("Fórmula: " .. entropia["formula"])
# Salida:
# CAMBIO DE ENTROPÍA
# Calor transferido: 334000 J
# Temperatura: 273 K
# ΔS = 1223.44 J/K
# Fórmula: ΔS = Q / T

# Vaporización de agua: Q = 2260000 J/kg, T = 373 K
calor_vap = 2260000
t_vap = 373
entropia_vap = termodinamica.entropiaCambio(calor_vap, t_vap)
escribir("\nVAPORIZACIÓN")
escribir("ΔS = " .. entropia_vap["resultado"] .. " J/K")
# Salida:
# VAPORIZACIÓN
# ΔS = 6059 J/K

# Comparar procesos
escribir("\nCOMPARACIÓN")
escribir("Fusión (1kg hielo): ΔS = 1223 J/K")
escribir("Vaporización (1kg agua): ΔS = 6059 J/K")
escribir("La vaporización aumenta más el desorden")
# Salida:
# COMPARACIÓN
# Fusión (1kg hielo): ΔS = 1223 J/K
# Vaporización (1kg agua): ΔS = 6059 J/K
# La vaporización aumenta más el desorden
```
