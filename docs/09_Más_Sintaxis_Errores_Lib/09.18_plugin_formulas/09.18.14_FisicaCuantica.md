## 9.18 Plugin `formulas`

### 9.18.14 Librería `fisicaCuantica`

La librería `fisicaCuantica` proporciona funciones para cálculos fundamentales en mecánica cuántica y relatividad, incluyendo el modelo atómico de Bohr y la equivalencia masa-energía de Einstein. Todas las funciones devuelven diccionarios con resultados detallados y la fórmula aplicada.

#### 🗝️ Estructura de los Diccionarios de Retorno

| Función | Claves del Diccionario Retornado |
| :--- | :--- |
| `fisicaCuantica.energiaMasa` | `resultado`, `unidad`, `formula` |
| `fisicaCuantica.modeloBohr` | `radio_orbital_m`, `energia_eV`, `velocidad_tangencial_ms`, `formula` |

#### Referencia de Funciones

| Función | Argumentos | Descripción |
| :--- | :--- | :--- |
| `fisicaCuantica.energiaMasa` | `(masaKg)` | Equivalencia entre masa y energía (Relatividad Especial de Einstein). Fórmula: $E = m \cdot c^2$ |
| `fisicaCuantica.modeloBohr` | `(numeroCuanticoN, numeroAtomicoZ)` | Radio, Energía y Velocidad del electrón en un átomo hidrogenoide (Modelo de Bohr). Fórmulas: $r = \frac{n^2 \cdot a_0}{Z}$, $E = -13.6 \cdot \frac{Z^2}{n^2}$ |

🎯 **Ejemplo: fisicaCuantica.modeloBohr**

Calcula las propiedades del electrón en un átomo hidrogenoide (con un solo electrón) según el modelo de Bohr, incluyendo radio orbital, energía y velocidad.

```latino
incluir("formulas")

# Átomo de hidrógeno (Z=1) en estado fundamental (n=1)
n = 1
z = 1

bohr = fisicaCuantica.modeloBohr(n, z)
escribir("ÁTOMO DE HIDRÓGENO (n=1)")
escribir("Radio orbital: " .. bohr["radio_orbital_m"] .. " m")
escribir("Energía: " .. bohr["energia_eV"] .. " eV")
escribir("Velocidad tangencial: " .. bohr["velocidad_tangencial_ms"] .. " m/s")
escribir("Fórmula: " .. bohr["formula"])
# Salida:
# ÁTOMO DE HIDRÓGENO (n=1)
# Radio orbital: 5.2917721067e-11 m
# Energía: -13.6 eV
# Velocidad tangencial: 2187691.252 m/s
# Fórmula: r = (n²·a₀)/Z | E = -13.6·(Z²/n²)

# Convertir radio a Angstroms para mejor lectura (1 Å = 1e-10 m)
radio_angstrom = bohr["radio_orbital_m"] * 1e10
escribir("Radio orbital: " .. radio_angstrom .. " Å")
# Salida: Radio orbital: 0.52917721067 Å

# Átomo de hidrógeno en primer estado excitado (n=2)
bohr_excitado = fisicaCuantica.modeloBohr(2, 1)
escribir("HIDRÓGENO (n=2) - Radio: " .. (bohr_excitado["radio_orbital_m"] * 1e10) .. " Å")
escribir("HIDRÓGENO (n=2) - Energía: " .. bohr_excitado["energia_eV"] .. " eV")
# Salida:
# HIDRÓGENO (n=2) - Radio: 2.11670884268 Å
# HIDRÓGENO (n=2) - Energía: -3.4 eV

# Ion helio singly ionizado (He⁺, Z=2) en estado fundamental
helio = fisicaCuantica.modeloBohr(1, 2)
escribir("ION HELIO He⁺ (n=1, Z=2)")
escribir("Radio: " .. (helio["radio_orbital_m"] * 1e10) .. " Å")
escribir("Energía: " .. helio["energia_eV"] .. " eV")
# Salida:
# ION HELIO He⁺ (n=1, Z=2)
# Radio: 0.264588605335 Å
# Energía: -54.4 eV

# Comparar propiedades para diferentes niveles y cargas
niveles = rango(1, 4)      # n = 1, 2, 3
cargas = [1, 2]

para n en niveles
    para z en cargas
        res = fisicaCuantica.modeloBohr(n, z)
        radio_ang = res["radio_orbital_m"] * 1e10
        escribir("n=" .. n .. ", Z=" .. z .. ": r=" .. radio_ang .. " Å, E=" .. res["energia_eV"] .. " eV")
    fin
fin
# Salida:
# n=1, Z=1: r=0.52917721067 Å, E=-13.6 eV
# n=1, Z=2: r=0.264588605335 Å, E=-54.4 eV
# n=2, Z=1: r=2.11670884268 Å, E=-3.4 eV
# n=2, Z=2: r=1.05835442134 Å, E=-13.6 eV
# n=3, Z=1: r=4.76259489603 Å, E=-1.5111111111111 eV
# n=3, Z=2: r=2.381297448015 Å, E=-6.0444444444444 eV
```

🎯 **Ejemplo: fisicaCuantica.energiaMasa**

Calcula la energía equivalente a una masa dada según la famosa ecuación de Einstein $E = mc^2$, donde $c = 299,792,458$ m/s es la velocidad de la luz en el vacío.

```latino
incluir("formulas")

# Energía equivalente a 1 gramo de masa
masa = 0.001  # 1 gramo en kg

emc = fisicaCuantica.energiaMasa(masa)
escribir("EQUIVALENCIA MASA-ENERGÍA")
escribir("Masa: " .. masa .. " kg")
escribir("Energía equivalente: " .. emc["resultado"] .. " " .. emc["unidad"])
escribir("Fórmula: " .. emc["formula"])
# Salida:
# EQUIVALENCIA MASA-ENERGÍA
# Masa: 0.001 kg
# Energía equivalente: 8.98755e13 J
# ≈ 21.5 kilotones de TNT

# Convertir a kilotones de TNT (1 kt TNT ≈ 4.184e12 J)
energia_joules = emc["resultado"]
kilotones = energia_joules / 4.184e12
escribir("Equivalente: " .. kilotones .. " kilotones de TNT")
# Equivalente: 21.480764310153386 kilotones de TNT (aprox. 0.0215 megatones)

# Masa de un electrón en kg (9.1093837e-31)
masa_electron = 9.1093837e-31
electron = fisicaCuantica.energiaMasa(masa_electron)
escribir("Energía del electrón: " .. electron["resultado"] .. " J")
escribir("Energía en eV: " .. (electron["resultado"] / 1.60217662e-19) .. " eV")
# Salida:
# Energía del electrón: 8.1871057768e-14 J
# Energía en eV: 511000 eV (0.511 MeV)

# Comparar diferentes masas
masas = [1e-6, 0.001, 1, 1000]  # 1mg, 1g, 1kg, 1ton
etiquetas = ["1 mg", "1 g", "1 kg", "1 ton"]
indice = 0

para m en masas
    res = fisicaCuantica.energiaMasa(m)
    energia_kt = res["resultado"] / 4.184e12
    escribir(etiquetas[indice] .. ": " .. res["resultado"] .. " J  (" .. energia_kt .. " kt TNT)")
    indice++
fin
# Salida:
# 1 mg: 89875517873.68 J  (21.48 kt TNT)
# 1 g: 89875517873681.76 J  (21481.5 kt TNT)
# 1 kg: 8.987551787368176e+16 J  (2.14815e+07 kt TNT)
# 1 ton: 8.987551787368176e+19 J  (2.14815e+10 kt TNT)
```
