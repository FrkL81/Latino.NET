## 9.18 Plugin `formulas`

### 9.18.19 Librería `matematicas`

La librería `matematicas` proporciona funciones para cálculos matemáticos fundamentales, incluyendo series geométricas, progresiones aritméticas y logaritmos en cualquier base. Las funciones devuelven diccionarios con los resultados y la fórmula aplicada.

#### 🗝️ Estructura de los Diccionarios de Retorno

| Función | Claves del Diccionario Retornado |
| :--- | :--- |
| **Todas** | `resultado`, `unidad`, `formula` |
| `matematicas.logaritmoBase` | — |
| `matematicas.progresionAritmetica` | `suma`, `termino_n`, `media` |
| `matematicas.serieGeometrica` | `suma_infinita` (solo si \|r\| < 1) |

#### Referencia de Funciones

| Función | Argumentos | Descripción |
| :--- | :--- | :--- |
| `matematicas.logaritmoBase` | `(valor, base)` | Logaritmo de un número en cualquier base (cambio de base). Fórmula: $\log_b(x) = \frac{\ln(x)}{\ln(b)}$ |
| `matematicas.progresionAritmetica` | `(primerTermino, diferenciaComun, numTerminos)` | Suma y término n-ésimo de una progresión aritmética. Fórmulas: $a_n = a_1 + (n-1)d$, $S = n \cdot \frac{a_1 + a_n}{2}$ |
| `matematicas.serieGeometrica` | `(primerTermino, razon, numTerminos)` | Suma de una serie geométrica finita. Fórmula: $S = a \cdot \frac{1 - r^n}{1 - r}$ |

🎯 **Ejemplo: matematicas.serieGeometrica**

Calcula la suma de una serie geométrica finita. Si la razón está en el intervalo (-1, 1), también proporciona la suma infinita teórica.

```latino
incluir("formulas")

# Serie geométrica: 2, 6, 18, 54, 162 (a=2, r=3, n=5)
a = 2
r = 3
n = 5

sg = matematicas.serieGeometrica(a, r, n)
escribir("SERIE GEOMÉTRICA (|r|>1)")
escribir("Primer término (a): " .. a)
escribir("Razón (r): " .. r)
escribir("Número de términos: " .. n)
escribir("Suma de " .. n .. " términos: " .. sg["resultado"])
escribir("Fórmula: " .. sg["formula"])
# Salida:
# SERIE GEOMÉTRICA (|r|>1)
# Primer término (a): 2
# Razón (r): 3
# Número de términos: 5
# Suma de 5 términos: 242
# Fórmula: S = a·(1 - rⁿ)/(1 - r)

# Serie geométrica convergente (|r|<1)
sg_conv = matematicas.serieGeometrica(100, 0.5, 10)
escribir("\nSERIE GEOMÉTRICA CONVERGENTE")
escribir("Suma de 10 términos: " .. sg_conv["resultado"])
escribir("Suma infinita teórica: " .. sg_conv["suma_infinita"])
# Salida:
# SERIE GEOMÉTRICA CONVERGENTE
# Suma de 10 términos: 199.8046875
# Suma infinita teórica: 200

# Verificar convergencia
sg_larga = matematicas.serieGeometrica(100, 0.5, 20)
escribir("Suma de 20 términos: " .. sg_larga["resultado"])
# Salida:
# Suma de 20 términos: 199.99980926514
```

🎯 **Ejemplo: matematicas.progresionAritmetica**

Calcula el término n-ésimo, la suma total y la media de los primeros n términos de una progresión aritmética.

```latino
incluir("formulas")

# Progresión aritmética: 3, 7, 11, 15, 19 (a=3, d=4, n=5)
a = 3
d = 4
n = 5

pa = matematicas.progresionAritmetica(a, d, n)
escribir("PROGRESIÓN ARITMÉTICA")
escribir("Primer término (a₁): " .. a)
escribir("Diferencia común (d): " .. d)
escribir("Número de términos: " .. n)
escribir("Resultado (suma): " .. pa["suma"])
escribir("Suma total: " .. pa["suma"])
escribir("Término " .. n .. " (aₙ): " .. pa["termino_n"])
escribir("Media de la progresión: " .. pa["media"])
escribir("Fórmula: " .. pa["formula"])
# Salida:
# PROGRESIÓN ARITMÉTICA
# Primer término (a₁): 3
# Diferencia común (d): 4
# Número de términos: 5
# Resultado (suma): 55
# Suma total: 55
# Término 5 (aₙ): 19
# Media de la progresión: 11
# Fórmula: aₙ = a₁ + (n-1)d | S = n·(a₁ + aₙ)/2

# Suma de los primeros 100 números naturales
suma_100 = matematicas.progresionAritmetica(1, 1, 100)
escribir("\nSUMA 1..100")
escribir("Término 100: " .. suma_100["termino_n"])
escribir("Suma total: " .. suma_100["suma"])
escribir("Media: " .. suma_100["media"])
# Salida:
# SUMA 1..100
# Término 100: 100
# Suma total: 5050
# Media: 50.5

# Ahorro progresivo (incremento mensual fijo)
ahorro = matematicas.progresionAritmetica(100, 50, 12)  # $100 primer mes, +$50 cada mes
escribir("\nAHORRO PROGRESIVO (12 meses)")
escribir("Ahorro mes 12: $" .. ahorro["termino_n"])
escribir("Ahorro total anual: $" .. ahorro["suma"])
escribir("Ahorro promedio mensual: $" .. ahorro["media"])
# Salida:
# AHORRO PROGRESIVO (12 meses)
# Ahorro mes 12: $650
# Ahorro total anual: $4500
# Ahorro promedio mensual: $375
```

🎯 **Ejemplo: matematicas.logaritmoBase**

Calcula el logaritmo de un número en cualquier base mediante el cambio de base.

```latino
incluir("formulas")

# Logaritmo base 2 de 8 (debe ser 3)
valor = 8
base = 2

log = matematicas.logaritmoBase(valor, base)
escribir("LOGARITMO EN BASE ARBITRARIA")
escribir("log₂(8) = " .. log["resultado"])
escribir("Unidad: " .. log["unidad"])
escribir("Fórmula: " .. log["formula"])
# Salida:
# LOGARITMO EN BASE ARBITRARIA
# log₂(8) = 3
# Unidad: adimensional
# Fórmula: log_b(x) = ln(x) / ln(b)

# pH es logaritmo base 10 (negativo)
concentracion_H = 1e-7  # concentración de iones H+ en agua pura
pH = -matematicas.logaritmoBase(concentracion_H, 10)["resultado"]
escribir("\npH del agua pura: " .. pH)
# Salida:
# pH del agua pura: 7

# Decibelios (logaritmo base 10)
potencia_salida = 100
potencia_entrada = 1
db = 10 * matematicas.logaritmoBase(potencia_salida / potencia_entrada, 10)["resultado"]
escribir("Ganancia: " .. db .. " dB")
# Salida:
# Ganancia: 20 dB

# Comparar diferentes bases
valores = [10, 100, 1000]
bases = [2, 10, mate.e]  # e es el número de Euler (minúscula)

escribir("\nLOGARITMOS EN DIFERENTES BASES")
para v en valores
    para b en bases
        res = matematicas.logaritmoBase(v, b)
        # Usamos formato C para que la salida se vea limpia (2 decimales)
        imprimirf("log_%.2f(%.0f) = %.4f\n", b, v, res["resultado"])
    fin
fin
# Salida:
# LOGARITMOS EN DIFERENTES BASES
# log_2.00(10) = 3.3219
# log_10.00(10) = 1.0000
# log_2.72(10) = 2.3026
# log_2.00(100) = 6.6439
# log_10.00(100) = 2.0000
# log_2.72(100) = 4.6052
# log_2.00(1000) = 9.9658
# log_10.00(1000) = 3.0000
# log_2.72(1000) = 6.9078
```
