## 9.18 Plugin `formulas`

### 9.18.25 Librería `senales`

La librería `senales` proporciona funciones esenciales para el análisis de señales y sistemas de comunicación, incluyendo cálculos de decibelios, teorema de Nyquist, relación señal-ruido, capacidad de canal Shannon y modulación AM. Las funciones devuelven diccionarios con los resultados, metadatos específicos y la fórmula aplicada.

#### 🗝️ Estructura de los Diccionarios de Retorno

| Función | Claves del Diccionario Retornado |
| :--- | :--- |
| **Todas** | `resultado`, `unidad`, `formula` |
| `senales.anchoBandaModulacionAM` | `frecuencia_superior_Hz`, `frecuencia_inferior_Hz` |
| `senales.capacidadCanalShannon` | `capacidad_Mbps`, `nota` |
| `senales.decibelesPotencia` | `tipo` |
| `senales.frecuenciaNyquist` | `frecuencia_nyquist_Hz`, `nota` |
| `senales.snr` | `calidad_senal` |

#### Referencia de Funciones

| Función | Argumentos | Descripción |
| :--- | :--- | :--- |
| `senales.anchoBandaModulacionAM` | `(frecuencia_portadora_Hz, frecuencia_maxima_audio_Hz)` | Ancho de banda de una señal AM (doble banda lateral). Fórmula: $BW = 2 \cdot f_m$ |
| `senales.capacidadCanalShannon` | `(ancho_banda_Hz, snr_lineal)` | Capacidad máxima teórica de un canal con ruido (Teorema de Shannon-Hartley). Fórmula: $C = B \cdot \log_2(1 + SNR)$ |
| `senales.decibelesPotencia` | `(potencia_salida, potencia_entrada)` | Nivel en decibeles para relación de potencias. Fórmula: $dB = 10 \cdot \log_{10}(P_{out} / P_{in})$ |
| `senales.decibelesVoltaje` | `(voltaje_salida, voltaje_entrada)` | Nivel en decibeles para relación de voltajes (o amplitudes). Fórmula: $dBV = 20 \cdot \log_{10}(V_{out} / V_{in})$ |
| `senales.frecuenciaNyquist` | `(frecuencia_maxima_senal)` | Frecuencia mínima de muestreo para evitar aliasing (Teorema de Nyquist-Shannon). Fórmula: $f_s \geq 2 \cdot f_{max}$ |
| `senales.snr` | `(potencia_senal, potencia_ruido)` | Relación Señal-Ruido (Signal-to-Noise Ratio). Fórmula: $SNR = 10 \cdot \log_{10}(P_{señal} / P_{ruido})$ |

🎯 **Ejemplo: senales.decibelesPotencia**

Calcula la ganancia o pérdida en decibelios (dB) para una relación de potencias, fundamental en telecomunicaciones y audio.

```latino
incluir("formulas")

# Amplificador con potencia de entrada 1W y salida 100W
p_in = 1
p_out = 100

db = senales.decibelesPotencia(p_out, p_in)
escribir("DECIBELIOS (POTENCIA)")
escribir("Potencia entrada: " .. p_in .. " W")
escribir("Potencia salida: " .. p_out .. " W")
escribir("Resultado: " .. db["resultado"] .. " dB")
escribir("Tipo: " .. db["tipo"])
escribir("Fórmula: " .. db["formula"])
# Salida:
# DECIBELIOS (POTENCIA)
# Potencia entrada: 1 W
# Potencia salida: 100 W
# Resultado: 20 dB
# Tipo: Ganancia de potencia
# Fórmula: dB = 10·log₁₀(P_out / P_in)

# Atenuación en cable coaxial
p_entrada_cable = 0.01  # 10 mW
p_salida_cable = 0.005  # 5 mW
atenuacion = senales.decibelesPotencia(p_salida_cable, p_entrada_cable)
escribir("\nATENUACIÓN EN CABLE")
escribir("Resultado: " .. atenuacion["resultado"] .. " dB")
escribir("Tipo: " .. atenuacion["tipo"])
# Salida:
# ATENUACIÓN EN CABLE
# Resultado: -3.01 dB
# Tipo: Atenuación (pérdida)
```

🎯 **Ejemplo: senales.decibelesVoltaje**

Calcula la ganancia o pérdida en decibelios para una relación de voltajes (o amplitudes), usando el factor 20 en lugar de 10.

```latino
incluir("formulas")

# Amplificador de voltaje con entrada 0.1V y salida 1V
v_in = 0.1
v_out = 1.0

dbv = senales.decibelesVoltaje(v_out, v_in)
escribir("DECIBELIOS (VOLTAJE)")
escribir("Voltaje entrada: " .. v_in .. " V")
escribir("Voltaje salida: " .. v_out .. " V")
escribir("Resultado: " .. dbv["resultado"] .. " dBV")
escribir("Fórmula: " .. dbv["formula"])
# Salida:
# DECIBELIOS (VOLTAJE)
# Voltaje entrada: 0.1 V
# Voltaje salida: 1.0 V
# Resultado: 20 dBV
# Fórmula: dBV = 20·log₁₀(V_out / V_in)

# Relación señal-ruido en voltaje
v_senal = 2.0
v_ruido = 0.1
snr_v = senales.decibelesVoltaje(v_senal, v_ruido)
escribir("\nSNR (VOLTAJE)")
escribir("SNR = " .. snr_v["resultado"] .. " dBV")
# Salida:
# SNR (VOLTAJE)
# SNR = 26.02 dBV
```

🎯 **Ejemplo: senales.frecuenciaNyquist**

Calcula la frecuencia mínima de muestreo necesaria para digitalizar una señal sin pérdida de información, según el teorema de Nyquist-Shannon.

```latino
incluir("formulas")

# Señal de audio con frecuencia máxima 20 kHz (audio de alta fidelidad)
f_max = 20000  # 20 kHz

nyquist = senales.frecuenciaNyquist(f_max)
escribir("TEOREMA DE NYQUIST")
escribir("Frecuencia máxima de la señal: " .. f_max .. " Hz")
escribir("Resultado (frecuencia muestreo): " .. nyquist["resultado"] .. " Hz")
escribir("Frecuencia de Nyquist: " .. nyquist["frecuencia_nyquist_Hz"] .. " Hz")
escribir("Nota: " .. nyquist["nota"])
escribir("Fórmula: " .. nyquist["formula"])
# Salida:
# TEOREMA DE NYQUIST
# Frecuencia máxima de la señal: 20000 Hz
# Resultado (frecuencia muestreo): 40000 Hz
# Frecuencia de Nyquist: 20000 Hz
# Nota: Para evitar aliasing, usar filtro antialiasing antes del muestreo
# Fórmula: fs_min = 2·f_max

# Audio telefónico (300 Hz - 3400 Hz)
f_telefono = 3400
fs_telefono = senales.frecuenciaNyquist(f_telefono)
escribir("\nTELEFONÍA")
escribir("Muestreo necesario: " .. fs_telefono["resultado"] / 1000 .. " kHz")
# Salida:
# TELEFONÍA
# Muestreo necesario: 6.8 kHz
```

🎯 **Ejemplo: senales.snr**

Calcula la relación señal-ruido (SNR) en decibelios, una medida crítica de la calidad de una señal en presencia de ruido, incluyendo una clasificación de la calidad.

```latino
incluir("formulas")

# Señal de radio FM con potencia 100 μW, ruido 0.1 μW
p_senal = 100e-6
p_ruido = 0.1e-6

snr = senales.snr(p_senal, p_ruido)
escribir("RELACIÓN SEÑAL-RUIDO (SNR)")
escribir("Potencia de señal: " .. p_senal .. " W")
escribir("Potencia de ruido: " .. p_ruido .. " W")
escribir("Resultado: " .. snr["resultado"] .. " dB")
escribir("Calidad de señal: " .. snr["calidad_senal"])
escribir("Fórmula: " .. snr["formula"])
# Salida:
# RELACIÓN SEÑAL-RUIDO (SNR)
# Potencia de señal: 0.0001 W
# Potencia de ruido: 1e-7 W
# Resultado: 30 dB
# Calidad de señal: Excelente
# Fórmula: SNR = 10·log₁₀(P_señal / P_ruido)

# Señal degradada
snr_baja = senales.snr(1e-6, 1e-6)  # SNR = 0 dB (señal = ruido)
escribir("\nSNR = 0 dB")
escribir("Calidad: " .. snr_baja["calidad_senal"])
# Salida:
# SNR = 0 dB
# Calidad: Mala (señal igual al ruido)
```

🎯 **Ejemplo: senales.capacidadCanalShannon**

Calcula la capacidad máxima teórica de un canal de comunicaciones según el teorema de Shannon-Hartley, incluyendo la capacidad en Mbps y notas explicativas.

```latino
incluir("formulas")

# Canal telefónico: ancho de banda 3100 Hz, SNR 30 dB (relación lineal 1000)
bw = 3100
snr_lineal = 1000  # 30 dB

capacidad = senales.capacidadCanalShannon(bw, snr_lineal)
escribir("CAPACIDAD DE CANAL (SHANNON)")
escribir("Ancho de banda: " .. bw .. " Hz")
escribir("SNR lineal: " .. snr_lineal)
escribir("Resultado: " .. capacidad["resultado"] .. " bps")
escribir("Capacidad en Mbps: " .. capacidad["capacidad_Mbps"] .. " Mbps")
escribir("Nota: " .. capacidad["nota"])
escribir("Fórmula: " .. capacidad["formula"])
# Salida:
# CAPACIDAD DE CANAL (SHANNON)
# Ancho de banda: 3100 Hz
# SNR lineal: 1000
# Resultado: 30898.401402391577 bps
# Capacidad en Mbps: 0.030898401402391577 Mbps
# Nota: Limite teorico maximo. Los protocolos reales usan ~70% de esto.
# Fórmula: C = B·log₂(1 + SNR)

# ADSL típico (ancho de banda 1.1 MHz, SNR 20 dB)
bw_adsl = 1.1e6
snr_adsl = 100  # 20 dB
c_adsl = senales.capacidadCanalShannon(bw_adsl, snr_adsl)
escribir("\nADSL")
escribir("Capacidad: " .. c_adsl["capacidad_Mbps"] .. " Mbps")
# Salida:
# ADSL
# Capacidad: 7.2 Mbps
```

🎯 **Ejemplo: senales.anchoBandaModulacionAM**

Calcula el ancho de banda de una señal modulada en AM (Amplitud Modulada) y las frecuencias laterales resultantes.

```latino
incluir("formulas")

# Emisora AM con portadora 1000 kHz, audio hasta 5 kHz
fc = 1000e3  # 1000 kHz
fm = 5000    # 5 kHz

am = senales.anchoBandaModulacionAM(fc, fm)
escribir("MODULACIÓN AM")
escribir("Frecuencia portadora: " .. (fc/1000) .. " kHz")
escribir("Frecuencia máxima de audio: " .. fm .. " Hz")
escribir("Resultado (ancho de banda): " .. am["resultado"] .. " Hz")
escribir("Frecuencia inferior: " .. am["frecuencia_inferior_Hz"] .. " Hz")
escribir("Frecuencia superior: " .. am["frecuencia_superior_Hz"] .. " Hz")
escribir("Fórmula: " .. am["formula"])
# Salida:
# MODULACIÓN AM
# Frecuencia portadora: 1000 kHz
# Frecuencia máxima de audio: 5000 Hz
# Resultado (ancho de banda): 10000 Hz
# Frecuencia inferior: 995000 Hz
# Frecuencia superior: 1005000 Hz
# Fórmula: BW = 2·f_m

# Estación AM con programación musical (15 kHz de audio)
fc_radio = 800e3  # 800 kHz
fm_musica = 15000  # 15 kHz
am_musica = senales.anchoBandaModulacionAM(fc_radio, fm_musica)
escribir("\nRADIO MUSICAL AM")
escribir("Ancho de banda: " .. (am_musica["resultado"] / 1000) .. " kHz")
escribir("Ocupa de " .. (am_musica["frecuencia_inferior_Hz"]/1000) .. " kHz a " .. (am_musica["frecuencia_superior_Hz"]/1000) .. " kHz")
# Salida:
# RADIO MUSICAL AM
# Ancho de banda: 30 kHz
# Ocupa de 785 kHz a 815 kHz
```
