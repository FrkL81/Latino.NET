## 9.18 Plugin `formulas`

### 9.18.17 Librería `hidraulica`

La librería `hidraulica` proporciona funciones esenciales para el análisis de flujo de fluidos en tuberías y canales abiertos, incluyendo la ecuación de Bernoulli, continuidad, número de Froude, y fórmulas empíricas para el cálculo de caudal y pérdidas de carga. Las funciones devuelven diccionarios con los resultados, diagnósticos del régimen de flujo y la fórmula aplicada.

#### 🗝️ Estructura de los Diccionarios de Retorno

| Función | Claves del Diccionario Retornado |
| :--- | :--- |
| **Todas** | `resultado`, `unidad`, `formula` |
| `hidraulica.bernoulli` | `carga_punto_1_m`, `carga_punto_2_m`, `diferencia_carga_m`, `es_ideal` |
| `hidraulica.caudalManning` | `velocidad_media_m_s` |
| `hidraulica.continuidad` | `caudal_m3_s`, `efecto` |
| `hidraulica.darcyWeisbach` | `presion_perdida_Pa` |
| `hidraulica.hazenWilliams` | `material_referencia`, `nota` |
| `hidraulica.numeroFroude` | `regimen` |

#### Referencia de Funciones

| Función | Argumentos | Descripción |
| :--- | :--- | :--- |
| `hidraulica.bernoulli` | `(diccionario_punto1, diccionario_punto2, densidad_kg_m3)` | Verifica la ecuación de Bernoulli entre dos puntos. Cada punto: `{'P','v','z'}`. Fórmula: $H = \frac{P}{\rho g} + \frac{v^2}{2g} + z$ |
| `hidraulica.caudalManning` | `(coef_manning, area_hidraulica_m2, radio_hidraulico_m, pendiente)` | Caudal en canal abierto por la fórmula de Manning. Fórmula: $Q = \frac{1}{n} \cdot A \cdot R^{2/3} \cdot S^{1/2}$ |
| `hidraulica.continuidad` | `(area1_m2, velocidad1_m_s, area2_m2)` | Velocidad en la sección 2 por la ecuación de continuidad (flujo incompresible). Fórmula: $A_1 \cdot v_1 = A_2 \cdot v_2$ |
| `hidraulica.darcyWeisbach` | `(factor_friccion, longitud_m, diametro_m, velocidad_m_s)` | Pérdida de carga por fricción en tuberías (Darcy-Weisbach). Fórmula: $h_f = f \cdot \frac{L}{D} \cdot \frac{v^2}{2g}$ |
| `hidraulica.hazenWilliams` | `(coef_c, radio_hidraulico_m, pendiente)` | Velocidad en tuberías por Hazen-Williams (agua a temperatura normal). Coeficiente C: PVC=150, Acero nuevo=140, Hierro dúctil=130, Hierro fundido=100, Concreto=120. Fórmula: $v = 0.849 \cdot C \cdot R^{0.63} \cdot S^{0.54}$ |
| `hidraulica.numeroFroude` | `(velocidad_m_s, profundidad_hidraulica_m)` | Número de Froude para clasificar el régimen de flujo en canal abierto. Fórmula: $Fr = \frac{v}{\sqrt{g \cdot D}}$ |

🎯 **Ejemplo: hidraulica.bernoulli**

Verifica la ecuación de Bernoulli entre dos puntos de una línea de corriente, calculando la carga hidráulica total y determinando si el flujo es ideal o presenta pérdidas.

```latino
incluir("formulas")

# Tubería horizontal con reducción de diámetro
punto1 = {"P": 200000, "v": 1.5, "z": 2}  # Presión en Pa, velocidad m/s, altura m
punto2 = {"P": 150000, "v": 3.0, "z": 2}  # Misma altura (horizontal)
densidad = 1000  # kg/m³ (agua)

bern = hidraulica.bernoulli(punto1, punto2, densidad)
escribir("ECUACIÓN DE BERNOULLI")
escribir("Carga punto 1: " .. bern["carga_punto_1_m"] .. " m")
escribir("Carga punto 2: " .. bern["carga_punto_2_m"] .. " m")
escribir("Diferencia de carga: " .. bern["diferencia_carga_m"] .. " m")
escribir("¿Flujo ideal?: " .. (bern["es_ideal"] ? "Sí" : "No (hay pérdidas)"))
escribir("Resultado: " .. bern["resultado"] .. " " .. bern["unidad"])
escribir("Fórmula: " .. bern["formula"])
# Salida:
# ECUACIÓN DE BERNOULLI
# Carga punto 1: 22.509042333518583 m
# Carga punto 2: 17.754615490508993 m
# Diferencia de carga: 4.75442684300959 m
# ¿Flujo ideal?: No (hay pérdidas)
# Resultado: 22.509042333518583 m
# Fórmula: H = P/ρg + v²/(2g) + z

# Sistema con cambio de elevación (tubería ascendente)
puntoA = {"P": 180000, "v": 2.0, "z": 0}   # Base
puntoB = {"P": 160000, "v": 2.0, "z": 5}   # 5 m más arriba
bern2 = hidraulica.bernoulli(puntoA, puntoB, 1000)
escribir("\nTUBERÍA ASCENDENTE")
escribir("Carga en A: " .. bern2["carga_punto_1_m"] .. " m")
escribir("Carga en B: " .. bern2["carga_punto_2_m"] .. " m")
escribir("Diferencia: " .. bern2["diferencia_carga_m"] .. " m")
# Salida:
# TUBERÍA ASCENDENTE
# Carga en A: 18.558835076198296 m
# Carga en B: 21.519402650242437 m
# Diferencia: 2.9605675740441413 m

# Flujo ideal sin pérdidas
punto1_ideal = {"P": 100000, "v": 2.0, "z": 10}
punto2_ideal = {"P": 93971.675, "v": 2.5, "z": 10.5}
bern_ideal = hidraulica.bernoulli(punto1_ideal, punto2_ideal, 1000)
escribir("\nFLUJO IDEAL")
escribir("Diferencia: " .. bern_ideal["diferencia_carga_m"] .. " m")
escribir("¿Flujo ideal?: " .. (bern_ideal["es_ideal"] ? "Sí" : "No"))
# Salida:
# FLUJO IDEAL
# Diferencia: 0 m
# ¿Flujo ideal?: Sí
```

> **⚠️ Cómo se eligió `P2 = 93971.675 Pa`.** Para que un flujo sea ideal, la carga total debe ser **idéntica** en ambos puntos: $H_1 = H_2$, donde $H = \frac{P}{\rho g} + \frac{v^2}{2g} + z$.
>
> El motor usa **g = 9.80665 m/s²** (gravedad estándar, no 9.81), y su comprobación de `es_ideal` es **muy estricta**: una diferencia de 0.0001 m ya devuelve `No`.
> Solo da `Sí` cuando la diferencia es cero dentro del error de punto flotante (~1e-15). Por eso el valor no es una cifra redonda: está calculado para igualar las cargas con la máxima precisión.
>
> Con el valor anterior (`P2 = 95000`) la diferencia era de 0.1048 m y el ejemplo se titulaba "flujo ideal sin pérdidas" mientras demostraba lo contrario.

🎯 **Ejemplo: hidraulica.continuidad**

Calcula la velocidad en la sección 2 de un conducto utilizando la ecuación de continuidad para flujo incompresible, incluyendo una descripción del efecto Venturi.

```latino
incluir("formulas")

# Tubería que se reduce de 0.1 m² a 0.05 m² con velocidad inicial 2 m/s
a1 = 0.1
v1 = 2.0
a2 = 0.05

cont = hidraulica.continuidad(a1, v1, a2)
escribir("ECUACIÓN DE CONTINUIDAD")
escribir("Área 1: " .. a1 .. " m²")
escribir("Velocidad 1: " .. v1 .. " m/s")
escribir("Área 2: " .. a2 .. " m²")
escribir("Resultado (velocidad 2): " .. cont["resultado"] .. " " .. cont["unidad"])
escribir("Caudal: " .. cont["caudal_m3_s"] .. " m³/s")
escribir("Efecto: " .. cont["efecto"])
escribir("Fórmula: " .. cont["formula"])
# Salida:
# ECUACIÓN DE CONTINUIDAD
# Área 1: 0.1 m²
# Velocidad 1: 2 m/s
# Área 2: 0.05 m²
# Resultado (velocidad 2): 4 m/s
# Caudal: 0.2 m³/s
# Efecto: Sección menor → velocidad aumenta (efecto Venturi)
# Fórmula: A₁·v₁ = A₂·v₂

# Sistema de derivación
a_principal = 0.2
v_principal = 1.5
a_rama = 0.08
cont_rama = hidraulica.continuidad(a_principal, v_principal, a_rama)
escribir("\nDERIVACIÓN")
escribir("Velocidad en rama: " .. cont_rama["resultado"] .. " m/s")
escribir(cont_rama["efecto"])
# Salida:
# DERIVACIÓN
# Velocidad en rama: 3.7500000000000004 m/s
# Efecto Venturi: Sección menor → velocidad aumenta (efecto Venturi)
```

🎯 **Ejemplo: hidraulica.numeroFroude**

Calcula el número de Froude y clasifica el régimen de flujo en canales abiertos (subcrítico, crítico o supercrítico).

```latino
incluir("formulas")

# Canal con velocidad 1.5 m/s y profundidad 2 m
velocidad = 1.5
profundidad = 2.0

fr = hidraulica.numeroFroude(velocidad, profundidad)
escribir("NÚMERO DE FROUDE")
escribir("Velocidad: " .. velocidad .. " m/s")
escribir("Profundidad hidráulica: " .. profundidad .. " m")
escribir("Resultado: " .. fr["resultado"])
escribir("Régimen: " .. fr["regimen"])
escribir("Unidad: " .. fr["unidad"])
escribir("Fórmula: " .. fr["formula"])
# Salida:
# NÚMERO DE FROUDE
# Velocidad: 1.5 m/s
# Profundidad hidráulica: 2 m
# Resultado: 0.338
# Régimen: Subcrítico (Fr < 1)
# Unidad: adimensional
# Fórmula: Fr = v / √(g·D)

# Flujo rápido en canal de montaña
fr_rapido = hidraulica.numeroFroude(5.0, 0.8)
escribir("\nCANAL DE MONTAÑA")
escribir("Fr = " .. fr_rapido["resultado"])
escribir("Régimen: " .. fr_rapido["regimen"])
# Salida:
# CANAL DE MONTAÑA
# Fr = 1.78
# Régimen: Supercrítico (rápido) — ondas NO se propagan aguas arriba

# Límite del ejemplo: Fr apenas supera 1, así que el motor lo clasifica como SUPERCRÍTICO
fr_critico = hidraulica.numeroFroude(3.132, 1.0)
escribir("\nFLUJO CRÍTICO")
escribir("Fr = " .. fr_critico["resultado"])
escribir("Régimen: " .. fr_critico["regimen"])
# Salida:
# FLUJO CRÍTICO
# Fr = 1.000141424638276
# Régimen: Supercrítico (rápido) — ondas NO se propagan aguas arriba
```

🎯 **Ejemplo: hidraulica.caudalManning**

Calcula el caudal en un canal abierto utilizando la fórmula de Manning, ampliamente usada en hidráulica de canales, incluyendo la velocidad media del flujo.

```latino
incluir("formulas")

# Canal rectangular revestido de concreto
n = 0.015  # Coeficiente de Manning para concreto
area = 4.0  # m² (ancho 2m × profundidad 2m)
radio = 0.8  # m (radio hidráulico)
pendiente = 0.001  # 0.1%

manning = hidraulica.caudalManning(n, area, radio, pendiente)
escribir("FÓRMULA DE MANNING")
escribir("Coef. Manning (n): " .. n)
escribir("Área hidráulica: " .. area .. " m²")
escribir("Radio hidráulico: " .. radio .. " m")
escribir("Pendiente: " .. pendiente)
escribir("Resultado (caudal): " .. manning["resultado"] .. " " .. manning["unidad"])
escribir("Velocidad media: " .. manning["velocidad_media_m_s"] .. " m/s")
escribir("Fórmula: " .. manning["formula"])
# Salida:
# FÓRMULA DE MANNING
# Coef. Manning (n): 0.015
# Área hidráulica: 4 m²
# Radio hidráulico: 0.8 m
# Pendiente: 0.001
# Resultado (caudal): 7.267115403284921 m³/s
# Velocidad media: 1.8167788508212301 m/s
# Fórmula: Q = (1/n)·A·R^(2/3)·S^(1/2)

# Comparar diferentes materiales
materiales = [
    {"nombre": "PVC liso", "n": 0.009},
    {"nombre": "Concreto", "n": 0.015},
    {"nombre": "Tierra", "n": 0.025},
    {"nombre": "Ripio", "n": 0.035}
]

escribir("\nCOMPARACIÓN DE MATERIALES (misma geometría)")
para mat en materiales
    q = hidraulica.caudalManning(mat["n"], 4.0, 0.8, 0.001)
    escribir(mat["nombre"] .. ": Q=" .. q["resultado"] .. " m³/s, v=" .. q["velocidad_media_m_s"] .. " m/s")
fin
# Salida:
# COMPARACIÓN DE MATERIALES (misma geometría)
# PVC liso: Q=12.111859005474868 m³/s, v=3.027964751368717 m/s
# Concreto: Q=7.267115403284921 m³/s, v=1.8167788508212301 m/s
# Tierra: Q=4.360269241970952 m³/s, v=1.090067310492738 m/s
# Ripio: Q=3.1144780299792516 m³/s, v=0.7786195074948129 m/s
```

🎯 **Ejemplo: hidraulica.darcyWeisbach**

Calcula la pérdida de carga por fricción en tuberías utilizando la ecuación de Darcy-Weisbach, incluyendo la pérdida de presión en pascales.

```latino
incluir("formulas")

# Tubería de acero de 100 m, diámetro 0.2 m, velocidad 2 m/s
f = 0.02  # factor de fricción (depende de Reynolds y rugosidad)
l = 100
d = 0.2
v = 2.0

dw = hidraulica.darcyWeisbach(f, l, d, v)
escribir("DARCY-WEISBACH")
escribir("Factor de fricción (f): " .. f)
escribir("Longitud: " .. l .. " m")
escribir("Diámetro: " .. d .. " m")
escribir("Velocidad: " .. v .. " m/s")
escribir("Resultado (pérdida de carga): " .. dw["resultado"] .. " " .. dw["unidad"])
escribir("Pérdida de presión: " .. dw["presion_perdida_Pa"] .. " Pa")
escribir("Fórmula: " .. dw["formula"])
# Salida:
# DARCY-WEISBACH
# Factor de fricción (f): 0.02
# Longitud: 100 m
# Diámetro: 0.2 m
# Velocidad: 2 m/s
# Resultado (pérdida de carga): 2.04 m
# Pérdida de presión: 20000 Pa
# Fórmula: h_f = f·(L/D)·v²/(2g)

# Comparar diferentes diámetros
diametros = [0.1, 0.15, 0.2, 0.25, 0.3]

escribir("\nPÉRDIDA VS DIÁMETRO (L=100m, v=2m/s, f=0.02)")
para diam en diametros
    res = hidraulica.darcyWeisbach(0.02, 100, diam, 2.0)
    escribir("D=" .. diam .. " m → hf=" .. res["resultado"] .. " m, ΔP=" .. res["presion_perdida_Pa"] .. " Pa")
fin
# Salida:
# PÉRDIDA VS DIÁMETRO (L=100m, v=2m/s, f=0.02)
# D=0.1 m → hf=4.08 m, ΔP=40000 Pa
# D=0.15 m → hf=2.72 m, ΔP=26666.67 Pa
# D=0.2 m → hf=2.04 m, ΔP=20000 Pa
# D=0.25 m → hf=1.63 m, ΔP=16000 Pa
# D=0.3 m → hf=1.36 m, ΔP=13333.33 Pa
```

🎯 **Ejemplo: hidraulica.hazenWilliams**

Calcula la velocidad del agua en tuberías utilizando la fórmula empírica de Hazen-Williams, incluyendo referencia del material y notas sobre su aplicabilidad.

```latino
incluir("formulas")

# Tubería de PVC (C=150), radio hidráulico 0.05 m, pendiente 0.005
c = 150  # PVC
r = 0.05  # radio hidráulico (para tubería circular, R = D/4)
s = 0.005  # pendiente

hw = hidraulica.hazenWilliams(c, r, s)
escribir("HAZEN-WILLIAMS")
escribir("Coeficiente C: " .. c)
escribir("Radio hidráulico: " .. r .. " m")
escribir("Pendiente: " .. s)
escribir("Resultado (velocidad): " .. hw["resultado"] .. " " .. hw["unidad"])
escribir("Material de referencia: " .. hw["material_referencia"])
escribir("Nota: " .. hw["nota"])
escribir("Fórmula: " .. hw["formula"])
# Salida:
# HAZEN-WILLIAMS
# Coeficiente C: 150
# Radio hidráulico: 0.05 m
# Pendiente: 0.005
# Resultado (velocidad): 1.1035546736393453 m/s
# Material de referencia: Plástico / PVC (excelente)
# Nota: Válida solo para agua a 15-25°C. Usa Darcy-Weisbach para otros fluidos.
# Fórmula: v = 0.849 · C · R^0.63 · S^0.54

# Comparar diferentes materiales (coeficientes C)
materiales_hw = [
    {"c": 150, "nombre": "PVC"},
    {"c": 140, "nombre": "Acero nuevo"},
    {"c": 130, "nombre": "Hierro dúctil"},
    {"c": 120, "nombre": "Concreto"},
    {"c": 100, "nombre": "Hierro fundido"}
]

escribir("\nCOMPARACIÓN DE MATERIALES (misma geometría)")
para mat en materiales_hw
    res = hidraulica.hazenWilliams(mat["c"], 0.05, 0.005)
    escribir(mat["nombre"] .. ": v=" .. res["resultado"] .. " m/s (" .. res["material_referencia"] .. ")")
fin
# Salida:
# COMPARACIÓN DE MATERIALES (misma geometría)
# PVC: v=1.1035546736393453 m/s (Plástico / PVC (excelente))
# Acero nuevo: v=1.0299843620633888 m/s (Acero nuevo o hierro dúctil (muy bueno))
# Hierro dúctil: v=0.9564140504874324 m/s (Acero nuevo o hierro dúctil (muy bueno))
# Concreto: v=0.8828437389114762 m/s (Concreto liso / hierro galvanizado (bueno))
# Hierro fundido: v=0.7357031157595634 m/s (Hierro fundido envejecido (aceptable))

# Calcular para diferentes diámetros (tubería circular)
diametros = [0.05, 0.1, 0.2, 0.3, 0.5]  # metros

escribir("\nVELOCIDAD VS DIÁMETRO (PVC, S=0.005)")
para d2 en diametros
    radio_h = d2 / 4  # para tubería circular llena
    res = hidraulica.hazenWilliams(150, radio_h, 0.005)
    area = (3.14159 * d2^2) / 4
    q = res["resultado"] * area
    escribir("D=" .. (d2*1000) .. " mm → v=" .. res["resultado"] .. " m/s, Q=" .. q .. " m³/s")
fin
# Salida:
# VELOCIDAD VS DIÁMETRO (PVC, S=0.005)
# D=50 mm → v=0.4607825881924669 m/s, Q=0.0009047437320247327 m³/s
# D=100 mm → v=0.7130910031205208 m/s, Q=0.005600598911233492 m³/s
# D=200 mm → v=1.1035546736393453 m/s, Q=0.03466916327158631 m³/s
# D=300 mm → v=1.4247259924889868 m/s, Q=0.1007078609417282 m³/s
# D=500 mm → v=1.9656041474329498 m/s, Q=0.38594514584586753 m³/s
```
