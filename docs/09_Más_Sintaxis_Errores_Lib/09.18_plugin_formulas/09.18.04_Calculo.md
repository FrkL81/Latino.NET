## 9.18 Plugin `formulas`

### 9.18.04 Librería `calculo`

La librería `calculo` proporciona métodos numéricos para integración, derivación y análisis de funciones. Incluye desde métodos clásicos como Simpson y Trapecio hasta técnicas avanzadas como cuadratura Gaussiana, extrapolación de Richardson y cálculo de gradientes y matrices jacobianas.

#### 🗝️ Estructura de los Diccionarios de Retorno

La librería `calculo` agrupa funciones de naturalezas muy distintas. Dependiendo de si calculas una integral escalar, un vector o una matriz, la clave principal del resultado cambiará.

Todas las funciones incluyen la clave `"formula"`. Las claves de los valores numéricos son:

| Tipo de Operación | Función | Clave Principal | Claves Opcionales / Diagnóstico |
| :--- | :--- | :--- | :--- |
| **Integrales (1D)** | `trapecio`, `simpson13`, `simpson38`, `cuadraturaGauss`, `monteCarlo`, `longitudArco` | `"resultado"` | `"errorEstimado"` (Monte Carlo), `"nSubintervalos"` |
| **Integrales Adaptativas** | `romberg` | `"resultado"` | `"errorEstimado"`, `"nivelesUsados"`, `"convergio"` |
| **Derivadas (1D)** | `derivada`, `segundaDerivada`, `derivadaRichardson` | `"resultado"` | `"errorEstimado"`, `"nivelesUsados"`, `"ordenError"` |
| **Vectores (ND)** | `gradiente` | **`"gradiente"`** | `"norma"` (del vector resultante), `"nVariables"` |
| **Matrices (ND)** | `jacobiana` | **`"jacobiana"`** | `"filas_m"`, `"columnas_n"`, `"h_usado"` |

#### Referencia de Funciones

| Función | Argumentos | Descripción |
| :--- | :--- | :--- |
| `calculo.cuadraturaGauss` | `(funcion, a, b, [puntos])` | Integración numérica por Cuadratura de Gauss-Legendre. |
| `calculo.derivadaRichardson` | `(funcion, x, [h], [niveles])` | Aproxima f'(x) con alta precisión usando Extrapolación de Richardson. |
| `calculo.derivada` | `(funcion, x, [h], [orden])` | Aproxima la primera derivada f'(x) por Diferencias Finitas. |
| `calculo.gradiente` | `(funcionNVar, listaPunto, [h])` | Calcula el gradiente numérico ∇f en un punto dado. |
| `calculo.jacobiana` | `(funcionVectorial, listaX, [h])` | Calcula la matriz Jacobiana J de una función vectorial F: ℝⁿ → ℝᵐ en el punto X. |
| `calculo.longitudArco` | `(funcion, a, b, n)` | Calcula la longitud de arco de y = f(x) en [a, b] numéricamente. |
| `calculo.monteCarlo` | `(funcion, a, b, nMuestras, [semilla])` | Estimación de ∫ₐᵇ f(x)dx por el Método de Monte Carlo. |
| `calculo.romberg` | `(funcion, a, b, [maxNivel], [tolerancia])` | Integración numérica por el Método de Romberg. |
| `calculo.segundaDerivada` | `(funcion, x, [h])` | Aproxima la segunda derivada f''(x) por Diferencias Finitas Centrales. |
| `calculo.simpson13` | `(funcion, a, b, n)` | Regla de Simpson 1/3 compuesta. Integra f(x) en [a, b]. |
| `calculo.simpson38` | `(funcion, a, b, n)` | Regla de Simpson 3/8 compuesta. Integra f(x) en [a, b]. |
| `calculo.trapecio` | `(funcion, a, b, n)` | Integración numérica por la Regla del Trapecio Compuesta. |

🎯 **Ejemplo: Integración numérica con la regla del trapecio en calculo.trapecio**

Aproxima la integral definida $\int_a^b f(x) \, dx$ mediante la regla del trapecio compuesta, dividiendo el intervalo en $n$ subintervalos.

```latino
incluir("formulas")

# Integral de x² en [0,1] (resultado exacto: 1/3 ≈ 0.33333)
f_cuadrado = fun(x) ret x^2 fin

res = calculo.trapecio(f_cuadrado, 0, 1, 100)
escribir("∫ x² dx ≈ " .. res["resultado"])
# Salida: ∫ x² dx ≈ 0.33335
```

🎯 **Ejemplo: calculo.simpson13**

Aproxima la integral definida $\int_a^b f(x) \, dx$ mediante la regla de Simpson 1/3 compuesta. El número de subintervalos $n$ debe ser par.

```latino
incluir("formulas")

# Integral de sen(x) en [0, π] (resultado exacto: 2)

```

🎯 **Ejemplo: calculo.cuadraturaGauss**

Aproxima la integral definida $\int_a^b f(x) \, dx$ mediante cuadratura de Gauss-Legendre. El parámetro `puntos` solo acepta los valores 2, 3, 4 o 5.

```latino
incluir("formulas")

# Integral de 1/(1+x²) en [0,1] (arctan(1) = π/4 ≈ 0.785398)
f_arctan = fun(x) ret 1 / (1 + x^2) fin

# Con 2 puntos (menor precisión)
res2 = calculo.cuadraturaGauss(f_arctan, 0, 1, 2)
escribir("Gauss-2: " .. res2["resultado"])
# Salida: Gauss-2: 0.785267

# Con 5 puntos (máxima precisión)
res5 = calculo.cuadraturaGauss(f_arctan, 0, 1, 5)
escribir("Gauss-5: " .. res5["resultado"])
# Salida: Gauss-5: 0.785398
```

🎯 **Ejemplo: calculo.monteCarlo**

Estima la integral definida $\int_a^b f(x) \, dx$ mediante el método de Monte Carlo. Retorna el valor estimado y su error estadístico.

```latino
incluir("formulas")

# Integral de √(1-x²) en [-1,1] (área de semicírculo = π/2 ≈ 1.5708)
f_circulo = fun(x) ret mate.raiz(1 - x^2) fin

res = calculo.monteCarlo(f_circulo, -1, 1, 10000, 12345)
escribir("Monte Carlo: " .. res["resultado"] .. " ± " .. res["errorEstimado"])
# Salida: Monte Carlo: 1.5702 ± 0.0087
```

🎯 **Ejemplo: calculo.gradiente**

Calcula el gradiente numérico $\nabla f$ de una función de varias variables en un punto dado. La función debe recibir una lista con las coordenadas.

```latino
incluir("formulas")

# Función: f(x,y) = x² + y² (gradiente: [2x, 2y])
f_grad = fun(p)
    retornar p[0]^2 + p[1]^2  # Índices base 0
fin

res = calculo.gradiente(f_grad, [1, 2])
escribir("∇f(1,2) = " .. res["gradiente"])
# Salida: ∇f(1,2) = [2.0001, 4.0001]
```

🎯 **Ejemplo: calculo.jacobiana**

Calcula la matriz Jacobiana $J$ de una función vectorial $F: \mathbb{R}^n \to \mathbb{R}^m$ en un punto dado. La función debe recibir una lista y retornar una lista con los valores de cada componente.

```latino
incluir("formulas")

# Función vectorial: F(x,y) = [x² + y, x·y]
f_jac = fun(v)
    retornar [
        v[0]^2 + v[1],  # F₁
        v[0] * v[1]      # F₂
    ]
fin

res = calculo.jacobiana(f_jac, [1, 2])
escribir("Jacobiana: " .. res["jacobiana"])
# Salida: Jacobiana: [[2.0000000000131024, 1.0000000000065512], [2.000000000002, 1.0000000000065512]]
# (La jacobiana se calcula por diferencias finitas, así que los valores
#  aproximan los exactos 2 y 1 con una desviación de orden 1e-12.)
```

🎯 **Ejemplo: calculo.longitudArco**

Calcula la longitud de arco de una curva $y = f(x)$ en el intervalo $[a, b]$ mediante la fórmula $L = \int_a^b \sqrt{1 + [f'(x)]^2} \, dx$.

```latino
incluir("formulas")

# Longitud de arco de f(x) = x^(3/2) en el intervalo [1, 4]
# Arrancamos en 1 para evitar la singularidad de dominio en x=0
f_arco = fun(x) ret x^(3/2) fin

res = calculo.longitudArco(f_arco, 1, 4, 100)
escribir("Longitud: " .. res["resultado"]) # Salida: Longitud: 7.6337
escribir("Fórmula: " .. res["formula"])    # Salida: Fórmula: L = ∫√(1 + [f'(x)]²) dx
```
