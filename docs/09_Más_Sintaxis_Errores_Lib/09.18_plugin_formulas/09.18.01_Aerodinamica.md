# Capítulo: 09_Más_Sintaxis_Errores_Lib

## 9.18 Plugin `formulas`

### 9.18.01 Librería `aerodinamica`

#### Referencia de Funciones

| Función | Argumentos | Descripción |
| :--- | :--- | :--- |
| `aerodinamica.numeroMach` | `(velocidadObjeto, velocidadSonido)` | Calcula el Número de Mach y el régimen de vuelo.\n\nFórmula: M = v / c |

🎯 **Ejemplo: Cálculo del Número de Mach y régimen de vuelo con aerodinamica.numeroMach**

Calcula el Número de Mach para determinar el régimen de vuelo (subsónico, sónico, etc.) basándose en la velocidad del objeto y la velocidad del sonido local.

```latino
incluir("formulas")

# Calcula el Número de Mach y el régimen de vuelo para un objeto a 340 m/s
v_avion = 340
v_sonido = 340
res = aerodinamica.numeroMach(v_avion, v_sonido)

escribir(res["resultado"])      # Salida: 1
escribir(res["unidad"])         # Salida: Mach
escribir(res["regimen_vuelo"])  # Salida: Transónico
escribir(res["formula"])        # Salida: M = v / c
```
