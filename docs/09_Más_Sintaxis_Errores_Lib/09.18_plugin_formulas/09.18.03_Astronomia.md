## 9.18 Plugin `formulas`

### 9.18.03 Librería `astronomia`

La librería `astronomia` proporciona funciones para cálculos fundamentales de mecánica celeste y astrofísica. Incluye desde la fuerza gravitacional entre cuerpos hasta la determinación de distancias estelares mediante paralaje. Todas las funciones devuelven diccionarios con el resultado, la unidad correspondiente y la fórmula aplicada.

#### Referencia de Funciones

| Función | Argumentos | Descripción |
| :--- | :--- | :--- |
| `astronomia.distanciaParalaje` | `(paralajeArcsec)` | Distancia a una estrella basada en su ángulo de paralaje. Fórmula: $d = \frac{1}{p}$ (p en segundos de arco) |
| `astronomia.fuerzaGravitacional` | `(masa1, masa2, distancia)` | Fuerza de atracción gravitacional entre dos cuerpos. Fórmula: $F = G\frac{m_1 m_2}{r^2}$ |
| `astronomia.keplerTercera` | `(diccionarioVariables)` | Tercera Ley de Kepler. Pasa 2 de: 'T' (periodo en s), 'a' (semieje en m), 'M' (masa central en kg). Fórmula: $T^2 = \frac{4\pi^2}{GM} a^3$ |
| `astronomia.velocidadEscape` | `(masaCuerpo, radio)` | Calcula la velocidad de escape. Fórmula: $v_e = \sqrt{\frac{2GM}{r}}$ |

🎯 **Ejemplo: Cálculo de velocidad de escape con astronomia.velocidadEscape**

Calcula la velocidad mínima necesaria para que un objeto escape del campo gravitacional de un cuerpo celeste.

```latino
incluir("formulas")

# Velocidad de escape de la Tierra
masa_tierra = 5.972e24    # kg
radio_tierra = 6.371e6    # metros

escape_tierra = astronomia.velocidadEscape(masa_tierra, radio_tierra)
escribir("Tierra: " .. escape_tierra["resultado"] .. " " .. escape_tierra["unidad"])
# Salida: Tierra: 11186.0 m/s

# Velocidad de escape de la Luna
masa_luna = 7.348e22      # kg
radio_luna = 1.737e6      # metros

escape_luna = astronomia.velocidadEscape(masa_luna, radio_luna)
escribir("Luna: " .. escape_luna["resultado"] .. " " .. escape_luna["unidad"])
# Salida: Luna: 2375.3 m/s
```

🎯 **Ejemplo: astronomia.fuerzaGravitacional**

Calcula la fuerza de atracción gravitacional entre dos cuerpos celestes según la ley de gravitación universal.

```latino
incluir("formulas")

# Fuerza entre la Tierra y la Luna
masa_tierra = 5.972e24        # kg
masa_luna = 7.348e22          # kg
distancia_tierra_luna = 3.844e8  # metros

f_tierra_luna = astronomia.fuerzaGravitacional(masa_tierra, masa_luna, distancia_tierra_luna)
escribir("Fuerza Tierra-Luna: " .. f_tierra_luna["resultado"] .. " " .. f_tierra_luna["unidad"])
# Salida: Fuerza Tierra-Luna: 1.982e20 N

# Fuerza entre dos personas (ejemplo didáctico)
f_personas = astronomia.fuerzaGravitacional(70, 70, 1)
escribir("Fuerza entre personas: " .. f_personas["resultado"] .. " " .. f_personas["unidad"])
# Salida: Fuerza entre personas: 3.27e-7 N
```

🎯 **Ejemplo: astronomia.distanciaParalaje**

Calcula la distancia a una estrella a partir de su ángulo de paralaje anual. El resultado se obtiene en pársecs.

```latino
incluir("formulas")

# Próxima Centauri (paralaje conocido)
paralaje_proxima = 0.7685  # segundos de arco

distancia_proxima = astronomia.distanciaParalaje(paralaje_proxima)
escribir("Próxima Centauri: " .. distancia_proxima["resultado"] .. " " .. distancia_proxima["unidad"])
# Salida: Próxima Centauri: 1.301 parsecs

# Conversión a años luz (1 parsec ≈ 3.26 años luz)
anios_luz = distancia_proxima["resultado"] * 3.26
escribir("Próxima Centauri: " .. anios_luz .. " años luz")
# Salida: Próxima Centauri: 4.24 años luz

# Estrella muy lejana
distancia_lejana = astronomia.distanciaParalaje(0.001)
escribir("Estrella lejana: " .. distancia_lejana["resultado"] .. " parsecs")
# Salida: Estrella lejana: 1000 parsecs
```

🎯 **Ejemplo: astronomia.keplerTercera**

Función omni-solver que aplica la tercera ley de Kepler. A partir de dos variables conocidas (período T, semieje a o masa central M), calcula la tercera.

```latino
incluir("formulas")

# Constantes útiles
constantes = formulas.constantes()
radio_tierra = 6.371e6      # metros
masa_tierra = 5.972e24      # kg

# --- CASO 1: Calcular período orbital (T) conociendo a y M ---
# Satélite a 400 km sobre la Tierra
radio_orbita = radio_tierra + 400000  # metros

datos1 = {
    "a": radio_orbita,
    "M": masa_tierra
}

res1 = astronomia.keplerTercera(datos1)
escribir("Período orbital: " .. res1["resultado"] .. " " .. res1["unidad"])
# Salida: Período orbital: 5544 s

minutos = res1["resultado"] / 60
escribir("Equivalente: " .. minutos .. " minutos")
# Salida: Equivalente: 92.4 minutos

# --- CASO 2: Calcular distancia orbital (a) conociendo T y M ---
# Satélite geoestacionario (T = 24 horas)
periodo_geo = 24 * 3600  # segundos

datos2 = {
    "T": periodo_geo,
    "M": masa_tierra
}

res2 = astronomia.keplerTercera(datos2)
escribir("Radio órbita geoestacionaria: " .. res2["resultado"] .. " " .. res2["unidad"])
# Salida: Radio órbita geoestacionaria: 42164000 m

altura_geo = (res2["resultado"] - radio_tierra) / 1000
escribir("Altura sobre Tierra: " .. altura_geo .. " km")
# Salida: Altura sobre Tierra: 35786 km

# --- CASO 3: Calcular masa central (M) conociendo T y a ---
# Sistema Tierra-Luna
periodo_lunar = 27.3 * 24 * 3600  # segundos
distancia_lunar = 3.844e8          # metros

datos3 = {
    "T": periodo_lunar,
    "a": distancia_lunar
}

res3 = astronomia.keplerTercera(datos3)
escribir("Masa Tierra: " .. res3["resultado"] .. " " .. res3["unidad"])
# Salida: Masa Tierra: 5.97e24 kg
```
