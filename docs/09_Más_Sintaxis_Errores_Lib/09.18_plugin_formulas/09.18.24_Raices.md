## 9.18 Plugin `formulas`

### 9.18.24 Librería `raices`

La librería `raices` proporciona una colección de métodos numéricos para encontrar raíces (ceros) de funciones en una variable. Incluye algoritmos desde bisección (robusto pero lento) hasta Brent (rápido y robusto), así como métodos para punto fijo y detección de intervalos. Todas las funciones devuelven diccionarios con el resultado, diagnóstico de convergencia y la fórmula o método aplicado.

#### 🗝️ Estructura de los Diccionarios de Retorno

| Función | Claves del Diccionario Retornado |
| :--- | :--- |
| **Todas** | `resultado`, `unidad`, `formula` |
| `raices.biseccion` | `convergio`, `iteraciones`, `error_estimado`, `advertencia` |
| `raices.brent` | `convergio`, `iteraciones`, `error_estimado`, `f_en_raiz`, `advertencia` |
| `raices.buscarIntervalos` | `intervalos`, `num_raices_posibles`, `nota` |
| `raices.newtonRaphson` | `convergio`, `iteraciones`, `error_estimado`, `advertencia` |
| `raices.puntoFijo` | `convergio`, `iteraciones`, `error_estimado`, `advertencia` |
| `raices.regulaFalsi` | `convergio`, `iteraciones`, `error_estimado`, `advertencia` |
| `raices.secante` | `convergio`, `iteraciones`, `error_estimado`, `advertencia` |

#### Referencia de Funciones

| Función | Argumentos | Descripción |
| :--- | :--- | :--- |
| `raices.biseccion` | `(funcion, a, b, [tolerancia], [maxIter])` | Encuentra una raíz de f(x) en el intervalo [a, b] por el método de Bisección. |
| `raices.brent` | `(funcion, a, b, [tolerancia], [maxIter])` | Encuentra una raíz de f(x) en [a, b] por el método de Brent. |
| `raices.buscarIntervalos` | `(funcion, a, b, numSubintervalos)` | Escanea [a, b] dividiendo en N subintervalos y detecta dónde f cambia de signo. |
| `raices.newtonRaphson` | `(funcionF, funcionDf, x0, [tolerancia], [maxIter])` | Encuentra una raíz de f(x) por el método de Newton-Raphson. |
| `raices.puntoFijo` | `(funcionG, x0, [tolerancia], [maxIter])` | Calcula un punto fijo x' tal que g(x') = x', por iteración x_{n+1} = g(x_n). |
| `raices.regulaFalsi` | `(funcion, a, b, [tolerancia], [maxIter])` | Encuentra una raíz de f(x) en [a, b] por el método de Regula Falsi. |
| `raices.secante` | `(funcion, x0, x1, [tolerancia], [maxIter])` | Encuentra una raíz de f(x) por el método de la Secante. |

🎯 **Ejemplo: raices.biseccion**

Método de bisección: divide repetidamente el intervalo a la mitad y selecciona el subintervalo donde ocurre el cambio de signo. Robusto pero relativamente lento.

```latino
incluir("formulas")

# Encontrar raíz de f(x) = x² - 2 en [1, 2] (raíz = √2 ≈ 1.4142)
funcion f(x)
    retornar x^2 - 2
fin

a = 1
b = 2
tol = 1e-8

raiz = raices.biseccion(f, a, b, tol)
escribir("BISECCIÓN")
escribir("Intervalo inicial: [" .. a .. ", " .. b .. "]")
escribir("Raíz encontrada: " .. raiz["resultado"])
escribir("Valor f(raíz): " .. f(raiz["resultado"]))
escribir("Convergió: " .. (raiz["convergio"] ? "Sí" : "No"))
escribir("Iteraciones: " .. raiz["iteraciones"])
escribir("Error estimado: " .. raiz["error_estimado"])
escribir("Fórmula: " .. raiz["formula"])

# Caso sin cambio de signo (no hay raíz) - CON VALIDACIÓN
funcion g(x)
    retornar x^2 + 1  # siempre positiva
fin

a2 = -1
b2 = 1

# 🔍 Verificar cambio de signo ANTES de llamar al método
si g(a2) * g(b2) > 0
    escribir("\nSIN CAMBIO DE SIGNO")
    escribir("Advertencia: La función no cambia de signo en el intervalo [" .. a2 .. ", " .. b2 .. "]")
    escribir("g(" .. a2 .. ") = " .. g(a2) .. ", g(" .. b2 .. ") = " .. g(b2))
sino
    raiz_err = raices.biseccion(g, a2, b2, tol)
    escribir("\nRaíz encontrada: " .. raiz_err["resultado"])
fin
```

🎯 **Ejemplo: raices.newtonRaphson**

Método de Newton-Raphson: utiliza la derivada para converger cuadráticamente. Muy rápido pero requiere derivada y buena aproximación inicial.

```latino
incluir("formulas")

# Encontrar raíz de f(x) = x² - 2, f'(x) = 2x
funcion f(x)
    retornar x^2 - 2
fin

funcion df(x)
    retornar 2*x
fin

x0 = 1.5
tol = 1e-10

raiz = raices.newtonRaphson(f, df, x0, tol)
escribir("NEWTON-RAPHSON")
escribir("Aproximación inicial: " .. x0)
escribir("Raíz encontrada: " .. raiz["resultado"])
escribir("Valor f(raíz): " .. f(raiz["resultado"]))
escribir("Convergió: " .. (raiz["convergio"] ? "Sí" : "No"))
escribir("Iteraciones: " .. raiz["iteraciones"])
escribir("Error estimado: " .. raiz["error_estimado"])
# Salida:
# NEWTON-RAPHSON
# Aproximación inicial: 1.5
# Raíz encontrada: 1.414213562373095
# Valor f(raíz): 2.2e-16
# Convergió: Sí
# Iteraciones: 4
# Error estimado: 7.1e-13

# Punto donde derivada es cero (falla)
funcion f_cero(x)
    retornar (x-1)^2  # raíz en x=1, derivada 2(x-1) que es 0 en la raíz
fin

funcion df_cero(x)
    retornar 2*(x-1)
fin

raiz_cero = raices.newtonRaphson(f_cero, df_cero, 0.5)
escribir("\nDERIVADA CERO EN RAÍZ")
escribir("Converge: " .. raiz_cero["convergio"])
# Salida:
# DERIVADA CERO EN RAÍZ
# Converge: cierto
```

🎯 **Ejemplo: raices.secante**

Método de la secante: aproxima la derivada usando diferencias finitas. No requiere derivada analítica y tiene buena velocidad de convergencia.

```latino
incluir("formulas")

# 🔹 Función didáctica: f(x) = x² - 2 → raíz en √2 ≈ 1.41421356
funcion f(x)
    retornar x^2 - 2
fin

# Aproximaciones iniciales: f(1) = -1, f(2) = 2 → hay cambio de signo ✅
x0 = 1
x1 = 2
tol = 1e-8

raiz = raices.secante(f, x0, x1, tol)

escribir("📐 MÉTODO DE LA SECANTE")
escribir("════════════════════════════")
escribir("Función: f(x) = x² - 2")
escribir("Raíz exacta conocida: √2 ≈ 1.41421356237")
escribir("")
escribir("Aproximaciones iniciales:")
escribir("  x₀ = " .. x0 .. " → f(x₀) = " .. f(x0))
escribir("  x₁ = " .. x1 .. " → f(x₁) = " .. f(x1))
escribir("")
escribir("Resultados:")
escribir("  Raíz encontrada: " .. raiz["resultado"])
escribir("  Error vs. √2: " .. mate.abs(raiz["resultado"] - mate.raiz(2)))
escribir("  Valor f(raíz): " .. f(raiz["resultado"]))
escribir("  Convergió: " .. (raiz["convergio"] ? "✅ Sí" : "❌ No"))
escribir("  Iteraciones: " .. raiz["iteraciones"])
escribir("  Error estimado: " .. raiz["error_estimado"])

# 🔹 Comparación conceptual con Newton
escribir("")
escribir("💡 Ventaja del método de la secante:")
escribir("   • No requiere calcular la derivada f'(x)")
escribir("   • Útil cuando f'(x) es compleja o costosa")
escribir("   • Convergencia casi cuadrática (~1.618)")
escribir("")
escribir("⚠️  Nota: Convergencia no garantizada si:")
escribir("   • Las aproximaciones iniciales están muy lejos de la raíz")
escribir("   • f'(x) ≈ 0 cerca de las iteraciones (denominador pequeño)")
```

🎯 **Ejemplo: raices.brent**

Método de Brent: combina bisección, secante e interpolación cuadrática inversa. Es el método recomendado para encontrar raíces en una variable por su robustez y velocidad.

```latino
incluir("formulas")

# 🔹 Función: f(x) = e^x - 3x (tiene dos raíces reales)
funcion f(x)
    retornar mate.exp(x) - 3*x
fin

# 🎯 Encontrar PRIMERA raíz en [0, 1] donde f(0)>0 y f(1)<0 ✅
a = 0
b = 1
tol = 1e-12

# Verificación pedagógica previa
escribir("🔍 Validación de intervalo:")
escribir("  f(" .. a .. ") = " .. f(a))
escribir("  f(" .. b .. ") = " .. f(b))
escribir("  ¿Cambio de signo? " .. (f(a)*f(b) < 0 ? "✅ Sí" : "❌ No"))
escribir("")

si f(a) * f(b) >= 0
    escribir("⚠️  Advertencia: Sin cambio de signo. Ajustando intervalo...")
    b = 1  # Forzamos intervalo conocido válido
fin

raiz = raices.brent(f, a, b, tol)

escribir("📐 MÉTODO DE BRENT")
escribir("════════════════════════════")
escribir("Función: f(x) = e^x - 3x")
escribir("Intervalo inicial: [" .. a .. ", " .. b .. "]")
escribir("Raíz encontrada: " .. raiz["resultado"])
escribir("Valor f(raíz): " .. f(raiz["resultado"]))
escribir("f en la raíz (desde tabla): " .. raiz["f_en_raiz"])
escribir("Convergió: " .. (raiz["convergio"] ? "✅ Sí" : "❌ No"))
escribir("Iteraciones: " .. raiz["iteraciones"])

# 🔹 Encontrar SEGUNDA raíz en [1, 2]
escribir("")
escribir("🔍 Buscando segunda raíz en [1, 2]:")
a2 = 1
b2 = 2
escribir("  f(" .. a2 .. ") = " .. f(a2))
escribir("  f(" .. b2 .. ") = " .. f(b2))

si f(a2) * f(b2) < 0
    raiz2 = raices.brent(f, a2, b2, tol)
    escribir("  Raíz encontrada: " .. raiz2["resultado"])
    escribir("  Valor f(raíz): " .. f(raiz2["resultado"]))
sino
    escribir("  ❌ No hay cambio de signo en [" .. a2 .. ", " .. b2 .. "]")
fin

# 🔹 Función oscilante: f(x) = sen(1/x)
funcion f_onda(x)
    si x == 0 retornar 0 fin  # Evitar división por cero
    retornar mate.sen(1/x)
fin

escribir("")
escribir("🌊 FUNCIÓN OSCILANTE: f(x) = sen(1/x)")
# Intervalo que contiene una raíz conocida: x = 1/π ≈ 0.31831
a3 = 0.3
b3 = 0.5
escribir("Intervalo: [" .. a3 .. ", " .. b3 .. "]")
escribir("  f(" .. a3 .. ") = " .. f_onda(a3))
escribir("  f(" .. b3 .. ") = " .. f_onda(b3))

si f_onda(a3) * f_onda(b3) < 0
    raiz_onda = raices.brent(f_onda, a3, b3, tol)
    escribir("  Raíz aproximada: " .. raiz_onda["resultado"])
    escribir("  Valor f(raíz): " .. f_onda(raiz_onda["resultado"]))
    # ✅ Verificación segura: solo accedemos a claves confirmadas del diccionario
    si raiz_onda["convergio"] == falso
        escribir("  ⚠️  El método no convergió con la tolerancia especificada")
    fin
    si raiz_onda["iteraciones"] > 20
        escribir("  ℹ️  Convergencia lenta: " .. raiz_onda["iteraciones"] .. " iteraciones")
    fin
sino
    escribir("  ⚠️  Sin cambio de signo detectado. Probando otro intervalo...")
    # Intervalo alternativo: [0.31, 0.33] contiene x = 1/π
    a3 = 0.31; b3 = 0.33
    si f_onda(a3) * f_onda(b3) < 0
        raiz_onda = raices.brent(f_onda, a3, b3, tol)
        escribir("  Raíz en [" .. a3 .. ", " .. b3 .. "]: " .. raiz_onda["resultado"])
    fin
fin
```

🎯 **Ejemplo: raices.puntoFijo**

Encuentra un punto fijo x' tal que g(x') = x' mediante iteración funcional. Requiere reescribir la ecuación original f(x)=0 como x = g(x).

```latino
incluir("formulas")

# Resolver x = cos(x) (punto fijo)
funcion g(x)
    retornar mate.cos(x)
fin

x0 = 0.5
tol = 1e-8

pf = raices.puntoFijo(g, x0, tol)
escribir("PUNTO FIJO")
escribir("Aproximación inicial: " .. x0)
escribir("Punto fijo encontrado: " .. pf["resultado"])
escribir("g(x) = " .. g(pf["resultado"]))
escribir("Convergió: " .. (pf["convergio"] ? "Sí" : "No"))
escribir("Iteraciones: " .. pf["iteraciones"])
escribir("Fórmula: " .. pf["formula"])
# Salida:
# PUNTO FIJO
# Aproximación inicial: 0.5
# Punto fijo encontrado: 0.7390851372357778
# g(x) = 0.7390851305068246
# Convergió: Sí
# Iteraciones: 45
# Fórmula: xₙ₊₁ = g(xₙ)

# Resolver x = √(2) (como punto fijo)
funcion g_raiz2(x)
    retornar 2/x  # punto fijo en x = √2
fin

pf_raiz2 = raices.puntoFijo(g_raiz2, 1.0)
escribir("\nRAÍZ DE 2")
escribir("Resultado: " .. pf_raiz2["resultado"])
escribir("Advertencia: " .. pf_raiz2["advertencia"])
# Salida:
# RAÍZ DE 2
# Resultado: 1
# Advertencia: Se alcanzó max_iter = 10000. Verifica que |g'(x*)| < 1 (condición de convergencia).
```

🎯 **Ejemplo: raices.regulaFalsi**

Método de Regula Falsi (falsa posición): similar a bisección pero usa interpolación lineal. Puede ser más rápido pero a veces converge lentamente.

```latino
incluir("formulas")

# Encontrar raíz de f(x) = x³ - 2x - 5
funcion f(x)
    retornar x^3 - 2*x - 5
fin

a = 2
b = 3
tol = 1e-8

raiz = raices.regulaFalsi(f, a, b, tol)
escribir("REGULA FALSI")
escribir("Intervalo inicial: [" .. a .. ", " .. b .. "]")
escribir("Raíz encontrada: " .. raiz["resultado"])
escribir("Valor f(raíz): " .. f(raiz["resultado"]))
escribir("Convergió: " .. (raiz["convergio"] ? "Sí" : "No"))
escribir("Iteraciones: " .. raiz["iteraciones"])
# Salida:
# REGULA FALSI
# Intervalo inicial: [2, 3]
# Raíz encontrada: 2.094551480976474
# Valor f(raíz): -6.3157301610772265E-09
# Convergió: Sí
# Iteraciones: 19

# Comparar con bisección
raiz_bis = raices.biseccion(f, 2, 3, 1e-8)
escribir("\nBisección: " .. raiz_bis["iteraciones"] .. " iteraciones")
# Salida:
# Bisección: 27 iteraciones
```

🎯 **Ejemplo: raices.buscarIntervalos**

Escanea un intervalo dividiéndolo en subintervalos y detecta dónde cambia de signo la función, útil para localizar raíces antes de aplicar métodos más precisos.

```latino
incluir("formulas")

# Función con múltiples raíces: f(x) = sen(x) en [0, 10]
funcion f(x)
    retornar mate.sen(x)
fin

a = 0
b = 10
n = 20  # 20 subintervalos

intervalos = raices.buscarIntervalos(f, a, b, n)
escribir("BÚSQUEDA DE INTERVALOS")
escribir("Intervalo analizado: [" .. a .. ", " .. b .. "]")
escribir("Número de subintervalos: " .. n)
escribir("Intervalos con cambio de signo: ")
para interv en intervalos["intervalos"]
    escribir("  [" .. interv[0] .. ", " .. interv[1] .. "]")
fin
escribir("Número de raíces posibles: " .. intervalos["num_raices_posibles"])
escribir("Nota: " .. intervalos["nota"])
# Salida:
# BÚSQUEDA DE INTERVALOS
# Intervalo analizado: [0, 10]
# Número de subintervalos: 20
# Intervalos con cambio de signo: 
#   [0, 0.5]
#   [3, 3.5]
#   [6, 6.5]
#   [9, 9.5]
# Número de raíces posibles: 4
# Nota: Cada par [a_i, b_i] contiene al menos una raíz. Pasa cada par a raices.brent o raices.biseccion para precisión.

# Función cuadrática con una raíz doble (sin cambio de signo)
funcion f_doble(x)
    retornar (x-2)^2  # raíz en x=2, pero siempre ≥0
fin

interv_doble = raices.buscarIntervalos(f_doble, 0, 4, 10)
escribir("\nRAÍZ DOBLE")
escribir("Intervalos encontrados: " .. interv_doble["intervalos"])
escribir("Nota: " .. interv_doble["nota"])
# Salida:
# RAÍZ DOBLE
# Intervalos encontrados: [[1.6, 2], [2, 2.4000000000000004]]
# Nota: Cada par [a_i, b_i] contiene al menos una raíz. Pasa cada par a raices.brent o raices.biseccion para precisión.
```
