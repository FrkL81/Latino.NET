## 9.18 Plugin `formulas`

### 9.18.08 Librería `economia`

La librería `economia` proporciona funciones para cálculos financieros y de análisis de inversiones. Actualmente incluye el cálculo del retorno de inversión (ROI), una métrica fundamental para evaluar la rentabilidad de proyectos y negocios. Todas las funciones devuelven diccionarios con el resultado, la unidad correspondiente y la fórmula aplicada.

#### Referencia de Funciones

| Función | Argumentos | Descripción |
| :--- | :--- | :--- |
| `economia.roi` | `(gananciaNeta, costoInversion)` | Calcula el Retorno de Inversión (ROI). Fórmula: $ROI = \frac{Ganancia}{Costo} \times 100$ |

🎯 **Ejemplo: economia.roi**

Calcula el Retorno de Inversión (ROI), expresado como porcentaje. Mide la eficiencia de una inversión comparando la ganancia obtenida con el costo incurrido.

```latino
incluir("formulas")

# Inversión en un negocio: costo $1000, ganancia $500
res1 = economia.roi(500, 1000)
escribir("ROI: " .. res1["resultado"] .. " " .. res1["unidad"])
# Salida: ROI: 50 %

# Interpretación: por cada peso invertido, se recuperó 1.50 pesos total
escribir("Fórmula: " .. res1["formula"])
# Salida: Fórmula: ROI = (Ganancia / Costo) · 100

# Inversión publicitaria: costo $500, ganancia $1500
res2 = economia.roi(1500, 500)
escribir("ROI campaña: " .. res2["resultado"] .. "%")
# Salida: ROI campaña: 300%

# Inversión con pérdida (ganancia negativa)
res3 = economia.roi(-200, 1000)
escribir("ROI negativo: " .. res3["resultado"] .. "%")
# Salida: ROI negativo: -20%

# Análisis comparativo de dos inversiones
inversion_a = economia.roi(800, 2000)   # 40%
inversion_b = economia.roi(600, 1200)   # 50%

si inversion_b["resultado"] > inversion_a["resultado"]
    escribir("La inversión B es más rentable ( " .. inversion_b["resultado"] .. "% vs " .. inversion_a["resultado"] .. "% )")
fin
# Salida: La inversión B es más rentable (50% vs 40%)
```
