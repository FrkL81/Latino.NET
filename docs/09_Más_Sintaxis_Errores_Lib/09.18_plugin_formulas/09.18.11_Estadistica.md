## 9.18 Plugin `formulas`

### 9.18.11 Librería `estadistica`

La librería `estadistica` proporciona funciones esenciales para el análisis estadístico de datos. **Todas las funciones retornan diccionarios** con el resultado y metadatos específicos (incluyendo `combinaciones` y `permutaciones`).

#### 🗝️ Estructura de los Diccionarios de Retorno

| Función | Claves del Diccionario Retornado |
| :--- | :--- |
| `estadistica.coeficienteVariacion` | `resultado`, `unidad`, `nivel`, `formula` |
| `estadistica.media` | `resultado`, `unidad`, `formula` |
| `estadistica.puntajeZ` | `resultado`, `unidad`, `interpretacion`, `formula` |
| `estadistica.varianzaDesviacion` | `media`, `varianza`, `desviacion_estandar`, `n`, `formula` |

#### Referencia de Funciones

| Función | Argumentos | Descripción |
| :--- | :--- | :--- |
| `estadistica.coeficienteVariacion` | `(media, desviacion_estandar)` | Coeficiente de Variación: dispersión relativa como porcentaje de la media. Fórmula: $CV = \frac{\sigma}{\mu} \times 100$ |
| `estadistica.combinaciones` | `(n, r)` | Combinaciones sin repetición (coeficiente binomial). Fórmula: $C(n,r) = \frac{n!}{r!(n-r)!}$ |
| `estadistica.media` | `(lista_valores)` | Media aritmética de una lista de valores. Fórmula: $\bar{x} = \frac{\sum x_i}{n}$ |
| `estadistica.permutaciones` | `(n, r)` | Permutaciones sin repetición. Fórmula: $P(n,r) = \frac{n!}{(n-r)!}$ |
| `estadistica.puntajeZ` | `(valor, media, desviacion_estandar)` | Puntaje Z (estandarización): cuántas desviaciones estándar se aleja un valor de la media. Fórmula: $z = \frac{x - \mu}{\sigma}$ |
| `estadistica.varianzaDesviacion` | `(lista_valores, [es_muestra])` | Varianza y desviación estándar. `es_muestra=verdadero` usa N-1 (corrección de Bessel). Fórmulas: $\sigma^2 = \frac{\sum (x_i - \bar{x})^2}{N}$, $\sigma = \sqrt{\sigma^2}$ |

🎯 **Ejemplo: estadistica.media**

Calcula el promedio aritmético de un conjunto de valores numéricos. **Nota:** La función espera que todos los elementos de la lista sean números. No realiza conversión automática de cadenas.

```latino
incluir("formulas")

# Calcular la calificación promedio de un estudiante
notas = [85, 90, 78, 92, 88]
resultado = estadistica.media(notas)
escribir("Promedio de notas: " .. resultado["resultado"])
escribir("Unidad: " .. resultado["unidad"])
escribir("Fórmula: " .. resultado["formula"])
# Salida:
# Promedio de notas: 86.6
# Unidad: unidades
# Fórmula: x̄ = (Σxᵢ) / n

# Temperaturas diarias de una semana
temperaturas = [22.5, 23.1, 21.8, 24.0, 22.7, 25.2, 24.5]
temp_media = estadistica.media(temperaturas)
escribir("Temperatura media semanal: " .. temp_media["resultado"] .. "°C")
# Salida: Temperatura media semanal: 23.4°C
```

🎯 **Ejemplo: estadistica.varianzaDesviacion**

Calcula la varianza y la desviación estándar. El parámetro opcional `es_muestra` determina si se aplica la corrección de Bessel (división por N-1) para muestras.

```latino
incluir("formulas")

# Análisis de edades en un grupo (considerado muestra)
edades = [25, 30, 35, 40, 45]
res_muestra = estadistica.varianzaDesviacion(edades, verdadero)
escribir("MEDIA: " .. res_muestra["media"])
escribir("VARIANZA (muestra): " .. res_muestra["varianza"])
escribir("DESVIACIÓN (muestra): " .. res_muestra["desviacion_estandar"])
escribir("NÚMERO DE ELEMENTOS: " .. res_muestra["n"])
# Salida:
# MEDIA: 35
# VARIANZA (muestra): 62.5
# DESVIACIÓN (muestra): 7.9056941504209
# NÚMERO DE ELEMENTOS: 5

# Mismos datos pero tratados como población completa
res_poblacion = estadistica.varianzaDesviacion(edades, falso)
escribir("VARIANZA (población): " .. res_poblacion["varianza"])
escribir("DESVIACIÓN (población): " .. res_poblacion["desviacion_estandar"])
# Salida:
# VARIANZA (población): 50.0
# DESVIACIÓN (población): 7.0710678118655

# Ver la fórmula utilizada
escribir("Fórmula: " .. res_muestra["formula"])
# Salida: Fórmula: σ² = Σ(xᵢ - x̄)² / N
```

🎯 **Ejemplo: estadistica.combinaciones**

Calcula el número de formas de seleccionar `r` elementos de un conjunto de `n` elementos, sin importar el orden. Retorna un diccionario con la clave `"resultado"`.

```latino
incluir("formulas")

# ¿Cuántas manos de 5 cartas hay en una baraja de 52?
manos = estadistica.combinaciones(52, 5)
escribir("Posibles manos de póker: " .. manos["resultado"])
# Salida: Posibles manos de póker: 2598960

# Formar un comité de 3 personas de un grupo de 10
comite = estadistica.combinaciones(10, 3)
escribir("Comités posibles: " .. comite["resultado"])
# Salida: Comités posibles: 120
```

🎯 **Ejemplo: estadistica.permutaciones**

Calcula el número de formas de ordenar `r` elementos seleccionados de un conjunto de `n` elementos, donde el orden importa. Retorna un diccionario con la clave `"resultado"`.

```latino
incluir("formulas")

# Podio de una carrera (10 corredores, 3 posiciones)
podio = estadistica.permutaciones(10, 3)
escribir("Posibles resultados del podio: " .. podio["resultado"])
# Salida: Posibles resultados del podio: 720

# Ordenar 5 libros en un estante
orden_libros = estadistica.permutaciones(5, 5)
escribir("Formas de ordenar 5 libros: " .. orden_libros["resultado"])
# Salida: Formas de ordenar 5 libros: 120
```

🎯 **Ejemplo: estadistica.puntajeZ**

Calcula el puntaje Z, que indica cuántas desviaciones estándar se aleja un valor de la media, e incluye una interpretación contextual.

```latino
incluir("formulas")

# Comparar rendimiento en diferentes materias
z_mate = estadistica.puntajeZ(85, 75, 8)
z_len = estadistica.puntajeZ(70, 65, 5)

escribir("Matemáticas - Puntaje Z: " .. z_mate["resultado"])
escribir("Matemáticas - Interpretación: " .. z_mate["interpretacion"])
escribir("Lenguaje - Puntaje Z: " .. z_len["resultado"])
escribir("Lenguaje - Interpretación: " .. z_len["interpretacion"])
# Salida:
# Matemáticas - Puntaje Z: 1.25
# Matemáticas - Interpretación: Por encima de la media
# Lenguaje - Puntaje Z: 1.0
# Lenguaje - Interpretación: Por encima de la media

# Identificar valores atípicos
z_atipico = estadistica.puntajeZ(150, 100, 15)
escribir("Puntaje Z: " .. z_atipico["resultado"])
escribir("Interpretación: " .. z_atipico["interpretacion"])
# Salida:
# Puntaje Z: 3.33
# Interpretación: Valor atípico (muy por encima de la media)
```

🎯 **Ejemplo: estadistica.coeficienteVariacion**

Calcula el coeficiente de variación, que expresa la desviación estándar como porcentaje de la media, e incluye una clasificación del nivel de dispersión.

```latino
incluir("formulas")

# Comparar consistencia en dos procesos de fabricación
cv_a = estadistica.coeficienteVariacion(1000, 50)
cv_b = estadistica.coeficienteVariacion(200, 15)

escribir("Proceso A - CV: " .. cv_a["resultado"] .. "%")
escribir("Proceso A - Nivel: " .. cv_a["nivel"])
escribir("Proceso B - CV: " .. cv_b["resultado"] .. "%")
escribir("Proceso B - Nivel: " .. cv_b["nivel"])
# Salida:
# Proceso A - CV: 5%
# Proceso A - Nivel: Muy homogéneo
# Proceso B - CV: 7.5%
# Proceso B - Nivel: Homogéneo

# Análisis de inversiones con diferente riesgo
cv_bajo = estadistica.coeficienteVariacion(50000, 2500)    # 5%
cv_medio = estadistica.coeficienteVariacion(50000, 7500)   # 15%
cv_alto = estadistica.coeficienteVariacion(50000, 15000)   # 30%

escribir("CV 5% - Nivel: " .. cv_bajo["nivel"])
escribir("CV 15% - Nivel: " .. cv_medio["nivel"])
escribir("CV 30% - Nivel: " .. cv_alto["nivel"])
# Salida:
# CV 5% - Nivel: Muy homogéneo
# CV 15% - Nivel: Dispersión moderada
# CV 30% - Nivel: Alta dispersión
```
