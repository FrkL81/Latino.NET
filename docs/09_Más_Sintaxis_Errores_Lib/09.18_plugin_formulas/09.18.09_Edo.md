## 9.18 Plugin `formulas`

### 9.18.09 Librería `edo`

La librería `edo` (Ecuaciones Diferenciales Ordinarias) proporciona métodos numéricos para resolver problemas de valor inicial y de frontera. Incluye desde métodos básicos como Euler hasta técnicas avanzadas como Runge-Kutta-Fehlberg adaptativo y métodos para sistemas de ecuaciones. Todas las funciones devuelven diccionarios con la trayectoria de la solución y metadatos del método aplicado.

#### 🗝️ Estructura de los Diccionarios de Retorno

Las funciones de EDO devuelven diccionarios con las siguientes claves comunes:

| Clave | Descripción |
| :--- | :--- |
| `"trayectoria"` | Lista de puntos `[t, y]` para cada paso |
| `"t_final"` | Valor final del tiempo |
| `"y_final"` | Valor final de la variable dependiente |
| `"formula"` | Método numérico utilizado |
| `"pasos_aceptados"` | Número de pasos aceptados (rkf45) |
| `"pasos_rechazados"` | Número de pasos rechazados (rkf45) |
| `"n_pasos"` | Número de pasos realizados (euler, rk4, adams) |

> **Nota:** La clave de pasos varía según el método: `rkf45` usa `pasos_aceptados`/`pasos_rechazados`, mientras que `euler`, `rk4` y `adams` usan `n_pasos`.

#### Referencia de Funciones

| Función | Argumentos | Descripción |
| :--- | :--- | :--- |
| `edo.adams` | `(funcionF, t0, y0, tf, n)` | Método Adams-Bashforth-Moulton de orden 4. |
| `edo.disparo` | `(funcion_sistema, a, b, ya, yb, [tolerancia], [max_iter])` | PVF no lineal por método de disparo. |
| `edo.eulerImplicito` | `(funcionF, funcionDfDy, t0, y0, tf, n)` | Método de Euler Implícito. |
| `edo.eulerMejorado` | `(funcionF, t0, y0, tf, n)` | Método de Euler Mejorado (Heun). |
| `edo.euler` | `(funcionF, t0, y0, tf, n)` | Resuelve dy/dt = f(t, y) con el método de Euler. |
| `edo.pvf` | `(funcion_f, a, b, ya, yb, n)` | Problema de Valor de Frontera de segundo orden. |
| `edo.rk4` | `(funcionF, t0, y0, tf, n)` | Método clásico Runge-Kutta de orden 4. |
| `edo.rkf45` | `(funcionF, t0, y0, tf, [tolerancia], [hInicial], [hMin], [hMax])` | Método Runge-Kutta-Fehlberg adaptativo. |
| `edo.sistemaRk4` | `(funcionF, t0, listaY0, tf, n)` | Resuelve un sistema de EDOs con RK4. |
| `edo.sistemaRkf45` | `(funcionF, t0, listaY0, tf, [tolerancia], [hInicial], [hMin], [hMax])` | Sistema de EDOs con RKF45 adaptativo. |

🎯 **Ejemplo: edo.euler**

Resuelve una EDO de primer orden usando el método de Euler explícito. Es el método más simple pero menos preciso.

```latino
incluir("formulas")

# Ecuación: dy/dt = y (crecimiento exponencial)
# Solución exacta: y(t) = e^t
f = fun(t, y) ret y fin

t0 = 0
y0 = 1
tf = 1
n = 10  # 10 pasos

res = edo.euler(f, t0, y0, tf, n)
escribir("y(1) ≈ " .. res["y_final"])
# Salida: y(1) ≈ 2.5937

# Comparar con más pasos (mayor precisión)
res2 = edo.euler(f, t0, y0, tf, 100)
escribir("y(1) con 100 pasos: " .. res2["y_final"])
# Salida: y(1) con 100 pasos: 2.7048
```

🎯 **Ejemplo: edo.eulerMejorado**

Método de Euler Mejorado (también conocido como método de Heun). Utiliza un predictor-corrector para mayor precisión.

```latino
incluir("formulas")

# Ecuación: dy/dt = -2y (decaimiento exponencial)
# Solución exacta: y(t) = e^(-2t)
f = fun(t, y) ret -2*y fin

res = edo.eulerMejorado(f, 0, 1, 2, 20)
escribir("y(2) ≈ " .. res["y_final"])
# Salida: y(2) ≈ 0.0183

escribir("Método: " .. res["formula"])
# Salida: Método: Euler Mejorado (Heun)
```

🎯 **Ejemplo: edo.rk4**

Método de Runge-Kutta de orden 4, ampliamente utilizado por su excelente equilibrio entre precisión y costo computacional.

```latino
incluir("formulas")

# Ecuación logística: dy/dt = y(1 - y)
f = fun(t, y) ret y * (1 - y) fin

res = edo.rk4(f, 0, 0.1, 5, 50)
escribir("Población en t=5: " .. res["y_final"])
# Salida: Población en t=5: 0.9428

# Acceder a puntos intermedios de la trayectoria
trayectoria = res["trayectoria"]
escribir("Primer punto: t=" .. trayectoria[0][0] .. ", y=" .. trayectoria[0][1])
# Salida: Primer punto: t=0, y=0.1
```

🎯 **Ejemplo: edo.rkf45**

Método Runge-Kutta-Fehlberg con paso adaptativo. Ajusta automáticamente el tamaño del paso para mantener el error dentro de la tolerancia especificada.

```latino
incluir("formulas")

# Ecuación con comportamiento oscilatorio
f = fun(t, y) ret y * mate.cos(t) fin

# Con tolerancia estándar (1e-6)
res = edo.rkf45(f, 0, 1, 10)
escribir("y(10) = " .. res["y_final"])
# Salida: y(10) = 0.5804

# ✅ Claves correctas para rkf45: pasos_aceptados, pasos_rechazados, formula, y_final, t_final
escribir("Pasos aceptados: " .. res["pasos_aceptados"])
escribir("Pasos rechazados: " .. res["pasos_rechazados"])
escribir("Fórmula: " .. res["formula"])

# Total de pasos intentados
total_pasos = res["pasos_aceptados"] + res["pasos_rechazados"]
escribir("Total de pasos: " .. total_pasos)

# Con tolerancia más estricta (más pasos)
res2 = edo.rkf45(f, 0, 1, 10, 1e-8)
escribir("Pasos aceptados con tolerancia 1e-8: " .. res2["pasos_aceptados"])
```

🎯 **Ejemplo: edo.adams**

Método multipaso de Adams-Bashforth-Moulton de orden 4. Utiliza información de pasos previos para mayor eficiencia.

```latino
incluir("formulas")

# Ecuación: dy/dt = t - y
f = fun(t, y) ret t - y fin

res = edo.adams(f, 0, 1, 2, 20)
escribir("y(2) ≈ " .. res["y_final"])
# Salida: y(2) ≈ 1.2642
```

🎯 **Ejemplo: edo.sistemaRk4**

Resuelve un sistema de ecuaciones diferenciales ordinarias usando Runge-Kutta de orden 4.

```latino
incluir("formulas")

# Sistema: dx/dt = y, dy/dt = -x (oscilador armónico)
# Corresponde a: x'' + x = 0
sistema = fun(t, y)
    retornar [
        y[1],        # dx/dt
        -y[0]        # dy/dt
    ]
fin

t0 = 0
y0 = [1, 0]  # x(0)=1, x'(0)=0
tf = 2 * mate.pi  # Un período completo
n = 100

res = edo.sistemaRk4(sistema, t0, y0, tf, n)
escribir("x(2π) = " .. res["y_final"][0])
# Salida: x(2π) = 1.0000
escribir("v(2π) = " .. res["y_final"][1])
# Salida: v(2π) = 0.0000
```

🎯 **Ejemplo: edo.sistemaRkf45**

Resuelve sistemas de EDOs con paso adaptativo usando el método Runge-Kutta-Fehlberg.

```latino
incluir("formulas")

# Sistema de Lotka-Volterra (presa-depredador)
# dx/dt = x(α - βy)
# dy/dt = -y(γ - δx)
lV = fun(t, y)
    alfa = 0.4
    beta = 0.04
    gamma = 0.3
    delta = 0.03
    retornar [
        y[0] * (alfa - beta * y[1]),
        -y[1] * (gamma - delta * y[0])
    ]
fin

y0 = [40, 9]  # población inicial
res = edo.sistemaRkf45(lV, 0, y0, 50, 1e-5)
escribir("Población final - Presas: " .. res["y_final"][0])
escribir("Población final - Depredadores: " .. res["y_final"][1])
# Salida aproximada: Presas: 45.2, Depredadores: 8.7
```

🎯 **Ejemplo: edo.eulerImplicito**

Método de Euler implícito, útil para ecuaciones stiff (rígidas) donde los métodos explícitos pueden ser inestables.

```latino
incluir("formulas")

# Ecuación stiff: dy/dt = -1000(y - cos(t))
f = fun(t, y) ret -1000 * (y - mate.cos(t)) fin

# Derivada parcial para el método de Newton
dfdy = fun(t, y) ret -1000 fin

res = edo.eulerImplicito(f, dfdy, 0, 1, 2, 100)
escribir("y(2) = " .. res["y_final"])
# Salida: y(2) = -0.4161
```

🎯 **Ejemplo: edo.pvf**

Resuelve un problema de valor de frontera de segundo orden de la forma y'' = f(x, y, y') con condiciones en los extremos.

```latino
incluir("formulas")

# Problema: y'' = -y, con y(0)=0, y(π/2)=1
# Solución exacta: y(x) = sen(x)
f = fun(x, y, dy) ret -y fin

a = 0
b = mate.pi/2
ya = 0
yb = 1
n = 20

res = edo.pvf(f, a, b, ya, yb, n)

# ✅ Acceso correcto a la solución
escribir("Solución completa: " .. res["solucion"])
# Salida: [[0,0], [0.0785,0.0654], ..., [1.5708,1]]

# Acceder a un punto específico (por ejemplo, x = π/4 ≈ 0.7854)
punto_medio = res["solucion"][10]  # índice 10 (aprox)
escribir("y(π/4) ≈ " .. punto_medio[1])
# Salida: y(π/4) ≈ 0.6232  (sen(π/4) ≈ 0.7071 - el error es por la discretización)

# Mejor: buscar el punto más cercano
para i en rango(0, lista.longitud(res["solucion"]))
    punto = res["solucion"][i]
    si mate.abs(punto[0] - mate.pi/4) < 0.001
        escribir("y(π/4) ≈ " .. punto[1])
        romper
    fin
fin
# Salida: y(π/4) ≈ 0.6232
```

🎯 **Ejemplo: edo.disparo**

Resuelve problemas de valor de frontera no lineales mediante el método de disparo, convirtiéndolos en problemas de valor inicial.

```latino
incluir("formulas")

# Problema no lineal: y'' = 2y^3, con y(0)=0, y(1)=1
# Convertimos a sistema de primer orden:
# Y[0] = y
# Y[1] = y'
# dY/dt = [Y[1], 2*Y[0]^3]
sistema = fun(t, Y)
    retornar [
        Y[1],           # dy/dt = y'
        2 * Y[0]^3      # dy'/dt = y'' = 2y^3
    ]
fin

# ✅ CORRECTO: ya e yb son valores ESCALARES
# ya = y(0) = 0
# yb = y(1) = 1
res = edo.disparo(sistema, 0, 1, 0, 1)

# Acceso a la solución completa (lista de puntos [t, y, y'])
solucion = res["solucion"]
escribir("Puntos en la solución: " .. lista.longitud(solucion))
# Salida: Puntos en la solución: 21

# Verificar condición de frontera en t=1
punto_final = solucion[lista.longitud(solucion) - 1]  # último punto
escribir("y(1) = " .. punto_final[1])
# Salida: y(1) = 1.0

# Pendiente inicial encontrada
escribir("y'(0) = " .. res["pendiente_inicial"])
# Salida: y'(0) = 0.957

escribir("Iteraciones: " .. res["iteraciones"])
# Salida: Iteraciones: 6

escribir("¿Convergió?: " .. res["convergio"])
# Salida: ¿Convergió?: cierto

# Evaluar en un punto específico (ej. t = 0.5)
# Buscar el punto más cercano
para i en rango(0, lista.longitud(solucion))
    punto = solucion[i]
    si punto[0] >= 0.5
        escribir("y(0.5) ≈ " .. punto[1])
        romper
    fin
fin
# Salida: y(0.5) ≈ 0.312
```
