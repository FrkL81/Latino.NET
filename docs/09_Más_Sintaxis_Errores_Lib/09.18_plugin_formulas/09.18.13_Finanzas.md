## 9.18 Plugin `formulas`

### 9.18.13 Librería `finanzas`

La librería `finanzas` proporciona funciones esenciales para cálculos financieros, incluyendo interés simple y compuesto, valor presente y futuro, amortización de préstamos y análisis de punto de equilibrio. Todas las funciones devuelven diccionarios con el resultado y metadatos específicos según el contexto.

#### 🗝️ Estructura de los Diccionarios de Retorno

| Función | Claves del Diccionario Retornado |
| :--- | :--- |
| **Todas** | `resultado`, `unidad`, `formula` |
| `finanzas.amortizacionCuota` | `total_pagado`, `total_intereses`, `numero_cuotas` |
| `finanzas.interesCompuesto` | `interes_generado`, `capital_inicial` |
| `finanzas.interesSimple` | `monto_final`, `interes_generado`, `capital_inicial` |
| `finanzas.puntoEquilibrio` | `margen_contribucion`, `ingreso_equilibrio` |

#### Referencia de Funciones

| Función | Argumentos | Descripción |
| :--- | :--- | :--- |
| `finanzas.amortizacionCuota` | `(capital, tasa_mensual, numero_cuotas)` | Cuota mensual fija de un préstamo (sistema francés). Fórmula: $C = P \cdot \frac{r(1+r)^n}{(1+r)^n - 1}$ |
| `finanzas.interesCompuesto` | `(capital, tasa_anual, tiempo_anios, [periodos_por_anio])` | Monto final con capitalización compuesta. periodos_por_anio: 1=anual, 12=mensual, 365=diario. Fórmula: $M = C \cdot (1 + r/n)^{n \cdot t}$ |
| `finanzas.interesSimple` | `(capital, tasa_anual, tiempo_anios)` | Interés simple (sin capitalización). Fórmula: $I = C \cdot r \cdot t$ |
| `finanzas.puntoEquilibrio` | `(costos_fijos, precio_venta, costo_variable_unitario)` | Punto de equilibrio: unidades mínimas para cubrir costos. Fórmula: $Q = \frac{CF}{PV - CV}$ |
| `finanzas.valorFuturo` | `(valor_presente, tasa_anual, tiempo_anios)` | Valor Futuro de un capital a interés compuesto anual. Fórmula: $VF = VP \cdot (1 + r)^t$ |
| `finanzas.valorPresente` | `(valor_futuro, tasa_anual, tiempo_anios)` | Valor Presente: ¿cuánto vale hoy un pago futuro? Fórmula: $VP = \frac{VF}{(1 + r)^t}$ |

🎯 **Ejemplo: finanzas.interesSimple**

Calcula el interés simple generado por un capital inicial durante un período determinado, sin capitalización de intereses.

```latino
incluir("formulas")

# Préstamo de $10,000 al 5% anual durante 3 años
capital = 10000
tasa = 0.05  # 5% anual
tiempo = 3   # 3 años

res = finanzas.interesSimple(capital, tasa, tiempo)
escribir("INTERÉS SIMPLE")
escribir("Resultado (interés): $" .. res["resultado"])
escribir("Interés generado: $" .. res["interes_generado"])
escribir("Monto final: $" .. res["monto_final"])
escribir("Capital inicial: $" .. res["capital_inicial"])
escribir("Unidad: " .. res["unidad"])
escribir("Fórmula: " .. res["formula"])
# Salida:
# INTERÉS SIMPLE
# Resultado (interés): $1500
# Interés generado: $1500
# Monto final: $11500
# Capital inicial: $10000
# Unidad: moneda
# Fórmula: I = C·r·t

# Inversión a 6 meses (0.5 años)
res_corto = finanzas.interesSimple(5000, 0.08, 0.5)
escribir("Interés en 6 meses: $" .. res_corto["resultado"])
# Salida: Interés en 6 meses: $200
```

🎯 **Ejemplo: finanzas.interesCompuesto**

Calcula el monto final y el interés generado cuando los intereses se capitalizan periódicamente.

```latino
incluir("formulas")

# Inversión de $5,000 al 6% anual durante 5 años
capital = 5000
tasa = 0.06   # 6% anual
tiempo = 5    # 5 años

# Capitalización anual
res_anual = finanzas.interesCompuesto(capital, tasa, tiempo, 1)
escribir("CAPITALIZACIÓN ANUAL")
escribir("Resultado (monto final): $" .. res_anual["resultado"])
escribir("Interés generado: $" .. res_anual["interes_generado"])
escribir("Capital inicial: $" .. res_anual["capital_inicial"])
# Salida:
# CAPITALIZACIÓN ANUAL
# Resultado (monto final): $6691.13
# Interés generado: $1691.13
# Capital inicial: $5000

# Capitalización mensual
res_mensual = finanzas.interesCompuesto(capital, tasa, tiempo, 12)
escribir("CAPITALIZACIÓN MENSUAL")
escribir("Monto final: $" .. res_mensual["resultado"])
escribir("Interés generado: $" .. res_mensual["interes_generado"])
# Salida:
# CAPITALIZACIÓN MENSUAL
# Monto final: $6744.25
# Interés generado: $1744.25

# Capitalización diaria
res_diario = finanzas.interesCompuesto(capital, tasa, tiempo, 365)
escribir("CAPITALIZACIÓN DIARIA")
escribir("Monto final: $" .. res_diario["resultado"])
# Salida:
# CAPITALIZACIÓN DIARIA
# Monto final: $6749.23

# Ver la fórmula utilizada
escribir("Fórmula: " .. res_mensual["formula"])
escribir("Unidad: " .. res_mensual["unidad"])
# Salida:
# Fórmula: M = C·(1 + r/n)^(n·t)
# Unidad: moneda
```

🎯 **Ejemplo: finanzas.valorPresente**

Calcula el valor actual de una cantidad futura, descontando los intereses que se podrían haber ganado. Retorna solo las claves base.

```latino
incluir("formulas")

# ¿Cuánto debo invertir hoy para tener $10,000 en 5 años al 4% anual?
vf = 10000
tasa = 0.04  # 4% anual
tiempo = 5   # 5 años

vp = finanzas.valorPresente(vf, tasa, tiempo)
escribir("VALOR PRESENTE")
escribir("Inversión necesaria hoy: $" .. vp["resultado"])
escribir("Unidad: " .. vp["unidad"])
escribir("Fórmula: " .. vp["formula"])
# Salida:
# VALOR PRESENTE
# Inversión necesaria hoy: $8219.27
# Unidad: moneda
# Fórmula: VP = VF / (1 + r)^t

# Verificación: calcular valor futuro de esa inversión
vf_verif = finanzas.valorFuturo(vp["resultado"], tasa, tiempo)
escribir("Valor futuro resultante: $" .. vf_verif["resultado"])
# Salida: Valor futuro resultante: $10000
```

🎯 **Ejemplo: finanzas.valorFuturo**

Calcula el valor futuro de una inversión inicial a interés compuesto anual. Retorna solo las claves base.

```latino
incluir("formulas")

# Inversión de $3,000 al 7% anual durante 10 años
vp = 3000
tasa = 0.07  # 7% anual
tiempo = 10  # 10 años

vf = finanzas.valorFuturo(vp, tasa, tiempo)
escribir("VALOR FUTURO")
escribir("Inversión inicial: $" .. vp)
escribir("Valor futuro: $" .. vf["resultado"])
escribir("Fórmula: " .. vf["formula"])
# Salida:
# VALOR FUTURO
# Inversión inicial: $3000
# Valor futuro: $5901.45
# Fórmula: VF = VP·(1 + r)^t

# Comparar diferentes tasas
tasas = [0.05, 0.07, 0.10]
para t en tasas
    vf_temp = finanzas.valorFuturo(1000, t, 10)
    escribir("Tasa " .. (t*100) .. "%: $" .. vf_temp["resultado"])
fin
# Salida:
# Tasa 5%: $1628.89
# Tasa 7%: $1967.15
# Tasa 10%: $2593.74
```

🎯 **Ejemplo: finanzas.amortizacionCuota**

Calcula la cuota fija mensual de un préstamo según el sistema de amortización francés, donde todas las cuotas son iguales.

```latino
incluir("formulas")

# Préstamo hipotecario de $200,000 al 0.3% mensual (3.6% anual) a 20 años
capital = 200000
tasa_mensual = 0.003   # 0.3% mensual
cuotas = 240           # 20 años × 12 meses

prestamo = finanzas.amortizacionCuota(capital, tasa_mensual, cuotas)
escribir("AMORTIZACIÓN PRÉSTAMO")
escribir("Resultado (cuota mensual): $" .. prestamo["resultado"])
escribir("Total pagado: $" .. prestamo["total_pagado"])
escribir("Total intereses: $" .. prestamo["total_intereses"])
escribir("Número de cuotas: " .. prestamo["numero_cuotas"])
escribir("Unidad: " .. prestamo["unidad"])
escribir("Fórmula: " .. prestamo["formula"])
# Salida:
# AMORTIZACIÓN PRÉSTAMO
# Resultado (cuota mensual): $1167.52
# Total pagado: $280204.80
# Total intereses: $80204.80
# Número de cuotas: 240
# Unidad: moneda
# Fórmula: C = P·[r(1+r)^n]/[(1+r)^n - 1]

# Préstamo automotriz a 5 años
auto = finanzas.amortizacionCuota(15000, 0.01, 60)  # 1% mensual, 60 cuotas
escribir("Cuota mensual auto: $" .. auto["resultado"])
escribir("Total intereses: $" .. auto["total_intereses"])
# Salida:
# Cuota mensual auto: $333.67
# Total intereses: $5020.20
```

🎯 **Ejemplo: finanzas.puntoEquilibrio**

Calcula la cantidad mínima de unidades que deben venderse para cubrir todos los costos (fijos y variables), donde el ingreso total iguala al costo total.

```latino
incluir("formulas")

# Pequeña empresa de fabricación
costos_fijos = 50000      # $50,000 al mes
precio = 250              # $250 por unidad
costo_var = 150           # $150 por unidad

pe = finanzas.puntoEquilibrio(costos_fijos, precio, costo_var)
escribir("PUNTO DE EQUILIBRIO")
escribir("Resultado (unidades): " .. pe["resultado"])
escribir("Margen de contribución: $" .. pe["margen_contribucion"])
escribir("Ingreso en equilibrio: $" .. pe["ingreso_equilibrio"])
escribir("Unidad: " .. pe["unidad"])
escribir("Fórmula: " .. pe["formula"])
# Salida:
# PUNTO DE EQUILIBRIO
# Resultado (unidades): 500
# Margen de contribución: $100
# Ingreso en equilibrio: $125000
# Unidad: unidades
# Fórmula: Q = CF / (PV - CV)

# Verificación
ingreso = 500 * precio        # 500 × $250 = $125,000
costo_total = costos_fijos + (500 * costo_var)  # $50,000 + $75,000 = $125,000
escribir("Ingreso - Costo total = $" .. (ingreso - costo_total))
# Salida: Ingreso - Costo total = $0

# Análisis de sensibilidad con diferentes precios
precios = [200, 250, 300]
para p en precios
    eq = finanzas.puntoEquilibrio(costos_fijos, p, costo_var)
    escribir("Precio $" .. p .. ": " .. eq["resultado"] .. " unidades")
fin
# Salida:
# Precio $200: 1000 unidades
# Precio $250: 500 unidades
# Precio $300: 334 unidades
```
