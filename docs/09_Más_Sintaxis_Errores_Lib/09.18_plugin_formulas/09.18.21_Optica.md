## 9.18 Plugin `formulas`

### 9.18.21 Librería `optica`

La librería `optica` proporciona funciones para el estudio de fenómenos ópticos fundamentales, incluyendo refracción (Ley de Snell), formación de imágenes en lentes delgadas y espejos esféricos. Las funciones devuelven diccionarios con los resultados, diagnóstico del fenómeno, características de la imagen y la fórmula aplicada.

#### 🗝️ Estructura de los Diccionarios de Retorno

| Función | Claves del Diccionario Retornado |
| :--- | :--- |
| **Todas** | `resultado`, `unidad`, `formula` |
| `optica.espejoEsferico` | `focal`, `distancia_imagen`, `aumento`, `tipo_espejo`, `tipo_imagen` |
| `optica.lenteDelgada` | `incognita`, `aumento`, `tipo_imagen` |
| `optica.leySnell` | `fenomeno` |

#### Referencia de Funciones

| Función | Argumentos | Descripción |
| :--- | :--- | :--- |
| `optica.espejoEsferico` | `(radio_curvatura, distancia_objeto)` | Posición de la imagen en un espejo esférico. Radio positivo = cóncavo, negativo = convexo. Fórmulas: $f = \frac{R}{2}$, $\frac{1}{f} = \frac{1}{d_o} + \frac{1}{d_i}$ |
| `optica.lenteDelgada` | `(diccionario_variables)` | Ecuación de lente delgada. Pasa 2 de: 'f', 'do', 'di' (distancias en metros). Fórmula: $\frac{1}{f} = \frac{1}{d_o} + \frac{1}{d_i}$ |
| `optica.leySnell` | `(n1, angulo1_grados, n2)` | Ley de Snell-Descartes (refracción). Calcula el ángulo de refracción. Fórmula: $n_1 \sin(\theta_1) = n_2 \sin(\theta_2)$ |

🎯 **Ejemplo: optica.leySnell**

Calcula el ángulo de refracción cuando la luz pasa de un medio a otro, e indica si ocurre refracción normal o reflexión total interna.

```latino
incluir("formulas")

# Luz del aire (n=1) al agua (n=1.33) con ángulo de 30°
n1 = 1.0      # aire
angulo1 = 30  # grados
n2 = 1.33     # agua

snell = optica.leySnell(n1, angulo1, n2)
escribir("LEY DE SNELL")
escribir("n₁ = " .. n1 .. " (aire)")
escribir("θ₁ = " .. angulo1 .. "°")
escribir("n₂ = " .. n2 .. " (agua)")
escribir("Ángulo de refracción: " .. mate.redondear(snell["resultado"], 2) .. "°")
escribir("Fenómeno: " .. snell["fenomeno"])
# Salida:
# LEY DE SNELL
# n₁ = 1 (aire)
# θ₁ = 30°
# n₂ = 1.33 (agua)
# Ángulo de refracción: 22.08°
# Fenómeno: Refraccion hacia la normal

# Reflexión total interna (agua → aire)
n_agua = 1.33
angulo_incidencia = 50  # mayor que el ángulo crítico (aprox 48.75°)
n_aire = 1.0

snell_total = optica.leySnell(n_agua, angulo_incidencia, n_aire)
escribir("\nREFLEXIÓN TOTAL")
escribir("θ₂ calculado: " .. snell_total["resultado"] .. "° (No existe rayo refractado)")
escribir("Fenómeno: " .. snell_total["fenomeno"])
# Salida:
# REFLEXIÓN TOTAL
# θ₂ calculado: NaN° (No existe rayo refractado)
# Fenómeno: Reflexion Total Interna

# Prisma de vidrio (n=1.5) en aire
n_vidrio = 1.5
snell_vidrio = optica.leySnell(n_aire, 40, n_vidrio)
escribir("\nVIDRIO (n=1.5)")
escribir("Ángulo dentro del vidrio: " .. mate.redondear(snell_vidrio["resultado"], 2) .. "°")
# Salida:
# VIDRIO (n=1.5)
# Ángulo dentro del vidrio: 25.37°
```

> **NaN en el plugin `formulas`:** cuando el resultado queda fuera del dominio real, el motor devuelve `NaN` en `resultado` y **no detiene el flujo** (no es un `RuntimeError`).
> El valor es de tipo `decimal` y **no sigue el estándar IEEE 754**: `NaN == NaN` devuelve `cierto`, mientras que en IEEE 754 sería `falso`.
> No lo trates como un número contaminado: detecta el caso por la clave `fenomeno`, que describe el régimen físico. `mate.redondear(NaN, 2)` devuelve `NaN` sin error.

🎯 **Ejemplo: optica.lenteDelgada**

Resuelve la ecuación de lente delgada permitiendo calcular distancia focal, distancia objeto o distancia imagen, además de proporcionar el aumento y tipo de imagen.

```latino
incluir("formulas")

# Calcular distancia imagen (di) para lente convergente con f=10 cm, do=15 cm
vars1 = {"f": 0.10, "do": 0.15}  # distancias en metros

lente1 = optica.lenteDelgada(vars1)
escribir("LENTE DELGADA (CONVERGENTE)")
escribir("Distancia focal (f): " .. vars1["f"] .. " m")
escribir("Distancia objeto (do): " .. vars1["do"] .. " m")
escribir("Distancia imagen (di): " .. lente1["resultado"] .. " m")
escribir("Incógnita calculada: " .. lente1["incognita"])
escribir("Aumento: " .. lente1["aumento"])
escribir("Tipo de imagen: " .. lente1["tipo_imagen"])
escribir("Fórmula: " .. lente1["formula"])
# Salida:
# LENTE DELGADA (CONVERGENTE)
# Distancia focal (f): 0.1 m
# Distancia objeto (do): 0.15 m
# Distancia imagen (di): 0.3 m
# Incógnita calculada: di
# Aumento: -2
# Tipo de imagen: Real, invertida
# Fórmula: 1/f = 1/do + 1/di

# Objeto dentro de la distancia focal (lupa)
vars2 = {"f": 0.10, "do": 0.05}
lente2 = optica.lenteDelgada(vars2)
escribir("\nOBJETO DENTRO DE DISTANCIA FOCAL")
escribir("di = " .. lente2["resultado"] .. " m")
escribir("Aumento: " .. lente2["aumento"])
escribir("Tipo: " .. lente2["tipo_imagen"])
# Salida:
# OBJETO DENTRO DE DISTANCIA FOCAL
# di = -0.1 m
# Aumento: 2
# Tipo: Virtual, derecha

# Calcular distancia focal a partir de do y di
vars3 = {"do": 0.20, "di": 0.30}
lente3 = optica.lenteDelgada(vars3)
escribir("\nCÁLCULO DE DISTANCIA FOCAL")
escribir("f = " .. lente3["resultado"] .. " m")
escribir("Incógnita: " .. lente3["incognita"])
# Salida:
# CÁLCULO DE DISTANCIA FOCAL
# f = 0.12 m
# Incógnita: f
```

🎯 **Ejemplo: optica.espejoEsferico**

Calcula la posición de la imagen formada por un espejo esférico (cóncavo o convexo), incluyendo distancia focal, aumento y características de la imagen.

```latino
incluir("formulas")

# Espejo cóncavo (radio positivo) con objeto a 30 cm
R = 0.40  # radio 40 cm (positivo = cóncavo)
do = 0.30 # distancia objeto 30 cm

espejo1 = optica.espejoEsferico(R, do)
escribir("ESPEJO ESFÉRICO (CÓNCAVO)")
escribir("Radio de curvatura: " .. R .. " m")
escribir("Distancia objeto: " .. do .. " m")
escribir("Distancia focal: " .. espejo1["focal"] .. " m")
escribir("Distancia imagen: " .. espejo1["distancia_imagen"] .. " m")
escribir("Resultado: " .. espejo1["resultado"] .. " " .. espejo1["unidad"])
escribir("Aumento: " .. espejo1["aumento"])
escribir("Tipo de espejo: " .. espejo1["tipo_espejo"])
escribir("Tipo de imagen: " .. espejo1["tipo_imagen"])
escribir("Fórmula: " .. espejo1["formula"])
# Salida:
# ESPEJO ESFÉRICO (CÓNCAVO)
# Radio de curvatura: 0.4 m
# Distancia objeto: 0.3 m
# Distancia focal: 0.2 m
# Distancia imagen: 0.6 m
# Resultado: 0.6 m
# Aumento: -2
# Tipo de espejo: Cóncavo
# Tipo de imagen: Real, invertida
# Fórmula: f = R/2 | 1/f = 1/do + 1/di

# Espejo convexo (radio negativo) - retrovisor
R_conv = -0.50  # radio -50 cm (convexo)
do_lejos = 2.0  # objeto a 2 m

espejo2 = optica.espejoEsferico(R_conv, do_lejos)
escribir("\nESPEJO CONVEXO (RETROVISOR)")
escribir("f = " .. espejo2["focal"] .. " m")
escribir("di = " .. espejo2["distancia_imagen"] .. " m")
escribir("Aumento: " .. espejo2["aumento"])
escribir("Tipo: " .. espejo2["tipo_imagen"])
# Salida:
# ESPEJO CONVEXO (RETROVISOR)
# f = -0.25 m
# di = -0.22 m
# Aumento: 0.11
# Tipo: Virtual, derecha, reducida

# Objeto en el centro de curvatura (espejo cóncavo)
R_centro = 0.60
do_centro = 0.60  # objeto en el centro (do = R)
espejo3 = optica.espejoEsferico(R_centro, do_centro)
escribir("\nOBJETO EN EL CENTRO DE CURVATURA")
escribir("di = " .. espejo3["distancia_imagen"] .. " m")
escribir("Aumento: " .. espejo3["aumento"])
# Salida:
# OBJETO EN EL CENTRO DE CURVATURA
# di = 0.6 m
# Aumento: -1

# Objeto en el foco (espejo cóncavo)
R_foco = 0.40
do_foco = 0.20  # objeto en el foco (do = f)
espejo4 = optica.espejoEsferico(R_foco, do_foco)
escribir("\nOBJETO EN EL FOCO")
escribir("di = " .. espejo4["distancia_imagen"])
escribir("Tipo: " .. espejo4["tipo_imagen"])
# Salida:
# OBJETO EN EL FOCO
# di = infinito
# Tipo: Imagen en el infinito
```
