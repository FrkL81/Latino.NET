## 9.18 Plugin `formulas`

### 9.18.06 Librería `computacion`

La librería `computacion` proporciona funciones para cálculos fundamentales en ciencias de la computación, incluyendo teoría de la información, análisis de algoritmos y redes. Todas las funciones devuelven diccionarios con el resultado y la fórmula aplicada.

#### Referencia de Funciones

| Función | Argumentos | Descripción |
| :--- | :--- | :--- |
| `computacion.bitsNecesarios` | `(num_valores_posibles)` | Cantidad mínima de bits para representar n valores distintos. Fórmula: $bits = \lceil \log_2(n) \rceil$ |
| `computacion.entropiaShannon` | `(lista_probabilidades)` | Entropía de Shannon de una fuente de información (en bits). Fórmula: $H = -\sum p_i \log_2(p_i)$ |
| `computacion.probabilidadColisionHash` | `(num_elementos, tamano_tabla)` | Probabilidad aproximada de al menos una colisión en una tabla hash. Fórmula: $P \approx 1 - e^{-n^2/(2m)}$ |
| `computacion.productoAnchoBandaLatencia` | `(ancho_banda_bps, latencia_s)` | Producto ancho de banda × latencia (BDP). Fórmula: $BDP = BW \cdot RTT$ |
| `computacion.tiempoBusqueda` | `(n_elementos, tipo_algoritmo)` | Operaciones estimadas para buscar en n elementos. Tipos: 'lineal', 'binaria', 'hash', 'arbol_b' |

🎯 **Ejemplo: computacion.entropiaShannon**

Calcula la entropía de una fuente de información, que mide la incertidumbre promedio o contenido de información en bits.

```latino
incluir("formulas")

# Fuente con dos símbolos equiprobables (1 bit de entropía)
prob1 = [0.5, 0.5]
res1 = computacion.entropiaShannon(prob1)
escribir("Entropía (2 símbolos): " .. res1["resultado"] .. " bits")
# Salida: Entropía (2 símbolos): 1.0 bits

# Fuente con cuatro símbolos equiprobables (2 bits)
prob2 = [0.25, 0.25, 0.25, 0.25]
res2 = computacion.entropiaShannon(prob2)
escribir("Entropía (4 símbolos): " .. res2["resultado"] .. " bits")
# Salida: Entropía (4 símbolos): 2.0 bits

# Fuente con símbolos de probabilidades desiguales
prob3 = [0.5, 0.25, 0.15, 0.1]
res3 = computacion.entropiaShannon(prob3)
escribir("Entropía (desigual): " .. res3["resultado"] .. " bits")
# Salida: Entropía (desigual): 1.75 bits
```

🎯 **Ejemplo: computacion.probabilidadColisionHash**

Calcula la probabilidad aproximada de que ocurra al menos una colisión al insertar n elementos en una tabla hash de tamaño m (paradoja del cumpleaños).

```latino
incluir("formulas")

# Paradoja del cumpleaños: 23 personas, 365 días
res1 = computacion.probabilidadColisionHash(23, 365)
escribir("Probabilidad (23 personas): " .. res1["resultado"])
# Salida: Probabilidad (23 personas): 0.507

# Tabla hash pequeña
res2 = computacion.probabilidadColisionHash(10, 100)
escribir("10 elementos en tabla 100: " .. res2["resultado"])
# Salida: 10 elementos en tabla 100: 0.393

# Muchos elementos (probabilidad cercana a 1)
res3 = computacion.probabilidadColisionHash(50, 100)
escribir("50 elementos en tabla 100: " .. res3["resultado"])
# Salida: 50 elementos en tabla 100: 0.999
```

🎯 **Ejemplo: computacion.tiempoBusqueda**

Estima el número de operaciones necesarias para buscar un elemento según el algoritmo y la cantidad de datos. Útil para análisis de complejidad algorítmica.

```latino
incluir("formulas")

# Búsqueda lineal (O(n))
res1 = computacion.tiempoBusqueda(1000, "lineal")
escribir("Búsqueda lineal: " .. res1["resultado"] .. " operaciones")
# Salida: Búsqueda lineal: 1000 operaciones

# Búsqueda binaria (O(log n))
res2 = computacion.tiempoBusqueda(1000, "binaria")
escribir("Búsqueda binaria: " .. res2["resultado"] .. " operaciones")
# Salida: Búsqueda binaria: 10 operaciones

# Tabla hash (O(1))
res3 = computacion.tiempoBusqueda(1000, "hash")
escribir("Operaciones estimadas: " .. res3["resultado"])
# Salida: Operaciones estimadas: 1
escribir("Complejidad Big-O: " .. res3["big_o"])
# Salida: Complejidad Big-O: O(1) amortizado

# Árbol B (O(log n) con factor de ramificación)
res4 = computacion.tiempoBusqueda(1000000, "arbol_b")
escribir("Operaciones estimadas: " .. res4["resultado"])
# Salida: Operaciones estimadas: 20
escribir("Complejidad Big-O: " .. res4["big_o"])
# Salida: Complejidad Big-O: O(log n)
```

🎯 **Ejemplo: computacion.productoAnchoBandaLatencia**

Calcula el producto ancho de banda × latencia (BDP), que indica cuántos bits pueden estar "en tránsito" en un enlace de comunicaciones en un momento dado.

```latino
incluir("formulas")

# Enlace de 1 Gbps con latencia de 100 ms
ancho_banda = 1e9  # 1 Gbps en bps
latencia = 0.1     # 100 ms en segundos

res1 = computacion.productoAnchoBandaLatencia(ancho_banda, latencia)
escribir("BDP: " .. res1["resultado"] .. " bits")
# Salida: BDP: 100000000 bits

# Convertir a megabytes para mejor comprensión
mb = res1["resultado"] / 8 / 1024 / 1024
escribir("Equivalente: " .. mb .. " MB")
# Salida: Equivalente: 11.92 MB

# Enlace de fibra transoceánica
res2 = computacion.productoAnchoBandaLatencia(100e9, 0.15)  # 100 Gbps, 150 ms
escribir("BDP fibra: " .. (res2["resultado"] / 8 / 1e9) .. " GB")
# Salida: BDP fibra: 1.875 GB
```

🎯 **Ejemplo: computacion.bitsNecesarios**

Determina la cantidad mínima de bits requerida para representar un número dado de valores distintos.

```latino
incluir("formulas")

# Valores típicos
res1 = computacion.bitsNecesarios(256)
escribir("256 valores: " .. res1["resultado"] .. " bits")
# Salida: 256 valores: 8 bits

res2 = computacion.bitsNecesarios(65536)
escribir("65536 valores: " .. res2["resultado"] .. " bits")
# Salida: 65536 valores: 16 bits

# Casos no potencia de 2 (redondeo hacia arriba)
res3 = computacion.bitsNecesarios(10)
escribir("10 valores: " .. res3["resultado"] .. " bits")
# Salida: 10 valores: 4 bits (2³=8 no alcanza, 2⁴=16 sí)

res4 = computacion.bitsNecesarios(100)
escribir("100 valores: " .. res4["resultado"] .. " bits")
# Salida: 100 valores: 7 bits (2⁶=64 no alcanza, 2⁷=128 sí)
```
