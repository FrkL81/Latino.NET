## 9.18 Plugin `formulas`

### 9.18.10 Librería `electricidad`

La librería `electricidad` (y su extensión `electromagnetismo`) proporciona funciones para cálculos fundamentales de circuitos eléctricos y fenómenos electromagnéticos. Incluye desde la ley de Ohm hasta resonancia LC y transformadores. Todas las funciones devuelven diccionarios con el resultado, la unidad correspondiente y claves específicas según el tipo de cálculo.

#### 🗝️ Estructura de los Diccionarios de Retorno

| Función | Claves de Retorno |
| :--- | :--- |
| `leyOhm` | `"resultado"`, `"unidad"`, `"incognita"` |
| `leyCoulomb` | `"resultado"`, `"unidad"` |
| `campoElectrico` | `"resultado"`, `"unidad"` |
| `potencialElectrico` | `"resultado"`, `"unidad"` |
| `inductorEnergia` | `"resultado"`, `"unidad"` |
| `capacitorEnergia` | `"resultado"`, `"unidad"`, `"carga_almacenada_C"` |
| `potenciaElectrica` | `"resultado"`, `"unidad"`, `"formula_usada"` |
| `resonanciaLC` | `"resultado"`, `"unidad"`, `"periodo_s"`, `"omega_rad_s"` |
| `leyFaraday` | `"resultado"`, `"unidad"`, `"nota"` |
| `transformador` | `"resultado"`, `"unidad"`, `"relacion_transformacion"`, `"tipo"` |
| `filtroRC` | `"resultado"`, `"unidad"`, `"constante_tiempo_s"`, `"rango"`, `"nota"` |

#### Referencia de Funciones

| Función | Argumentos | Descripción |
| :--- | :--- | :--- |
| `electricidad.filtroRC` | `(resistenciaOhm, capacitanciaF)` | Frecuencia de corte de un filtro RC pasa-bajos. Fórmula: $f_c = \frac{1}{2\pi RC}$ |
| `electricidad.leyCoulomb` | `(carga1, carga2, distancia)` | Fuerza electrostática entre dos cargas. Fórmula: $F = k\frac{q_1 q_2}{r^2}$ |
| `electricidad.leyOhm` | `(diccionarioVariables)` | Ley de Ohm. Pasa 2 valores: 'V', 'I' o 'R'. Fórmula: $V = I \cdot R$ |
| `electromagnetismo.campoElectrico` | `(cargaC, distanciaM)` | Intensidad del campo eléctrico. Fórmula: $E = k\frac{\|q\|}{r^2}$ |
| `electromagnetismo.capacitorEnergia` | `(capacitanciaF, voltajeV)` | Energía en un capacitor. Fórmula: $U = \frac{1}{2}CV^2$ |
| `electromagnetismo.inductorEnergia` | `(inductanciaH, corrienteA)` | Energía en un inductor. Fórmula: $U = \frac{1}{2}LI^2$ |
| `electromagnetismo.leyFaraday` | `(numEspiras, deltaFlujoWb, deltaTiempoS)` | FEM inducida (Ley de Faraday). Fórmula: $\mathcal{E} = -N\frac{\Delta\Phi}{\Delta t}$ |
| `electromagnetismo.potenciaElectrica` | `(diccionarioVariables)` | Potencia eléctrica. Pasa 2 de: 'V', 'I', 'R'. Fórmulas: $P = VI$, $P = I^2R$, $P = V^2/R$ |
| `electromagnetismo.potencialElectrico` | `(cargaC, distanciaM)` | Potencial eléctrico. Fórmula: $V = k\frac{q}{r}$ |
| `electromagnetismo.resonanciaLC` | `(inductanciaH, capacitanciaF)` | Frecuencia de resonancia de un circuito LC. Fórmula: $f_0 = \frac{1}{2\pi\sqrt{LC}}$ |
| `electromagnetismo.transformador` | `(voltajePrimario, espirasPrimario, espirasSecundario)` | Voltaje en el secundario de un transformador ideal. Fórmula: $V_2 = V_1 \frac{N_2}{N_1}$ |

🎯 **Ejemplo: electricidad.leyOhm**

Función omni-solver para la ley de Ohm. A partir de dos variables conocidas (voltaje V, corriente I o resistencia R), calcula la tercera.

```latino
incluir("formulas")

# Calcular voltaje (V = I·R)
datos1 = {"I": 2, "R": 10}
res1 = electricidad.leyOhm(datos1)
escribir("Voltaje: " .. res1["resultado"] .. " " .. res1["unidad"])
# Salida: Voltaje: 20 V
escribir("Incógnita resuelta: " .. res1["incognita"])
# Salida: Incógnita resuelta: V

# Calcular corriente (I = V/R)
datos2 = {"V": 12, "R": 4}
res2 = electricidad.leyOhm(datos2)
escribir("Corriente: " .. res2["resultado"] .. " " .. res2["unidad"])
# Salida: Corriente: 3 A
escribir("Incógnita: " .. res2["incognita"])
# Salida: Incógnita: I

# Calcular resistencia (R = V/I)
datos3 = {"V": 120, "I": 0.5}
res3 = electricidad.leyOhm(datos3)
escribir("Resistencia: " .. res3["resultado"] .. " " .. res3["unidad"])
# Salida: Resistencia: 240 Ω
escribir("Incógnita: " .. res3["incognita"])
# Salida: Incógnita: R
```

🎯 **Ejemplo: electricidad.leyCoulomb**

Calcula la fuerza electrostática entre dos cargas puntuales. Las cargas se expresan en Coulombs (C) y la distancia en metros (m).

```latino
incluir("formulas")

# Dos cargas de 1 μC separadas 1 cm
q1 = 1e-6    # 1 μC
q2 = 1e-6    # 1 μC
r = 0.01     # 1 cm

res = electricidad.leyCoulomb(q1, q2, r)
escribir("Fuerza: " .. res["resultado"] .. " " .. res["unidad"])
# Salida: Fuerza: 89.8755 N

# Cargas opuestas
res2 = electricidad.leyCoulomb(1e-6, -1e-6, 0.01)
escribir("Fuerza (opuestas): " .. res2["resultado"] .. " N")
# Salida: Fuerza (opuestas): -89.8755 N
```

🎯 **Ejemplo: electromagnetismo.potenciaElectrica**

Función omni-solver para potencia eléctrica. A partir de dos variables conocidas (voltaje V, corriente I o resistencia R), calcula la potencia e indica qué fórmula se utilizó.

```latino
incluir("formulas")

# Potencia con V e I conocidos
datos1 = {"V": 12, "I": 2}
res1 = electromagnetismo.potenciaElectrica(datos1)
escribir("Potencia: " .. res1["resultado"] .. " " .. res1["unidad"])
# Salida: Potencia: 24 W
escribir("Fórmula usada: " .. res1["formula_usada"])
# Salida: Fórmula usada: P = V·I

# Potencia con I y R conocidos
datos2 = {"I": 2, "R": 6}
res2 = electromagnetismo.potenciaElectrica(datos2)
escribir("Potencia: " .. res2["resultado"] .. " W")
# Salida: Potencia: 24 W
escribir("Fórmula usada: " .. res2["formula_usada"])
# Salida: Fórmula usada: P = I²·R

# Potencia con V y R conocidos
datos3 = {"V": 12, "R": 4}
res3 = electromagnetismo.potenciaElectrica(datos3)
escribir("Potencia: " .. res3["resultado"] .. " W")
# Salida: Potencia: 36 W
escribir("Fórmula usada: " .. res3["formula_usada"])
# Salida: Fórmula usada: P = V²/R
```

🎯 **Ejemplo: electromagnetismo.leyFaraday**

Calcula la fuerza electromotriz inducida por variación de flujo magnético.

```latino
incluir("formulas")

# Bobina de 100 espiras, variación de flujo 0.5 Wb en 0.1 s
n = 100
delta_flujo = 0.5    # Wb

res = electromagnetismo.leyFaraday(n, delta_flujo, delta_t)
escribir("FEM inducida: " .. res["resultado"] .. " " .. res["unidad"])
# Salida: FEM inducida: -500 V
escribir("Nota: " .. res["nota"])
# Salida: Nota: El signo negativo indica oposición al cambio de flujo (Lenz)
```
