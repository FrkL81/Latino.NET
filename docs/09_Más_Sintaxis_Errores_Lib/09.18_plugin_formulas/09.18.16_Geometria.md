## 9.18 Plugin `formulas`

### 9.18.16 Librería `geometria`

La librería `geometria` proporciona funciones para cálculos geométricos fundamentales, incluyendo áreas, volúmenes y distancias para figuras bidimensionales y tridimensionales. Las funciones devuelven diccionarios con los resultados y la fórmula aplicada.

#### 🗝️ Estructura de los Diccionarios de Retorno

| Función | Claves del Diccionario Retornado |
| :--- | :--- |
| **Todas** | `formula` (las claves base como `resultado`, `unidad` varían según la función) |
| `geometria.areaCirculo` | `resultado`, `unidad`, `formula` |
| `geometria.cilindroCompleto` | `area_lateral`, `area_total`, `volumen`, `formula` |
| `geometria.cono` | `generatriz`, `area_base`, `area_lateral`, `area_total`, `volumen`, `formula` |
| `geometria.distanciaPuntos` | `resultado`, `unidad`, `formula` |
| `geometria.elipse` | `area`, `perimetro`, `excentricidad`, `formula` |
| `geometria.esfera` | `area_superficial`, `volumen`, `formula` |
| `geometria.piramideRectangular` | `area_base`, `area_lateral`, `area_total`, `volumen`, `formula` |
| `geometria.poligonoRegular` | `area`, `perimetro`, `apotema`, `angulo_interior`, `formula` |
| `geometria.trapecio` | `resultado`, `unidad`, `formula` |

> **Nota:** Las funciones de figuras 3D (`cilindroCompleto`, `esfera`, `cono`, `piramideRectangular`) y 2D avanzadas (`elipse`, `poligonoRegular`) no retornan `resultado` ni `unidad`, sino campos directos de la figura. Para obtener un valor de área/volumen, accede a la clave específica (ej: `resultado["area_total"]`, `resultado["volumen"]`).

#### Referencia de Funciones

| Función | Argumentos | Descripción |
| :--- | :--- | :--- |
| `geometria.areaCirculo` | `(radio)` | Calcula el área de un círculo. Fórmula: $A = \pi \cdot r^2$ |
| `geometria.cilindroCompleto` | `(radio, altura)` | Área y volumen de un cilindro. Fórmulas: $A_{lat} = 2\pi rh$, $A_{tot} = 2\pi r(h+r)$, $V = \pi r^2 h$ |
| `geometria.cono` | `(radio, altura)` | Área total y volumen de un cono recto. Fórmulas: $g = \sqrt{r^2 + h^2}$, $A_{tot} = \pi r(r+g)$, $V = \frac{1}{3}\pi r^2 h$ |
| `geometria.distanciaPuntos` | `(diccionario_puntos)` | Distancia euclidiana entre dos puntos en 2D o 3D. Pasa: `{'x1','y1','x2','y2'}` o `{'x1','y1','z1','x2','y2','z2'}` |
| `geometria.elipse` | `(semieje_mayor, semieje_menor)` | Área, perímetro aproximado y excentricidad de una elipse. Fórmulas: $A = \pi \cdot a \cdot b$, $e = \sqrt{1 - \frac{b^2}{a^2}}$ |
| `geometria.esfera` | `(radio)` | Área superficial y volumen de una esfera. Fórmulas: $A = 4\pi r^2$, $V = \frac{4}{3}\pi r^3$ |
| `geometria.piramideRectangular` | `(base_largo, base_ancho, altura)` | Área total y volumen de una pirámide de base rectangular. Fórmula: $V = \frac{1}{3} \cdot A_{base} \cdot h$ |
| `geometria.poligonoRegular` | `(num_lados, longitud_lado)` | Área y perímetro de un polígono regular. Fórmula: $A = \frac{n \cdot l^2}{4 \cdot \tan(\pi/n)}$ |
| `geometria.trapecio` | `(base_mayor, base_menor, altura)` | Área de un trapecio. Fórmula: $A = \frac{(B + b)}{2} \cdot h$ |

🎯 **Ejemplo: geometria.areaCirculo**

Calcula el área de un círculo dado su radio. Retorna un diccionario con las claves base.

```latino
incluir("formulas")

# Círculo de radio 5 metros
radio = 5
area = geometria.areaCirculo(radio)
escribir("ÁREA DEL CÍRCULO")
escribir("Radio: " .. radio .. " m")
escribir("Resultado: " .. area["resultado"] .. " " .. area["unidad"])
escribir("Fórmula: " .. area["formula"])
# Salida:
# ÁREA DEL CÍRCULO
# Radio: 5 m
# Resultado: 78.539816339745 m²
# Fórmula: A = π·r²
```

🎯 **Ejemplo: geometria.cilindroCompleto**

Calcula el área lateral, área total y volumen de un cilindro recto.

```latino
incluir("formulas")

# Cilindro de radio 3 m y altura 10 m

cil = geometria.cilindroCompleto(radio, altura)
escribir("CILINDRO")
escribir("Radio: " .. radio .. " m, Altura: " .. altura .. " m")
escribir("Resultado (volumen): " .. cil["volumen"] .. " m³")
escribir("Área lateral: " .. cil["area_lateral"] .. " m²")
escribir("Área total: " .. cil["area_total"] .. " m²")
escribir("Volumen: " .. cil["volumen"] .. " m³")
escribir("Fórmula: " .. cil["formula"])
# Salida:
# Radio: 3 m, Altura: 10 m
# Resultado (volumen): 282.7433388230814 m³
# Área lateral: 188.49555921538757 m²
# Área total: 245.04422698000386 m²
# Volumen: 282.7433388230814 m³
# Fórmula: A_lat = 2πrh | A_tot = 2πr(h+r) | V = πr²h
```

🎯 **Ejemplo: geometria.distanciaPuntos**

Calcula la distancia euclidiana entre dos puntos en 2D o 3D. Retorna un diccionario con las claves base.

```latino
incluir("formulas")

# Distancia 2D entre puntos (0,0) y (3,4)
p2d = {"x1": 0, "y1": 0, "x2": 3, "y2": 4}

dist2d = geometria.distanciaPuntos(p2d)
escribir("DISTANCIA 2D")
escribir("Punto A: (0, 0)")
escribir("Punto B: (3, 4)")
escribir("Resultado: " .. dist2d["resultado"] .. " " .. dist2d["unidad"])
escribir("Fórmula: " .. dist2d["formula"])
# Salida:
# DISTANCIA 2D
# Punto A: (0, 0)
# Punto B: (3, 4)
# Resultado: 5 m
# Fórmula: d = √((x₂-x₁)² + (y₂-y₁)²)

# Distancia 3D entre puntos en el espacio
p3d = {"x1": 1, "y1": 2, "z1": 3, "x2": 4, "y2": 5, "z2": 6}

dist3d = geometria.distanciaPuntos(p3d)
escribir("\nDISTANCIA 3D")
escribir("Punto A: (1, 2, 3)")
escribir("Punto B: (4, 5, 6)")
escribir("Resultado: " .. dist3d["resultado"] .. " " .. dist3d["unidad"])
# Salida:
# DISTANCIA 3D
# Punto A: (1, 2, 3)
# Punto B: (4, 5, 6)
# Resultado: 5.1961524227066 m
```
