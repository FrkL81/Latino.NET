## 9.18 Plugin `formulas`

### 9.18.05 Librería `cinematica`

La librería `cinematica` proporciona funciones para el estudio del movimiento de los cuerpos, incluyendo movimientos rectilíneos, energía mecánica y tiro parabólico. Las funciones devuelven diccionarios con el resultado, la unidad correspondiente y la fórmula aplicada.

#### Referencia de Funciones

| Función | Argumentos | Descripción |
| :--- | :--- | :--- |
| `cinematica.energiaCinetica` | `(masa, velocidad)` | Energía cinética. Fórmula: $E_c = \frac{1}{2} m v^2$ |
| `cinematica.energiaPotencial` | `(masa, altura)` | Energía potencial gravitatoria. Fórmula: $E_p = m \cdot g \cdot h$ |
| `cinematica.impulso` | `(fuerza, tiempo)` | Impulso de una fuerza. Fórmula: $J = F \cdot \Delta t$ |
| `cinematica.momentoLineal` | `(masa, velocidad)` | Cantidad de movimiento. Fórmula: $p = m \cdot v$ |
| `cinematica.mru` | `(diccionarioVariables)` | Movimiento Rectilíneo Uniforme. Pasa 2 de: 'v', 'd', 't'. Fórmula: $v = \frac{d}{t}$ |
| `cinematica.mruaPosicion` | `(posicionInicial, velocidadInicial, aceleracion, tiempo)` | Posición en MRUA. Fórmula: $x = x_0 + v_0 \cdot t + \frac{1}{2} a \cdot t^2$ |
| `cinematica.mruaVelocidad` | `(velocidadInicial, aceleracion, tiempo)` | Velocidad final en MRUA. Fórmula: $v = v_0 + a \cdot t$ |
| `cinematica.tiroParabolico` | `(velocidadInicial, anguloGrados)` | Componentes de tiro parabólico. Fórmulas: $h_{max} = \frac{v_0^2 \sin^2\theta}{2g}$, $d_{max} = \frac{v_0^2 \sin 2\theta}{g}$ |

🎯 **Ejemplo: Solución de Movimiento Rectilíneo Uniforme con cinematica.mru**

Función omni-solver para el Movimiento Rectilíneo Uniforme. A partir de dos variables conocidas (velocidad v, distancia d o tiempo t), calcula la tercera.

```latino
incluir("formulas")

# Calcular velocidad (v = d/t)
datos1 = {"d": 100, "t": 20}
res1 = cinematica.mru(datos1)
escribir("Velocidad: " .. res1["resultado"] .. " " .. res1["unidad"])
# Salida: Velocidad: 5 m/s

# Calcular tiempo (t = d/v)
datos2 = {"d": 200, "v": 10}
res2 = cinematica.mru(datos2)
escribir("Tiempo: " .. res2["resultado"] .. " " .. res2["unidad"])
# Salida: Tiempo: 20 s

# Calcular distancia (d = v·t)
datos3 = {"v": 15, "t": 8}
res3 = cinematica.mru(datos3)
escribir("Distancia: " .. res3["resultado"] .. " " .. res3["unidad"])
# Salida: Distancia: 120 m
```

🎯 **Ejemplo: cinematica.mruaVelocidad**

Calcula la velocidad final en un movimiento rectilíneo uniformemente acelerado (MRUA).

```latino
incluir("formulas")

# Auto que acelera desde el reposo
v0 = 0        # m/s
a = 2         # m/s²
t = 5         # segundos

res = cinematica.mruaVelocidad(v0, a, t)
escribir("Velocidad final: " .. res["resultado"] .. " " .. res["unidad"])
# Salida: Velocidad final: 10 m/s

# Fórmula aplicada
escribir("Fórmula: " .. res["formula"])
# Salida: Fórmula: v = v₀ + a·t
```

🎯 **Ejemplo: cinematica.mruaPosicion**

Calcula la posición final en un movimiento rectilíneo uniformemente acelerado (MRUA).

```latino
incluir("formulas")

# Móvil con posición inicial 10 m, velocidad 5 m/s, aceleración 2 m/s² durante 3 s
x0 = 10
v0 = 5
a = 2
t = 3

res = cinematica.mruaPosicion(x0, v0, a, t)
escribir("Posición final: " .. res["resultado"] .. " " .. res["unidad"])
# Salida: Posición final: 34 m

# Verificación manual: 10 + 5·3 + ½·2·9 = 10 + 15 + 9 = 34
```

🎯 **Ejemplo: cinematica.energiaCinetica**

Calcula la energía cinética de un cuerpo en movimiento.

```latino
incluir("formulas")

# Vehículo de 1000 kg a 20 m/s (72 km/h)
masa = 1000   # kg
vel = 20      # m/s

res = cinematica.energiaCinetica(masa, vel)
escribir("Energía cinética: " .. res["resultado"] .. " " .. res["unidad"])
# Salida: Energía cinética: 200000 J

# A mayor velocidad, la energía crece al cuadrado
res2 = cinematica.energiaCinetica(masa, 40)
escribir("A 40 m/s: " .. res2["resultado"] .. " J")
# Salida: A 40 m/s: 800000 J
```

🎯 **Ejemplo: cinematica.energiaPotencial**

Calcula la energía potencial gravitatoria de un cuerpo elevado sobre la superficie terrestre. Utiliza $g = 9.80665 \, m/s^2$.

```latino
incluir("formulas")

# Objeto de 5 kg a 10 metros de altura
masa = 5      # kg
altura = 10   # metros

res = cinematica.energiaPotencial(masa, altura)
escribir("Energía potencial: " .. res["resultado"] .. " " .. res["unidad"])
# Salida: Energía potencial: 490.3325 J

# Comparación con diferentes alturas
res2 = cinematica.energiaPotencial(masa, 20)
escribir("A 20 m: " .. res2["resultado"] .. " J")
# Salida: A 20 m: 980.665 J
```

🎯 **Ejemplo: cinematica.momentoLineal**

Calcula la cantidad de movimiento (momento lineal) de un cuerpo.

```latino
incluir("formulas")

# Camión de 5000 kg a 15 m/s
masa = 5000   # kg
vel = 15      # m/s

res = cinematica.momentoLineal(masa, vel)
escribir("Momento lineal: " .. res["resultado"] .. " " .. res["unidad"])
# Salida: Momento lineal: 75000 kg·m/s

# Objeto pequeño a alta velocidad
res2 = cinematica.momentoLineal(0.5, 100)
escribir("Proyectil: " .. res2["resultado"] .. " kg·m/s")
# Salida: Proyectil: 50 kg·m/s
```

🎯 **Ejemplo: cinematica.impulso**

Calcula el impulso mecánico, equivalente a la variación del momento lineal.

```latino
incluir("formulas")

# Fuerza constante de 100 N aplicada durante 2 segundos
fuerza = 100   # Newtons
tiempo = 2     # segundos

res = cinematica.impulso(fuerza, tiempo)
escribir("Impulso: " .. res["resultado"] .. " " .. res["unidad"])
# Salida: Impulso: 200 N·s

# Relación con momento lineal
escribir("Equivale a: " .. res["formula"])
# Salida: Equivale a: J = F·Δt
```

🎯 **Ejemplo: cinematica.tiroParabolico**

Calcula los parámetros principales de un tiro parabólico: altura máxima, alcance máximo y tiempo de vuelo.

```latino
incluir("formulas")

# Proyectil lanzado a 50 m/s con ángulo de 45°
v0 = 50
angulo = 45

res = cinematica.tiroParabolico(v0, angulo)
escribir("Altura máxima: " .. res["altura_maxima"] .. " m")
# Salida: Altura máxima: 63.78 m

escribir("Alcance máximo: " .. res["alcance_maximo"] .. " m")
# Salida: Alcance máximo: 254.97 m

escribir("Tiempo de vuelo: " .. res["tiempo_vuelo"] .. " s")
# Salida: Tiempo de vuelo: 7.21 s

# Lanzamiento con ángulo bajo (30°)
res2 = cinematica.tiroParabolico(50, 30)
escribir("A 30° - Alcance: " .. res2["alcance_maximo"] .. " m")
# Salida: A 30° - Alcance: 220.81 m

# Lanzamiento vertical (90°)
res3 = cinematica.tiroParabolico(50, 90)
escribir("A 90° - Altura: " .. res3["altura_maxima"] .. " m")
# Salida: A 90° - Altura: 127.55 m
escribir("Alcance: " .. res3["alcance_maximo"] .. " m")
# Salida: Alcance: 0 m
```
