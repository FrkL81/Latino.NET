## 9.18 Plugin `formulas`

### 9.18.07 Librería `dinamica`

La librería `dinamica` proporciona funciones para el estudio de las fuerzas y sus efectos sobre el movimiento de los cuerpos, incluyendo trabajo, energía, potencia y movimiento rotacional. Todas las funciones devuelven diccionarios con el resultado, la unidad correspondiente y la fórmula aplicada.

#### Referencia de Funciones

| Función | Argumentos | Descripción |
| :--- | :--- | :--- |
| `dinamica.energiaMecanica` | `(masa, velocidad, altura)` | Energía mecánica total (cinética + potencial). Fórmula: $E_m = \frac{1}{2}mv^2 + mgh$ |
| `dinamica.newtonFuerza` | `(masa, aceleracion)` | Segunda Ley de Newton. Fórmula: $F = m \cdot a$ |
| `dinamica.penduloSimple` | `(longitud)` | Período de oscilación de un péndulo simple. Fórmula: $T = 2\pi \sqrt{L/g}$ |
| `dinamica.peso` | `(masa)` | Peso de un objeto en la superficie terrestre ($g = 9.80665 \, m/s^2$). Fórmula: $W = m \cdot g$ |
| `dinamica.potencia` | `(trabajo, tiempo)` | Potencia mecánica media. Fórmula: $P = W / t$ |
| `dinamica.segundaLeyRotacional` | `(momento_inercia, aceleracion_angular)` | Segunda Ley de Newton para rotación. Fórmula: $\tau = I \cdot \alpha$ |
| `dinamica.trabajo` | `(fuerza, distancia, anguloGrados)` | Calcula el trabajo mecánico. Fórmula: $W = F \cdot d \cdot \cos(\theta)$ |

🎯 **Ejemplo: dinamica.trabajo**

Calcula el trabajo mecánico realizado por una fuerza constante al desplazar un objeto. El ángulo se expresa en grados.

```latino
incluir("formulas")

# Fuerza de 100 N aplicada en dirección del movimiento (0°) sobre 5 metros
res1 = dinamica.trabajo(100, 5, 0)
escribir("Trabajo: " .. res1["resultado"] .. " " .. res1["unidad"])
# Salida: Trabajo: 500 J

# Fuerza aplicada con ángulo de 60°
res2 = dinamica.trabajo(100, 5, 60)
escribir("Trabajo a 60°: " .. res2["resultado"] .. " J")
# Salida: Trabajo a 60°: 250 J

# Fuerza perpendicular al movimiento (90°) → trabajo nulo
res3 = dinamica.trabajo(100, 5, 90)
escribir("Trabajo perpendicular: " .. res3["resultado"] .. " J")
# Salida: Trabajo perpendicular: 0 J
```

🎯 **Ejemplo: dinamica.newtonFuerza**

Aplica la segunda ley de Newton para calcular la fuerza necesaria para acelerar una masa.

```latino
incluir("formulas")

# Acelerar un auto de 1000 kg a 3 m/s²
res1 = dinamica.newtonFuerza(1000, 3)
escribir("Fuerza necesaria: " .. res1["resultado"] .. " " .. res1["unidad"])
# Salida: Fuerza necesaria: 3000 N

# Empujar un objeto pequeño
res2 = dinamica.newtonFuerza(2, 5)
escribir("Fuerza: " .. res2["resultado"] .. " N")
# Salida: Fuerza: 10 N
```

🎯 **Ejemplo: dinamica.peso**

Calcula el peso de un objeto en la superficie terrestre, considerando la aceleración gravitacional estándar.

```latino
incluir("formulas")

# Persona de 70 kg
res1 = dinamica.peso(70)
escribir("Peso: " .. res1["resultado"] .. " " .. res1["unidad"])
# Salida: Peso: 686.47 N

# Objeto de 10 kg
res2 = dinamica.peso(10)
escribir("Peso: " .. res2["resultado"] .. " N")
# Salida: Peso: 98.07 N
```

🎯 **Ejemplo: dinamica.energiaMecanica**

Calcula la energía mecánica total de un cuerpo, sumando su energía cinética y su energía potencial gravitatoria.

```latino
incluir("formulas")

# Objeto de 2 kg a 10 m/s y 5 m de altura
res1 = dinamica.energiaMecanica(2, 10, 5)
escribir("Energía mecánica: " .. res1["resultado"] .. " " .. res1["unidad"])
# Salida: Energía mecánica: 198.07 J

# Componentes por separado
escribir("Energía cinética: " .. res1["energia_cinetica"] .. " J")
escribir("Energía potencial: " .. res1["energia_potencial"] .. " J")
# Salida: Energía cinética: 100 J
# Salida: Energía potencial: 98.13 J
```

🎯 **Ejemplo: dinamica.potencia**

Calcula la potencia mecánica media, que es la rapidez con la que se realiza un trabajo.

```latino
incluir("formulas")

# Realizar 500 J de trabajo en 2 segundos
res1 = dinamica.potencia(500, 2)
escribir("Potencia: " .. res1["resultado"] .. " " .. res1["unidad"])
# Salida: Potencia: 250 W

# Motor que realiza 10000 J en 5 segundos
res2 = dinamica.potencia(10000, 5)
escribir("Potencia del motor: " .. res2["resultado"] .. " W")
# Salida: Potencia del motor: 2000 W (2 kW)
```

🎯 **Ejemplo: dinamica.penduloSimple**

Calcula el período de oscilación de un péndulo simple para pequeñas amplitudes, utilizando la aceleración gravitacional estándar.

```latino
incluir("formulas")

# Péndulo de 1 metro de longitud
res1 = dinamica.penduloSimple(1)
escribir("Período: " .. res1["resultado"] .. " " .. res1["unidad"])
# Salida: Período: 2.006 s

# Péndulo de 2 metros
res2 = dinamica.penduloSimple(2)
escribir("Período (L=2m): " .. res2["resultado"] .. " s")
# Salida: Período (L=2m): 2.837 s

# Péndulo de 0.5 metros
res3 = dinamica.penduloSimple(0.5)
escribir("Período (L=0.5m): " .. res3["resultado"] .. " s")
# Salida: Período (L=0.5m): 1.418 s
```

🎯 **Ejemplo: dinamica.segundaLeyRotacional**

Calcula el torque (momento de fuerza) necesario para producir una aceleración angular en un cuerpo con determinado momento de inercia.

```latino
incluir("formulas")

# Disco con momento de inercia 0.5 kg·m², aceleración angular 2 rad/s²
res1 = dinamica.segundaLeyRotacional(0.5, 2)
escribir("Torque: " .. res1["resultado"] .. " " .. res1["unidad"])
# Salida: Torque: 1 N·m

# Volante de inercia grande
res2 = dinamica.segundaLeyRotacional(10, 0.5)
escribir("Torque requerido: " .. res2["resultado"] .. " N·m")
# Salida: Torque requerido: 5 N·m
```
