## 9.18 Plugin `formulas`

### 9.18.15 Librería `fluidos`

La librería `fluidos` proporciona funciones para el análisis de mecánica de fluidos, incluyendo el cálculo del número de Reynolds para determinar el régimen de flujo. Las funciones devuelven diccionarios con el resultado, diagnóstico del régimen y la fórmula aplicada.

#### 🗝️ Estructura de los Diccionarios de Retorno

| Función | Claves del Diccionario Retornado |
| :--- | :--- |
| `fluidos.reynolds` | `resultado`, `unidad`, `regimen`, `formula` |

#### Referencia de Funciones

| Función | Argumentos | Descripción |
| :--- | :--- | :--- |
| `fluidos.reynolds` | `(densidad, velocidad, diametro, viscosidad)` | Calcula el número de Reynolds y su régimen. Fórmula: $Re = \frac{\rho \cdot v \cdot D}{\mu}$ |

🎯 **Ejemplo: fluidos.reynolds**

Calcula el número de Reynolds, un parámetro adimensional que caracteriza el régimen de flujo de un fluido (laminar, transicional o turbulento). El resultado incluye una clasificación automática del tipo de flujo.

```latino
incluir("formulas")

# Agua a 20°C fluyendo por una tubería de 0.1 m de diámetro
# Densidad del agua: 1000 kg/m³
# Velocidad: 1.5 m/s
# Viscosidad dinámica del agua: 0.001 Pa·s
densidad = 1000    # kg/m³
velocidad = 1.5    # m/s
diametro = 0.1     # m
viscosidad = 0.001 # Pa·s

re = fluidos.reynolds(densidad, velocidad, diametro, viscosidad)
escribir("NÚMERO DE REYNOLDS (AGUA)")
escribir("Re = " .. re["resultado"])
escribir("Régimen: " .. re["regimen"])
escribir("Unidad: " .. re["unidad"])
escribir("Fórmula: " .. re["formula"])
# Salida:
# NÚMERO DE REYNOLDS (AGUA)
# Re = 150000
# Régimen: Turbulento
# Unidad: adimensional
# Fórmula: Re = (ρ·v·D) / μ

# Flujo de aceite lubricante (más viscoso)
# Densidad del aceite: 850 kg/m³
# Velocidad: 0.5 m/s
# Diámetro: 0.05 m
# Viscosidad del aceite: 0.1 Pa·s
re_aceite = fluidos.reynolds(850, 0.5, 0.05, 0.1)
escribir("ACEITE LUBRICANTE")
escribir("Re = " .. re_aceite["resultado"])
escribir("Régimen: " .. re_aceite["regimen"])
# Salida:
# ACEITE LUBRICANTE
# Re = 212.5
# Régimen: Laminar

# Flujo de aire en un conducto de ventilación
# Densidad del aire: 1.225 kg/m³
# Velocidad: 10 m/s
# Diámetro: 0.3 m
# Viscosidad del aire: 1.81e-5 Pa·s
re_aire = fluidos.reynolds(1.225, 10, 0.3, 1.81e-5)
escribir("AIRE EN CONDUCTO")
escribir("Re = " .. re_aire["resultado"])
escribir("Régimen: " .. re_aire["regimen"])
# Salida:
# AIRE EN CONDUCTO
# Re = 203038.67
# Régimen: Turbulento

# Analizar diferentes velocidades en una tubería de agua
diametro_tuberia = 0.05  # 5 cm
velocidades = [0.1, 0.5, 1.0, 2.0, 5.0]  # m/s

escribir("\nANÁLISIS DE RÉGIMEN PARA AGUA (D=5cm)")
para v en velocidades
    re_temp = fluidos.reynolds(1000, v, diametro_tuberia, 0.001)
    escribir("v=" .. v .. " m/s → Re=" .. re_temp["resultado"] .. " (" .. re_temp["regimen"] .. ")")
fin
# Salida:
# ANÁLISIS DE RÉGIMEN PARA AGUA (D=5cm)
# v=0.1 m/s → Re=5000 (Transicional)
# v=0.5 m/s → Re=25000 (Turbulento)
# v=1.0 m/s → Re=50000 (Turbulento)
# v=2.0 m/s → Re=100000 (Turbulento)
# v=5.0 m/s → Re=250000 (Turbulento)

# Comparar diferentes diámetros a velocidad constante
diametros = [0.01, 0.025, 0.05, 0.1, 0.2]  # metros
velocidad_fija = 1.0  # m/s

escribir("\nEFECTO DEL DIÁMETRO (agua, v=1 m/s)")
para d en diametros
    re_temp = fluidos.reynolds(1000, velocidad_fija, d, 0.001)
    escribir("D=" .. (d*100) .. " cm → Re=" .. re_temp["resultado"] .. " (" .. re_temp["regimen"] .. ")")
fin
# Salida:
# EFECTO DEL DIÁMETRO (agua, v=1 m/s)
# D=1 cm → Re=10000 (Turbulento)
# D=2.5 cm → Re=25000 (Turbulento)
# D=5 cm → Re=50000 (Turbulento)
# D=10 cm → Re=100000 (Turbulento)
# D=20 cm → Re=200000 (Turbulento)

# Ejemplo con fluido muy viscoso (miel)
# Densidad de la miel: 1400 kg/m³
# Velocidad: 0.05 m/s
# Diámetro: 0.02 m
# Viscosidad de la miel: 10 Pa·s
re_miel = fluidos.reynolds(1400, 0.05, 0.02, 10)
escribir("\nMIEL (fluido muy viscoso)")
escribir("Re = " .. re_miel["resultado"])
escribir("Régimen: " .. re_miel["regimen"])
# Salida:
# MIEL (fluido muy viscoso)
# Re = 0.14
# Régimen: Laminar

# Clasificación de regímenes según el valor de Re
# Re < 2000: Laminar
# 2000 ≤ Re < 4000: Transicional
# Re ≥ 4000: Turbulento
```
