## 9.18 Plugin `formulas`

### 9.18.22 Librería `optimizacion`

La librería `optimizacion` proporciona métodos numéricos avanzados para encontrar mínimos de funciones (optimización 1D y Multidimensional) y resolver problemas de Programación Lineal.

> **Nota General:** Todas las funciones de optimización no lineal buscan **minimizar** la función objetivo. Si deseas buscar un máximo, debes multiplicar tu función por `-1` (ej: `retornar -f(x)`).

#### 🗝️ Estructura de los Diccionarios de Retorno

| Función | Claves del Diccionario Retornado |
| :--- | :--- |
| **Todas** | `optimo`, `f_optimo`, `convergio`, `iteraciones`, `error_estimado`, `formula` |
| `optimizacion.bfgs` | `optimo`, `f_optimo`, `convergio`, `iteraciones`, `error_estimado`, `formula` |
| `optimizacion.brent1D` | `optimo`, `f_optimo`, `convergio`, `iteraciones`, `error_estimado`, `formula` |
| `optimizacion.busquedaCuadricula` | `optimo`, `f_optimo`, `evaluaciones`, `formula`, `nota` |
| `optimizacion.descensoGradiente` | `optimo`, `f_optimo`, `convergio`, `iteraciones`, `error_estimado`, `formula`, `tasa_final` |
| `optimizacion.genetico` | `optimo`, `f_optimo`, `convergio`, `iteraciones`, `error_estimado`, `formula`, `nota` |
| `optimizacion.nelderMead` | `optimo`, `f_optimo`, `convergio`, `iteraciones`, `error_estimado`, `formula` |
| `optimizacion.recocidoSimulado` | `optimo`, `f_optimo`, `convergio`, `iteraciones`, `error_estimado`, `formula`, `temperatura_final`, `tasa_aceptacion`, `nota` |
| `optimizacion.seccionAurea` | `optimo`, `f_optimo`, `convergio`, `iteraciones`, `error_estimado`, `formula` |
| `optimizacion.simplexLineal` | `solucion`, `f_optimo`, `estado`, `iteraciones`, `holguras`, `formula` |

> **Nota:** La clave principal es `optimo` (no `resultado`) y el valor de la función en el óptimo es `f_optimo` (no `f_x`).

#### Referencia de Funciones

| Función | Argumentos | Descripción |
| :--- | :--- | :--- |
| `optimizacion.bfgs` | `(funcion, listaX0, [tolerancia], [maxIter])` | Minimiza f(X) con el método cuasi-Newton BFGS. |
| `optimizacion.brent1D` | `(funcion, a, b, [tolerancia], [maxIter])` | Minimiza f(x) en [a, b] con el Método de Brent para optimización 1D. |
| `optimizacion.busquedaCuadricula` | `(funcion, lista_limites_inf, lista_limites_sup, lista_n_puntos)` | Evalúa f(X) en una cuadrícula regular y retorna el mejor punto encontrado. |
| `optimizacion.descensoGradiente` | `(funcion, listaX0, [tasa], [tolerancia], [maxIter])` | Minimiza f(X) con el Método de Descenso de Gradiente. |
| `optimizacion.genetico` | `(funcion, listaLimitesInf, listaLimitesSup, [tamPoblacion], [generaciones], [tolerancia], [semilla])` | Minimiza f(X) mediante un Algoritmo Genético de valor real. |
| `optimizacion.nelderMead` | `(funcion, listaX0, [escalaInicial], [tolerancia], [maxIter])` | Minimiza f(X) con el Método de Nelder-Mead (Simplex Downhill). |
| `optimizacion.recocidoSimulado` | `(funcion, listaX0, listaLimitesInf, listaLimitesSup, [tempInicial], [maxIter])` | Minimiza f(X) con el Método de Recocido Simulado. |
| `optimizacion.seccionAurea` | `(funcion, a, b, [tolerancia], [maxIter])` | Minimiza f(x) en el intervalo [a, b] usando el Método de Sección Áurea. |
| `optimizacion.simplexLineal` | `(listaC, matrizA, listaB)` | Resuelve un problema de Programación Lineal estándar (maximización con restricciones ≤). |

🎯 **Ejemplo: optimizacion.seccionAurea**

Minimiza $f(x)$ en el intervalo cerrado $[a, b]$ usando el Método de la Sección Áurea. Es extremadamente robusto y no requiere derivadas.

```latino
incluir("formulas")

# Encontrar el mínimo de f(x) = (x-2)² + 1 en [0, 5] (El mínimo real es x=2)
f_parabola = fun(x) ret (x-2)^2 + 1 fin

res = optimizacion.seccionAurea(f_parabola, 0, 5)
escribir("x óptimo: " .. res["optimo"][0])  # Salida: x óptimo: 2.0
escribir("Valor mínimo: " .. res["f_optimo"]) # Salida: Valor mínimo: 1.0
```

🎯 **Ejemplo: optimizacion.brent1D**

Minimiza $f(x)$ combinando la robustez de la Sección Áurea con la velocidad de la Interpolación Cuadrática. Es el método recomendado para funciones de una sola variable.

```latino
incluir("formulas")

f_parabola = fun(x) ret (x-2)^2 + 1 fin
res = optimizacion.brent1D(f_parabola, 0, 5)

escribir("x óptimo: " .. res["optimo"][0])  # Salida: x óptimo: 2.0
escribir("Iteraciones: " .. res["iteraciones"]) # Converge mucho más rápido que seccionAurea
```

🎯 **Ejemplo: optimizacion.descensoGradiente**

Minimiza una función multidimensional $f(X)$ moviéndose en dirección contraria al gradiente.

```latino
incluir("formulas")

# Minimizar f(x,y) = x² + y² (Mínimo real en [0,0])
f_2d = fun(v) ret v[0]^2 + v[1]^2 fin

res = optimizacion.descensoGradiente(f_2d, [5, 5])
escribir("Óptimo: " .. res["optimo"]) # Salida: Óptimo: [3.5336350475342664E-07, 3.5336350475342664E-07]
escribir("Valor: " .. res["f_optimo"])  # Salida: Valor: 2.4973153298324995E-13
```

🎯 **Ejemplo: optimizacion.bfgs**

Método Cuasi-Newton (Broyden-Fletcher-Goldfarb-Shanno). Es el algoritmo de optimización multidimensional más eficiente del motor para funciones suaves.

```latino
incluir("formulas")

f_2d = fun(v) ret v[0]^2 + v[1]^2 fin

# BFGS converge en muy pocas iteraciones comparado con el Descenso de Gradiente
res = optimizacion.bfgs(f_2d, [5, 5])
escribir("Convergió: " .. res["convergio"]) # Salida: Convergió: cierto
```

🎯 **Ejemplo: optimizacion.nelderMead**

Método del Simplex (Downhill). Minimiza funciones multidimensionales sin calcular gradientes, ideal para funciones con "ruido" o no diferenciables.

```latino
incluir("formulas")

f_2d = fun(v) ret v[0]^2 + v[1]^2 fin
res = optimizacion.nelderMead(f_2d, [3, 4])

escribir("Óptimo: " .. res["optimo"]) # Salida: Óptimo: [8.32263611970715E-05, -7.31521958670377E-05]
```

🎯 **Ejemplo: optimizacion.genetico**

Algoritmo heurístico de búsqueda global. Explora todo el dominio para escapar de mínimos locales utilizando selección natural, cruce y mutación.

```latino
incluir("formulas")

f_2d = fun(v) ret v[0]^2 + v[1]^2 fin

# Buscar en el cuadrado[-5, -5] a [5, 5]
res = optimizacion.genetico(f_2d, [-5, -5], [5, 5])
escribir("Óptimo encontrado: " .. res["optimo"]) 
```

🎯 **Ejemplo: optimizacion.simplexLineal**

Resuelve problemas de Programación Lineal (maximización de recursos) sujetos a restricciones estrictas de tipo $\le$.
El algoritmo asume que todas las variables son positivas ($x \ge 0$).

**Importante:** Para maximizar, debes pasar los coeficientes de la función objetivo (`listaC`) en **negativo**.

```latino
incluir("formulas")

# Problema de la Fábrica (Maximizar ganancias):
# Ganancia Z = 3x + 2y
# Restricciones (Horas de máquina, materia prima, etc.):
#   2x + y <= 100
#    x + y <= 80
#    x     <= 40

# 1. Pasamos los coeficientes de ganancia en NEGATIVO
c = [-3, -2]  

# 2. Matriz de restricciones (Lado Izquierdo)
A = [
    [2, 1],
    [1, 1],
    [1, 0]
]

# 3. Límites de restricciones (Lado Derecho)
b = [100, 80, 40]

opt = optimizacion.simplexLineal(c, A, b)

escribir("Producir X: " .. opt["solucion"][0]) # Salida: 20
escribir("Producir Y: " .. opt["solucion"][1]) # Salida: 60
escribir("Ganancia Máxima: " .. opt["f_optimo"]) # Salida: 180
escribir("Recursos sobrantes (Holguras): " .. opt["holguras"]) # Salida:[0, 0, 20]
```

🎯 **Ejemplo: optimizacion.recocidoSimulado**

Minimiza $f(X)$ mediante el algoritmo estocástico de Recocido Simulado (Simulated Annealing). Es capaz de escapar de mínimos locales aceptando soluciones temporalmente peores con una probabilidad que disminuye conforme el sistema se "enfría". Ideal para paisajes de funciones muy accidentados.

```latino
incluir("formulas")

# Función objetivo (Ej: x² + y²)
f_costo = fun(v) ret v[0]^2 + v[1]^2 fin

# Punto inicial: [5, 5]
# Límites de búsqueda: de [-10, -10] a [10, 10]
res = optimizacion.recocidoSimulado(f_costo, [5, 5], [-10, -10], [10, 10])

escribir("Óptimo encontrado: " .. res["optimo"])
escribir("Valor en el óptimo: " .. res["f_optimo"])
escribir("Temperatura final: " .. res["temperatura_final"])
escribir("Tasa de aceptación: " .. mate.redondear(res["tasa_aceptacion"] * 100, 2) .. "%")
```

🎯 **Ejemplo: optimizacion.busquedaCuadricula**

Evalúa $f(X)$ exhaustivamente en una cuadrícula regular y retorna el mejor punto encontrado. Es excelente para exploración inicial del espacio o para ajuste de hiperparámetros (Grid Search).
*Nota:* El costo computacional crece exponencialmente con las dimensiones. Producto total de puntos máximo permitido: 1,000,000.

```latino
incluir("formulas")

f_costo = fun(v) ret v[0]^2 + v[1]^2 fin

# Buscar en el rango de -2 a 2 para X e Y
# Usando 5 puntos de muestra por cada dimensión (Total = 5 * 5 = 25 evaluaciones)
res = optimizacion.busquedaCuadricula(f_costo, [-2, -2], [2, 2], [5, 5])

escribir("Mejor punto en la cuadrícula: " .. res["optimo"]) # Salida: [0, 0]
escribir("Valor mínimo detectado: " .. res["f_optimo"])     # Salida: 0
escribir("Evaluaciones totales: " .. res["evaluaciones"])   # Salida: 25
```
