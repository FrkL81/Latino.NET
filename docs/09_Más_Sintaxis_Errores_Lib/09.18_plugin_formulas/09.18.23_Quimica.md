## 9.18 Plugin `formulas`

### 9.18.23 Librería `quimica`

La librería `quimica` proporciona funciones esenciales para cálculos en química general, incluyendo pH, diluciones, cinética química, termoquímica, electroquímica y bioquímica. Las funciones devuelven diccionarios con los resultados, diagnóstico del estado, y la fórmula aplicada.

Las filas siguientes listan **solo las claves adicionales** a las tres comunes (`resultado`, `unidad`, `formula`). El porcentaje de `rendimientoReaccion` se lee en `resultado`, no en una clave propia.

| Función | Claves del Diccionario Retornado |
| :--- | :--- |
| **Todas** | `resultado`, `unidad`, `formula` |
| `quimica.celdaElectroquimica` | `tipo_celda`, `espontanea` |
| `quimica.dilucion` | `incognita` |
| `quimica.michaelisMenten` | `saturacion_pct`, `regimen` (solo cuando se despeja `v`) |
| `quimica.phEstado` | `estado` |
| `quimica.rendimientoReaccion` | `calidad`, `masa_perdida` |

#### Referencia de Funciones

| Función | Argumentos | Descripción |
| :--- | :--- | :--- |
| `quimica.arrhenius` | `(factorPreexponencial, energiaActivacionJ, temperaturaK)` | Constante de velocidad de reacción (Ecuación de Arrhenius). $R = 8.314$ J/(mol·K). Fórmula: $k = A \cdot e^{-E_a/(RT)}$ |
| `quimica.celdaElectroquimica` | `(potencialCatodo, potencialAnodo)` | Voltaje de celda electroquímica estándar. Fórmula: $E°_{celda} = E°_{cátodo} - E°_{ánodo}$ |
| `quimica.concentracionMolar` | `(molesSoluto, volumenLitros)` | Concentración molar de una solución. Fórmula: $M = \frac{n}{V}$ |
| `quimica.dilucion` | `(diccionarioVariables)` | Ley de dilución. Pasa 3 de: 'M1', 'V1', 'M2', 'V2'. Fórmula: $M_1 V_1 = M_2 V_2$ |
| `quimica.entalpiaReaccion` | `(sumaProductosKJ, sumaReactivosKJ)` | Entalpía estándar de reacción (Ley de Hess). Fórmula: $\Delta H°_{rxn} = \sum \Delta H°_f(\text{productos}) - \sum \Delta H°_f(\text{reactivos})$ |
| `quimica.hendersonHasselbalch` | `(pka, concentracionBase, concentracionAcido)` | pH de una solución buffer. Fórmula: $pH = pKa + \log_{10}\left(\frac{[A^-]}{[HA]}\right)$ |
| `quimica.michaelisMenten` | `(diccionarioVariables)` | Cinética enzimática. Pasa 3 de: 'v', 'Vmax', 'Km', '[S]'. Fórmula: $v = \frac{V_{max} \cdot [S]}{K_m + [S]}$ |
| `quimica.phEstado` | `(concentracionH)` | Calcula el pH y el estado de la solución. Fórmula: $pH = -\log_{10}[H^+]$ |
| `quimica.rendimientoReaccion` | `(masaObtenida, masaTeorica)` | Rendimiento porcentual de una reacción química. Fórmula: $R\% = \frac{m_{obtenida}}{m_{teórica}} \cdot 100$ |

🎯 **Ejemplo: quimica.phEstado**

Calcula el pH de una solución a partir de la concentración de iones hidrógeno [H⁺] y clasifica el medio como ácido, básico o neutro.

```latino
incluir("formulas")

# Agua pura [H⁺] = 1e-7 M
h_concentracion = 1e-7

ph = quimica.phEstado(h_concentracion)
escribir("pH DEL AGUA PURA")
escribir("[H⁺] = " .. h_concentracion .. " M")
escribir("pH = " .. ph["resultado"])
escribir("Estado: " .. ph["estado"])
escribir("Fórmula: " .. ph["formula"])
# Salida:
# pH DEL AGUA PURA
# [H⁺] = 1e-7 M
# pH = 7.0
# Estado: Neutro
# Fórmula: pH = -log₁₀[H⁺]

# Ácido clorhídrico 0.01 M
h_acido = 0.01
ph_acido = quimica.phEstado(h_acido)
escribir("\nÁCIDO FUERTE (HCl 0.01 M)")
escribir("pH = " .. ph_acido["resultado"])
escribir("Estado: " .. ph_acido["estado"])
# Salida:
# ÁCIDO FUERTE (HCl 0.01 M)
# pH = 2.0
# Estado: Ácido

# Hidróxido de sodio 0.001 M (pOH = 3, pH = 11)
h_base = 1e-11  # [H⁺] en solución básica
ph_base = quimica.phEstado(h_base)
escribir("\nBASE FUERTE (NaOH 0.001 M)")
escribir("pH = " .. ph_base["resultado"])
escribir("Estado: " .. ph_base["estado"])
# Salida:
# BASE FUERTE (NaOH 0.001 M)
# pH = 11.0
# Estado: Básico
```

🎯 **Ejemplo: quimica.dilucion**

Aplica la ley de dilución $M_1V_1 = M_2V_2$ para calcular concentraciones o volúmenes desconocidos en procesos de dilución.

```latino
incluir("formulas")

# Diluir ácido sulfúrico: M1=18 M, V1=?, M2=1 M, V2=500 mL
vars1 = {"M1": 18, "M2": 1, "V2": 500}  # V1 es incógnita (mL)

dil = quimica.dilucion(vars1)
escribir("DILUCIÓN DE ÁCIDO SULFÚRICO")
escribir("M1 = " .. vars1["M1"] .. " M (concentrado)")
escribir("V2 = " .. vars1["V2"] .. " mL (diluido)")
escribir("M2 = " .. vars1["M2"] .. " M (diluido)")
escribir("Volumen necesario (V1): " .. dil["resultado"] .. " mL")
escribir("Incógnita calculada: " .. dil["incognita"])
escribir("Fórmula: " .. dil["formula"])
# Salida:
# DILUCIÓN DE ÁCIDO SULFÚRICO
# M1 = 18 M (concentrado)
# V2 = 500 mL (diluido)
# M2 = 1 M (diluido)
# Volumen necesario (V1): 27.78 mL
# Incógnita calculada: V1
# Fórmula: M₁·V₁ = M₂·V₂

# Calcular concentración final después de diluir
vars2 = {"M1": 12, "V1": 100, "V2": 500}  # M2 es incógnita
dil2 = quimica.dilucion(vars2)
escribir("\nDILUCIÓN DE HCl")
escribir("M2 = " .. dil2["resultado"] .. " M")
# Salida:
# DILUCIÓN DE HCl
# M2 = 2.4 M
```

🎯 **Ejemplo: quimica.rendimientoReaccion**

Calcula el rendimiento porcentual de una reacción química, comparando la cantidad real obtenida con la cantidad teórica esperada.

```latino
incluir("formulas")

# Síntesis de aspirina: masa teórica 5.0 g, masa obtenida 4.2 g
obtenida = 4.2
teorica = 5.0

rend = quimica.rendimientoReaccion(obtenida, teorica)
escribir("RENDIMIENTO DE REACCIÓN")
escribir("Masa teórica: " .. teorica .. " g")
escribir("Masa obtenida: " .. obtenida .. " g")
escribir("Rendimiento: " .. rend["resultado"] .. "%")
escribir("Fórmula: " .. rend["formula"])
# Salida:
# RENDIMIENTO DE REACCIÓN
# Masa teórica: 5.0 g
# Masa obtenida: 4.2 g
# Rendimiento: 84%
# Fórmula: R% = (m_obtenida / m_teórica) · 100

# Reacción con pérdidas
bajo = quimica.rendimientoReaccion(3.2, 10.0)
escribir("\nRendimiento bajo: " .. bajo["resultado"] .. "%")
# Salida:
# Rendimiento bajo: 32%
```

🎯 **Ejemplo: quimica.arrhenius**

Calcula la constante de velocidad de una reacción química usando la ecuación de Arrhenius, que relaciona la temperatura con la velocidad de reacción.

```latino
incluir("formulas")

# Reacción con A = 1e12 s⁻¹, Ea = 75 kJ/mol, T = 300 K
A = 1e12
Ea = 75000  # 75 kJ/mol en J/mol
T = 300     # Kelvin
R = 8.314   # constante de los gases (J/mol·K)

k = quimica.arrhenius(A, Ea, T)
escribir("ECUACIÓN DE ARRHENIUS")
escribir("Factor preexponencial (A): " .. A .. " s⁻¹")
escribir("Energía de activación: " .. (Ea/1000) .. " kJ/mol")
escribir("Temperatura: " .. T .. " K")
escribir("Constante de velocidad: " .. k["resultado"] .. " s⁻¹")
escribir("Fórmula: " .. k["formula"])
# Salida:
# ECUACIÓN DE ARRHENIUS
# Factor preexponencial (A): 1e12 s⁻¹
# Energía de activación: 75 kJ/mol
# Temperatura: 300 K
# Constante de velocidad: 0.08741681309553753 s⁻¹
# Fórmula: k = A·e^(-Ea/RT)

# Efecto de la temperatura
T2 = 310  # 37°C (temperatura corporal)
k2 = quimica.arrhenius(A, Ea, T2)
escribir("\nA 37°C (310 K): k = " .. k2["resultado"] .. " s⁻¹")
factor_aumento = k2["resultado"] / k["resultado"]
escribir("Aumento: " .. factor_aumento .. " veces")
# Salida:
# A 37°C (310 K): k = 0.23058648100471502 s⁻¹
# Aumento: 2.6377818275382316 veces
```

🎯 **Ejemplo: quimica.celdaElectroquimica**

Calcula el potencial estándar de una celda electroquímica y determina si la reacción es espontánea.

```latino
incluir("formulas")

# Celda de Daniell (Zn/Cu)
# Zn²⁺/Zn: E° = -0.76 V (ánodo - oxidación)
# Cu²⁺/Cu: E° = +0.34 V (cátodo - reducción)
e_catodo = 0.34   # Cu²⁺/Cu
e_anodo = -0.76   # Zn²⁺/Zn

celda = quimica.celdaElectroquimica(e_catodo, e_anodo)
escribir("CELDA ELECTROQUÍMICA (DANIELL)")
escribir("E°cátodo (Cu²⁺/Cu): " .. e_catodo .. " V")
escribir("E°ánodo (Zn²⁺/Zn): " .. e_anodo .. " V")
escribir("Potencial de celda: " .. celda["resultado"] .. " V")
escribir("Tipo de celda: " .. celda["tipo_celda"])
escribir("¿Reacción espontánea?: " .. (celda["espontanea"] ? "Sí" : "No"))
escribir("Fórmula: " .. celda["formula"])
# Salida:
# CELDA ELECTROQUÍMICA (DANIELL)
# E°cátodo (Cu²⁺/Cu): 0.34 V
# E°ánodo (Zn²⁺/Zn): -0.76 V
# Potencial de celda: 1.10 V
# Tipo de celda: Galvánica (voltaica)
# ¿Reacción espontánea?: Sí
# Fórmula: E°_celda = E°_cátodo - E°_ánodo

# Celda no espontánea (necesita electrólisis)
e_catodo2 = -0.44  # Fe²⁺/Fe
e_anodo2 = 0.80    # Ag⁺/Ag (invertido)
celda2 = quimica.celdaElectroquimica(e_catodo2, e_anodo2)
escribir("\nCELDA NO ESPONTÁNEA")
escribir("Potencial: " .. celda2["resultado"] .. " V")
escribir("Tipo: " .. celda2["tipo_celda"])
# Salida:
# CELDA NO ESPONTÁNEA
# Potencial: -1.24 V
# Tipo: Electrolítica
```

🎯 **Ejemplo: quimica.hendersonHasselbalch**

Calcula el pH de una solución buffer (tampón) usando la ecuación de Henderson-Hasselbalch, fundamental en bioquímica y sistemas biológicos.

```latino
incluir("formulas")

# Buffer fosfato: pKa2 = 7.2, [HPO₄²⁻] = 0.1 M, [H₂PO₄⁻] = 0.05 M
pka = 7.2
base = 0.1   # [A⁻] forma desprotonada
acido = 0.05 # [HA] forma protonada

buffer = quimica.hendersonHasselbalch(pka, base, acido)
escribir("ECUACIÓN DE HENDERSON-HASSELBALCH")
escribir("pKa = " .. pka)
escribir("[A⁻] = " .. base .. " M")
escribir("[HA] = " .. acido .. " M")
escribir("pH = " .. buffer["resultado"])
escribir("Fórmula: " .. buffer["formula"])
# Salida:
# ECUACIÓN DE HENDERSON-HASSELBALCH
# pKa = 7.2
# [A⁻] = 0.1 M
# [HA] = 0.05 M
# pH = 7.5
# Fórmula: pH = pKa + log₁₀([A⁻]/[HA])

# Buffer con igual concentración (pH = pKa)
igual = quimica.hendersonHasselbalch(4.76, 0.1, 0.1)  # ácido acético/acetato
escribir("\nBUFFER ACÉTICO (1:1)")
escribir("pH = " .. igual["resultado"] .. " (igual al pKa)")
# Salida:
# BUFFER ACÉTICO (1:1)
# pH = 4.76 (igual al pKa)

# Buffer sanguíneo (bicarbonato)
sangre = quimica.hendersonHasselbalch(6.1, 0.024, 0.0012)
escribir("\nBUFFER SANGUÍNEO (bicarbonato)")
escribir("pH = " .. sangre["resultado"])
# Salida:
# BUFFER SANGUÍNEO (bicarbonato)
# pH = 7.4
```

🎯 **Ejemplo: quimica.entalpiaReaccion**

Calcula el cambio de entalpía estándar de una reacción usando la ley de Hess, a partir de las entalpías de formación de productos y reactivos.

```latino
incluir("formulas")

# Combustión del metano: CH₄ + 2O₂ → CO₂ + 2H₂O
# ΔH°f productos: CO₂ = -393.5 kJ/mol, H₂O = -241.8 kJ/mol (vapor)
# ΔH°f reactivos: CH₄ = -74.8 kJ/mol, O₂ = 0 kJ/mol
productos = -393.5 + 2 * (-241.8)  # -877.1 kJ
reactivos = -74.8 + 2 * 0           # -74.8 kJ

entalpia = quimica.entalpiaReaccion(productos, reactivos)
escribir("ENTALPÍA DE REACCIÓN (COMBUSTIÓN METANO)")
escribir("Σ ΔH°f productos: " .. productos .. " kJ/mol")
escribir("Σ ΔH°f reactivos: " .. reactivos .. " kJ/mol")
escribir("ΔH°reacción: " .. entalpia["resultado"] .. " kJ/mol")
escribir("Fórmula: " .. entalpia["formula"])
# Salida:
# ENTALPÍA DE REACCIÓN (COMBUSTIÓN METANO)
# Σ ΔH°f productos: -877.1 kJ/mol
# Σ ΔH°f reactivos: -74.8 kJ/mol
# ΔH°reacción: -802.3 kJ/mol
# Fórmula: ΔH°rxn = ΣΔH°f(productos) - ΣΔH°f(reactivos)

# Reacción endotérmica
endo = quimica.entalpiaReaccion(50, 10)
escribir("\nREACCIÓN ENDOTÉRMICA")
escribir("ΔH = " .. endo["resultado"] .. " kJ/mol (positivo)")
# Salida:
# REACCIÓN ENDOTÉRMICA
# ΔH = 40 kJ/mol (positivo)
```

🎯 **Ejemplo: quimica.michaelisMenten**

Modela la cinética enzimática según la ecuación de Michaelis-Menten, permitiendo calcular velocidad de reacción, velocidad máxima, constante de Michaelis o concentración de sustrato.

```latino
incluir("formulas")

# Calcular velocidad de reacción (v) dados Vmax, Km y [S]
vars1 = {"Vmax": 100, "Km": 5, "S": 2}  # µmol/min, mM, mM

mm1 = quimica.michaelisMenten(vars1)
escribir("CINÉTICA ENZIMÁTICA (MICHAELIS-MENTEN)")
escribir("Vmax = " .. vars1["Vmax"] .. " µmol/min")
escribir("Km = " .. vars1["Km"] .. " mM")
escribir("[S] = " .. vars1["S"] .. " mM")
escribir("Velocidad (v) = " .. mm1["resultado"] .. " µmol/min")
escribir("Incógnita calculada: " .. mm1["incognita"])
escribir("Fórmula: " .. mm1["formula"])
# Salida:
# CINÉTICA ENZIMÁTICA (MICHAELIS-MENTEN)
# Vmax = 100 µmol/min
# Km = 5 mM
# [S] = 2 mM
# Velocidad (v) = 28.57 µmol/min
# Incógnita calculada: v
# Fórmula: v = (Vmax·[S]) / (Km + [S])

# Calcular Km a partir de datos experimentales
vars2 = {"v": 40, "Vmax": 100, "S": 5}
mm2 = quimica.michaelisMenten(vars2)
escribir("\nCÁLCULO DE Km")
escribir("Km = " .. mm2["resultado"] .. " mM")
# Salida:
# CÁLCULO DE Km
# Km = 7.5 mM

# A diferentes concentraciones de sustrato
sustratos = [1, 2, 5, 10, 20, 50]
escribir("\nVELOCIDAD vs [S] (Vmax=100, Km=5)")
para s en sustratos
    res = quimica.michaelisMenten({"Vmax": 100, "Km": 5, "S": s})
    escribir("[S]=" .. s .. " mM → v=" .. res["resultado"] .. " µmol/min")
fin
# Salida:
# VELOCIDAD vs [S] (Vmax=100, Km=5)
# [S]=1 mM → v=16.67 µmol/min
# [S]=2 mM → v=28.57 µmol/min
# [S]=5 mM → v=50.0 µmol/min
# [S]=10 mM → v=66.67 µmol/min
# [S]=20 mM → v=80.0 µmol/min
# [S]=50 mM → v=90.91 µmol/min
```
