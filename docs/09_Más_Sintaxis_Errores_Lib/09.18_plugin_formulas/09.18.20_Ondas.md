## 9.18 Plugin `formulas`

### 9.18.20 Librería `ondas`

La librería `ondas` proporciona funciones para el estudio de fenómenos ondulatorios, incluyendo la relación entre frecuencia, período y longitud de onda, así como el efecto Doppler y la clasificación espectral de la luz. Las funciones devuelven diccionarios con los resultados, metadatos específicos y la fórmula aplicada.

#### 🗝️ Estructura de los Diccionarios de Retorno

| Función | Claves del Diccionario Retornado |
| :--- | :--- |
| **Todas** | `resultado`, `unidad`, `formula` |
| `ondas.frecuenciaPeriodo` | `incognita` |
| `ondas.longitudOndaLuz` | `espectro` |

#### Referencia de Funciones

| Función | Argumentos | Descripción |
| :--- | :--- | :--- |
| `ondas.efectoDoppler` | `(frecuencia_fuente, velocidad_sonido, velocidad_observador, velocidad_fuente)` | Frecuencia percibida por efecto Doppler (+ si se acercan, - si se alejan). Fórmula: $f' = f \cdot \frac{v + v_{obs}}{v + v_{src}}$ |
| `ondas.frecuenciaPeriodo` | `(diccionario_variables)` | Relación inversa entre frecuencia y período. Pasa 'f' o 'T'. Fórmula: $f = \frac{1}{T}$ |
| `ondas.longitudOndaLuz` | `(frecuencia)` | Longitud de onda de la luz en el vacío dado su frecuencia ($c = 299,792,458$ m/s). Fórmula: $\lambda = \frac{c}{f}$ |
| `ondas.velocidadOnda` | `(frecuencia, longitud_onda)` | Velocidad de propagación de una onda. Fórmula: $v = f \cdot \lambda$ |

🎯 **Ejemplo: ondas.velocidadOnda**

Calcula la velocidad de propagación de una onda a partir de su frecuencia y longitud de onda.

```latino
incluir("formulas")

# Onda sonora en el aire (frecuencia 440 Hz, longitud de onda 0.78 m)
frecuencia = 440  # Hz
longitud = 0.78   # metros

v = ondas.velocidadOnda(frecuencia, longitud)
escribir("VELOCIDAD DE ONDA")
escribir("Frecuencia: " .. frecuencia .. " Hz")
escribir("Longitud de onda: " .. longitud .. " m")
escribir("Velocidad: " .. v["resultado"] .. " " .. v["unidad"])
escribir("Fórmula: " .. v["formula"])
# Salida:
# VELOCIDAD DE ONDA
# Frecuencia: 440 Hz
# Longitud de onda: 0.78 m
# Velocidad: 343.2 m/s
# Fórmula: v = f·λ

# Onda electromagnética (luz visible)
f_luz = 5e14  # 500 THz (luz verde)
λ_luz = 600e-9  # 600 nm
v_luz = ondas.velocidadOnda(f_luz, λ_luz)
escribir("\nVELOCIDAD DE LA LUZ")
escribir("Velocidad calculada: " .. v_luz["resultado"] .. " m/s")
# Salida:
# VELOCIDAD DE LA LUZ
# Velocidad calculada: 300000000 m/s

# Verificar en diferentes medios
fijo = 1000
λ1 = 0.34  # sonido en aire
λ2 = 1.48  # sonido en agua (aprox)
v1 = ondas.velocidadOnda(fijo, λ1)
v2 = ondas.velocidadOnda(fijo, λ2)
escribir("\nCOMPARACIÓN DE MEDIOS")
escribir("Aire: " .. v1["resultado"] .. " m/s")
escribir("Agua: " .. v2["resultado"] .. " m/s")
# Salida:
# COMPARACIÓN DE MEDIOS
# Aire: 340 m/s
# Agua: 1480 m/s
```

🎯 **Ejemplo: ondas.frecuenciaPeriodo**

Calcula la relación inversa entre frecuencia y período. Permite pasar una de las dos variables para obtener la otra.

```latino
incluir("formulas")

# Calcular período a partir de frecuencia (60 Hz)
vars1 = {"f": 60}  # frecuencia en Hz
fp1 = ondas.frecuenciaPeriodo(vars1)
escribir("FRECUENCIA ↔ PERÍODO")
escribir("Frecuencia: 60 Hz")
escribir("Período calculado: " .. fp1["resultado"] .. " s")
escribir("Incógnita calculada: " .. fp1["incognita"])
escribir("Fórmula: " .. fp1["formula"])
# Salida:
# FRECUENCIA ↔ PERÍODO
# Frecuencia: 60 Hz
# Período calculado: 0.01667 s
# Incógnita calculada: T
# Fórmula: f = 1 / T

# Calcular frecuencia a partir de período (0.02 s = 50 Hz)
vars2 = {"T": 0.02}
fp2 = ondas.frecuenciaPeriodo(vars2)
escribir("\nPeríodo: 0.02 s")
escribir("Frecuencia calculada: " .. fp2["resultado"] .. " Hz")
escribir("Incógnita calculada: " .. fp2["incognita"])
# Salida:
# Período: 0.02 s
# Frecuencia calculada: 50 Hz
# Incógnita calculada: f

# Tabla de frecuencias musicales
notas = [261.63, 293.66, 329.63, 349.23, 392.00, 440.00, 493.88]  # Do a Si
escribir("\nPERÍODOS DE NOTAS MUSICALES")
para f_nota en notas
    res = ondas.frecuenciaPeriodo({"f": f_nota})
    escribir("f=" .. f_nota .. " Hz → T=" .. res["resultado"] .. " s")
fin
# Salida:
# PERÍODOS DE NOTAS MUSICALES
# f=261.63 Hz → T=0.00382 s
# f=293.66 Hz → T=0.00341 s
# f=329.63 Hz → T=0.00303 s
# ...
```

🎯 **Ejemplo: ondas.efectoDoppler**

Calcula la frecuencia percibida por un observador cuando la fuente sonora o el observador están en movimiento (efecto Doppler).

```latino
incluir("formulas")

# Ambulancia acercándose (velocidad 30 m/s, observador quieto)
f_fuente = 500  # Hz (sirena)
v_sonido = 340  # m/s
v_obs = 0       # observador quieto
v_fuente = -30  # negativa si se acerca (convención: positiva si se aleja)

doppler = ondas.efectoDoppler(f_fuente, v_sonido, v_obs, v_fuente)
escribir("EFECTO DOPPLER (FUENTE ACERCÁNDOSE)")
escribir("Frecuencia emitida: " .. f_fuente .. " Hz")
escribir("Velocidad fuente: " .. mate.abs(v_fuente) .. " m/s (acercándose)")
escribir("Frecuencia percibida: " .. doppler["resultado"] .. " Hz")
escribir("Fórmula: " .. doppler["formula"])
# Salida:
# EFECTO DOPPLER (FUENTE ACERCÁNDOSE)
# Frecuencia emitida: 500 Hz
# Velocidad fuente: 30 m/s (acercándose)
# Frecuencia percibida: 548.39 Hz
# Fórmula: f' = f·(v ± v_obs)/(v ± v_fuente)

# Fuente alejándose
v_fuente_aleja = 30  # positiva si se aleja
doppler_aleja = ondas.efectoDoppler(f_fuente, v_sonido, 0, v_fuente_aleja)
escribir("\nFUENTE ALEJÁNDOSE")
escribir("Frecuencia percibida: " .. doppler_aleja["resultado"] .. " Hz")
# Salida:
# FUENTE ALEJÁNDOSE
# Frecuencia percibida: 459.46 Hz

# Observador moviéndose hacia la fuente
v_obs_acerca = 20  # observador hacia la fuente
doppler_obs = ondas.efectoDoppler(f_fuente, v_sonido, v_obs_acerca, 0)
escribir("\nOBSERVADOR ACERCÁNDOSE")
escribir("Frecuencia percibida: " .. doppler_obs["resultado"] .. " Hz")
# Salida:
# OBSERVADOR ACERCÁNDOSE
# Frecuencia percibida: 529.41 Hz

# Caso ultrasónico (murciélago)
f_murcielago = 50000  # 50 kHz
v_murcielago = 10     # volando hacia presa
eco = ondas.efectoDoppler(f_murcielago, v_sonido, 0, -v_murcielago)
escribir("\nMURCIÉLAGO (ecolocalización)")
escribir("Frecuencia reflejada: " .. eco["resultado"] .. " Hz")
# Salida:
# MURCIÉLAGO (ecolocalización)
# Frecuencia reflejada: 51515 Hz
```

🎯 **Ejemplo: ondas.longitudOndaLuz**

Calcula la longitud de onda de la luz en el vacío a partir de su frecuencia e incluye una clasificación del tipo de radiación en el espectro electromagnético.

```latino
incluir("formulas")

# Luz verde (frecuencia 5.5 × 10¹⁴ Hz)
f_verde = 5.5e14  # Hz

luz = ondas.longitudOndaLuz(f_verde)
escribir("LONGITUD DE ONDA (LUZ)")
escribir("Frecuencia: " .. f_verde .. " Hz")
escribir("Longitud de onda: " .. luz["resultado"] .. " " .. luz["unidad"])
escribir("Espectro: " .. luz["espectro"])
escribir("Fórmula: " .. luz["formula"])
# Salida:
# LONGITUD DE ONDA (LUZ)
# Frecuencia: 550000000000000 Hz
# Longitud de onda: 5.45e-7 m
# Espectro: Visible (verde)
# Fórmula: λ = c / f

# Convertir a nanómetros para mejor lectura
λ_nm = luz["resultado"] * 1e9
escribir("\nLongitud de onda: " .. λ_nm .. " nm")
# Salida:
# Longitud de onda: 545 nm

# Explorar diferentes regiones del espectro
frecuencias = [
    1e6,      # Ondas de radio (AM)
    1e9,      # Microondas
    4e14,     # Rojo
    6e14,     # Azul
    1e16,     # Ultravioleta
    1e18      # Rayos X
]

escribir("\nCLASIFICACIÓN ESPECTRAL")
para f en frecuencias
    res = ondas.longitudOndaLuz(f)
    λ_en_nm = res["resultado"] * 1e9
    escribir("f=" .. f .. " Hz → λ=" .. λ_en_nm .. " nm (" .. res["espectro"] .. ")")
fin
# Salida:
# CLASIFICACIÓN ESPECTRAL
# f=1000000 Hz → λ=299792458000 nm (Ondas de radio)
# f=1000000000 Hz → λ=299792.458 nm (Microondas)
# f=400000000000000 Hz → λ=749.48 nm (Rojo)
# f=600000000000000 Hz → λ=499.65 nm (Azul)
# f=10000000000000000 Hz → λ=29.98 nm (Ultravioleta)
# f=1000000000000000000 Hz → λ=0.3 nm (Rayos X)

# Calcular longitud para una frecuencia específica (láser He-Ne: 632.8 nm)
f_he_ne = 4.74e14
laser = ondas.longitudOndaLuz(f_he_ne)
λ_laser = laser["resultado"] * 1e9
escribir("\nLÁSER HELIO-NEÓN")
escribir("Frecuencia: " .. f_he_ne .. " Hz")
escribir("Longitud calculada: " .. λ_laser .. " nm")
escribir("Espectro: " .. laser["espectro"])
# Salida:
# LÁSER HELIO-NEÓN
# Frecuencia: 474000000000000 Hz
# Longitud calculada: 632.4735400843882 nm
# Espectro: Visible
```
