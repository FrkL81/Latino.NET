## 9.18 Plugin `formulas`

### 9.18.02 Librería `algebraLineal`

La librería `algebraLineal` proporciona funciones para operaciones con vectores y matrices, incluyendo resolución de sistemas lineales, factorizaciones, cálculo de valores propios y operaciones elemento a elemento. Todas las funciones devuelven diccionarios con los resultados y metadatos de la operación.

#### Referencia de Funciones (`algebraLineal`)

| Función | Argumentos | Descripción |
| :--- | :--- | :--- |
| `algebraLineal.abs` | `(coleccion)` | Aplica valor absoluto a cada elemento de un vector o matriz. |
| `algebraLineal.cholesky` | `(matriz_A)` | Descompone A = L * L^T para matrices simétricas definidas positivas. |
| `algebraLineal.clip` | `(coleccion, minimo, maximo)` | Limita (clamp) cada elemento de un vector o matriz al rango [minimo, maximo]. |
| `algebraLineal.cruz` | `(vector_a, vector_b)` | Calcula el producto vectorial (producto cruz) entre dos vectores en el espacio tridimensional R^3. |
| `algebraLineal.determinante` | `(matriz_A)` | Calcula el determinante de una matriz cuadrada mediante factorización LU. |
| `algebraLineal.dividirEscalar` | `(coleccion, n)` | Divide cada elemento de un vector o matriz por un escalar n. |
| `algebraLineal.dividirTerminos` | `(colA, colB)` | Divide dos vectores o matrices elemento a elemento. |
| `algebraLineal.factorizacionLU` | `(matriz_A)` | Descompone la matriz en A = P \* L \* U (matriz de permutación P, triangular inferior L y triangular superior U). |
| `algebraLineal.iguales` | `(colA, colB, [tolerancia])` | Compara si dos vectores o matrices son iguales elemento a elemento dentro de una tolerancia. |
| `algebraLineal.invertir` | `(matriz_A)` | Calcula la matriz inversa A^-1 mediante factorización LU con pivoteo parcial. |
| `algebraLineal.multiplicarEscalar` | `(coleccion, n)` | Multiplica cada elemento de un vector o matriz por un escalar n. |
| `algebraLineal.multiplicarTerminos` | `(colA, colB)` | Producto de Hadamard: multiplica dos vectores o matrices elemento a elemento. |
| `algebraLineal.multiplicar` | `(matriz_A, matriz_B)` | Multiplica dos matrices compatibles: A (m×k) por B (k×n). |
| `algebraLineal.negativo` | `(coleccion)` | Invierte el signo (-x) de cada elemento de un vector o matriz. |
| `algebraLineal.norma` | `(lista, [tipo])` | Calcula la norma de un vector o matriz (tipos soportados: 1, 2, frobenius, inf). |
| `algebraLineal.potenciaEscalar` | `(coleccion, exp)` | Eleva cada elemento de un vector o matriz al exponente dado. |
| `algebraLineal.punto` | `(vector_a, vector_b)` | Calcula el producto escalar (producto punto) entre dos vectores de igual dimensión. |
| `algebraLineal.raiz` | `(coleccion)` | Aplica raíz cuadrada a cada elemento de un vector o matriz. |
| `algebraLineal.redondear` | `(coleccion, [decimales])` | Redondea cada elemento de un vector o matriz al número de decimales especificado. |
| `algebraLineal.resolver` | `(matriz_A, vector_b)` | Resuelve el sistema lineal A * x = b mediante eliminación gaussiana con pivoteo parcial. |
| `algebraLineal.restarEscalar` | `(coleccion, n)` | Resta un escalar n a cada elemento de un vector o matriz. |
| `algebraLineal.restar` | `(colA, colB)` | Resta dos vectores o matrices elemento a elemento. |
| `algebraLineal.sumarEscalar` | `(coleccion, n)` | Suma un escalar n a cada elemento de un vector o matriz. |
| `algebraLineal.sumar` | `(colA, colB)` | Suma dos vectores o matrices elemento a elemento. |
| `algebraLineal.transponer` | `(matriz_A)` | Calcula la matriz transpuesta A^T intercambiando filas por columnas. |
| `algebraLineal.traza` | `(matriz_A)` | Calcula la traza (suma de la diagonal principal) de una matriz cuadrada. |
| `algebraLineal.valorPropioDominante` | `(matriz_A, [tolerancia], [max_iter])` | Encuentra el valor propio dominante (mayor en módulo) y su vector propio mediante el método de las potencias. |
| `algebraLineal.valoresPropios` | `(matriz_A, [max_iter], [tolerancia])` | Calcula todos los valores propios de una matriz cuadrada real mediante el algoritmo QR. |

🎯 **Ejemplo: Resolución de sistemas lineales con algebraLineal.resolver**

Resuelve el sistema de ecuaciones lineales $A \cdot x = b$ mediante el método de eliminación gaussiana con pivoteo parcial. Retorna el vector solución y la norma del residuo para verificación.

```latino
incluir("formulas")

# Sistema de 2x2:
# 2x +  y = 8
#  x -  y = 1
matriz_a = [[2, 1], [1, -1]]
vector_b = [8, 1]

res = algebraLineal.resolver(matriz_a, vector_b)

# La clave de retorno es 'solucion', no 'resultado'
escribir(res["solucion"])          # Salida: [3, 2]
escribir("Error: " .. res["norma_residuo"]) # Salida: Error: 0
```

🎯 **Ejemplo: algebraLineal.factorizacionLU**

Descompone una matriz cuadrada $A$ en el producto de tres matrices: una matriz de permutación $P$, una matriz triangular inferior $L$ y una matriz triangular superior $U$.

```latino
incluir("formulas")

matriz_a = [[4, 12, -16], [12, 37, -43], [-16, -43, 98]]
res = algebraLineal.factorizacionLU(matriz_a)

escribir("L: " .. res["L"])
escribir("U: " .. res["U"])
escribir("P: " .. res["P"])
escribir("det: " .. res["determinante"]) # Salida: det: 36
```

🎯 **Ejemplo: algebraLineal.cholesky**

Realiza la factorización de Cholesky ($A = L \cdot L^T$) para matrices simétricas y definidas positivas.

```latino
incluir("formulas")

matriz_a = [[4, 12, -16], [12, 37, -43], [-16, -43, 98]]
res = algebraLineal.cholesky(matriz_a)

escribir("L: " .. res["L"])
escribir("Lᵀ: " .. res["Lt"])

```

🎯 **Ejemplo: algebraLineal.invertir**

Calcula la matriz inversa $A^{-1}$ tal que $A \cdot A^{-1} = I$, utilizando factorización LU con pivoteo parcial.

```latino
incluir("formulas")

matriz_a = [[4, 12, -16], [12, 37, -43], [-16, -43, 98]]
res = algebraLineal.invertir(matriz_a)

escribir(res["inversa"])
# Verificar que A * A⁻¹ ≈ I
identidad = algebraLineal.multiplicar(matriz_a, res["inversa"])
escribir(identidad["resultado"]) # Aproximadamente [[1,0,0], [0,1,0], [0,0,1]]
```

🎯 **Ejemplo: algebraLineal.valorPropioDominante**

🎯 **Ejemplo: algebraLineal.valoresPropios**

Calcula todos los valores propios de una matriz cuadrada real mediante el algoritmo QR iterativo.

```latino
incluir("formulas")

# Matriz simétrica 2x2
matriz_a = [[1, 2], [2, 1]]
res = algebraLineal.valoresPropios(matriz_a)

# La salida en bruto puede tener artefactos de punto flotante (ej: 2.999999999999999)
# Usamos algebraLineal.redondear para limpiar el vector resultante:
vps_limpios = algebraLineal.redondear(res["valores_propios"], 4)

escribir("Valores propios: " .. vps_limpios) # Salida: Valores propios: [3, -1]

# Ejemplo con parámetros de control de iteración
res2 = algebraLineal.valoresPropios(matriz_a, 500, 1e-8)
escribir("Cantidad hallada: " .. lista.longitud(res2["valores_propios"])) # Salida: Cantidad hallada: 2
```

🎯 **Ejemplo: algebraLineal.negativo**

Invierte el signo de cada elemento del vector o matriz. Equivalente a multiplicar por -1 de forma más directa.

```latino
incluir("formulas")

datos = [ 1, -2, 3.5, 0 ]
res = algebraLineal.negativo(datos)
escribir(res) # Salida: [ -1, 2, -3.5, -0 ]
```

> **💡 Curiosidad Técnica: ¿Por qué sale `-0`?**
> En Latino.NET (al igual que en Python, C# o JavaScript), los números utilizan el estándar internacional de punto flotante *IEEE 754*. Este estándar conserva el bit de signo incluso para el cero. Por lo tanto, al invertir `0`, obtienes `-0`. No te preocupes, a nivel lógico el motor sabe que son idénticos matemáticamente: la expresión `(-0 == 0)` siempre evaluará como `cierto`.
>
> **Y al formatear:** `escribir(-0)` imprime literalmente `-0`, pero las funciones de formateo lo normalizan a `0`. Con `escribirf`, tanto `{0}` como `{0:F2}` producen `0` y `0.00` respectivamente. Es decir, el signo negativo del cero solo es visible en la impresión directa del valor, nunca en una cadena de formato.

🎯 **Ejemplo: algebraLineal.iguales**

Compara dos colecciones elemento a elemento dentro de una tolerancia.

```latino
incluir("formulas")

v1 = [3, 4, 8]
v2 = [3, 4, 8]
res = algebraLineal.iguales(v1, v2)
escribir(res) # Salida: cierto

# Comparación con tolerancia para punto flotante
a = [0.1 + 0.2]  # 0.30000000000000004
b = [0.3]
res2 = algebraLineal.iguales(a, b, 1e-10)
escribir(res2) # Salida: cierto

# Formas diferentes
m1 = [[4, 8]]
m2 = [[3, 4, 8]]
res3 = algebraLineal.iguales(m1, m2)
escribir(res3) # Salida: falso
```
