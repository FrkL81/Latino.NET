## 9.18 Plugin `formulas` (Ciencias e Ingeniería)

El plugin `formulas` convierte a Latino.NET en un **entorno de cálculo científico y de ingeniería**. Reúne un amplio catálogo organizado en 26 disciplinas, desde mecánica clásica y termodinámica hasta álgebra lineal, métodos numéricos y optimización.

Para la gran mayoría de los cálculos físicos, el plugin implementa un contrato estandarizado: retorna un diccionario con el valor numérico, su unidad de medida dimensional, la fórmula matemática aplicada y, cuando corresponde, diagnósticos de régimen físico.

> **Requiere carga explícita:** `incluir("formulas")`

### 🧠 Conceptos Previos

#### Cómo responde cada función

El comportamiento de retorno se adapta a la naturaleza del problema matemático:

1. **Fórmulas de magnitud única (estándar):** Retornan un diccionario con la tríada base:
   - `resultado`: El valor numérico calculado (o aproximado).
   - `unidad`: La unidad de medida en el Sistema Internacional o derivada (`"N"`, `"J"`, `"m/s"`, `"Pa"`, etc.).
   - `formula`: La expresión teórica en texto plano o notación matemática (`"F = m·a"`).

    ```latino
    incluir("formulas")

    # 1. Ejemplo en Dinámica: Segunda Ley de Newton (F = m · a)
    # Parámetros: masa = 10 kg, aceleración = 9.8 m/s²
    fuerza = dinamica.newtonFuerza(10, 9.8)

    escribir("--- Dinámica: Fuerza ---")
    escribir("Resultado: " .. fuerza["resultado"])   # 98
    escribir("Unidad:    " .. fuerza["unidad"])      # N
    escribir("Fórmula:   " .. fuerza["formula"])     # F = m·a

    # 2. Ejemplo en Cinemática: Velocidad final en MRUA (v = v₀ + a · t)
    # Parámetros: v_inicial = 0 m/s, aceleración = 9.8 m/s², tiempo = 5 s
    velocidad = cinematica.mruaVelocidad(0, 9.8, 5)

    escribir("--- Cinemática: Velocidad ---")
    escribir("Resultado: " .. velocidad["resultado"]) # 49
    escribir("Unidad:    " .. velocidad["unidad"])    # m/s
    escribir("Fórmula:   " .. velocidad["formula"])   # v = v0 + a·t
    ```

2. **Fórmulas multifactoriales:** Cuando un fenómeno físico produce varias magnitudes simultáneas (como un tiro parabólico o la geometría de un sólido), la clave genérica `resultado` se sustituye por las magnitudes específicas del fenómeno (`altura_maxima`, `alcance_maximo`, `tiempo_vuelo`), conservando siempre la expresión teórica en `formula`.

3. **Operaciones algebraicas directas:** Ciertas operaciones matriciales y vectoriales puras (como sumas o restas de matrices en `algebraLineal`) devuelven directamente colecciones (`lista`) para permitir encadenamientos matemáticos inmediatos.

#### 🎯 Patrones de Uso y Retorno

Para interactuar con el catálogo, las funciones se agrupan en cuatro patrones de consumo:

| Patrón | Mecánica de Invocación | Estructura de Salida | Ejemplo representativo |
| :--- | :--- | :--- | :--- |
| **Directo** | Argumentos posicionales tradicionales | Tríada estándar (`resultado`, `unidad`, `formula`) | `dinamica.newtonFuerza(masa, aceleracion)` |
| **Omni-Solver** | Recibe un diccionario con variables conocidas; despeja la incógnita ausente | Tríada estándar + clave `incognita` despejada | `electricidad.leyOhm({"V": 12, "R": 4})` $\rightarrow$ calcula `I` |
| **Multifactorial** | Argumentos de entrada del sistema | Múltiples claves específicas del problema + `formula` | `cinematica.tiroParabolico(v0, angulo)` $\rightarrow$ altura, alcance, tiempo |
| **Con Diagnóstico** | Parámetros del fluido o sistema físico | Tríada estándar + clasificación cualitativa de régimen | `fluidos.reynolds(...)` $\rightarrow$ `regimen`: laminar/turbulento |

#### ⚖️ Constantes Físicas Universales

El plugin expone un diccionario inmutable de constantes físicas y astronómicas fundamentales para alimentar los cálculos sin recurrir a números mágicos:

```latino
incluir("formulas")
C = formulas.constantes()

escribir(C["g"])        # 9.80665 m/s² (aceleración de la gravedad estándar)
escribir(C["c"])        # 299792458 m/s (velocidad de la luz en el vacío)
escribir(C["R"])        # 8.314462618 J/(mol·K) (constante de los gases)
escribir(C["NA"])       # 6.02214076e23 (número de Avogadro)
escribir(C["pi"])       # 3.141592653589793
```

### 🚀 Ampliación del Catálogo

¿Necesitas una fórmula de ingeniería o ciencia que todavía no está incluida? En el repositorio oficial de Latino.NET puedes proponer su incorporación mediante una solicitud de funcionalidad (*Feature Request*).

Para acelerar su inclusión, proporciona la disciplina, la expresión matemática formal, las variables de entrada con sus unidades del Sistema Internacional y una fuente bibliográfica o estándar técnico que permita verificar su exactitud.
