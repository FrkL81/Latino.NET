## 9.11 Comandos de Consola (CLI)

Latino.NET ofrece una interfaz de línea de comandos robusta para ejecutar scripts y gestionar el entorno de desarrollo.

### 🚀 Modos de Ejecución

| Comando | Descripción |
| :--- | :--- |
| `latino` | Inicia el modo interactivo (REPL). |
| `latino archivo.lat` | Ejecuta un script de Latino. |
| `latino -e "codigo"` | Ejecuta una línea de código directamente. |

### ⚙️ Opciones de Información

| Opción | Aliases | Descripción |
| :--- | :--- | :--- |
| `--apoyar` | - | Muestra cómo apoyar el proyecto y abre el enlace de patrocinio en el navegador. |
| `--ayuda` | `-a`, `-h` | Muestra el menú de ayuda con todas las opciones. |
| `--licencia` | `-l` | Muestra la licencia MIT de Latino.NET. |
| `--version` | `-v` | Muestra la versión actual y créditos. |

- 💡 **Ejemplos de Uso**

```bash
# Ejecutar código rápido
latino -e "escribir(mate.raiz(144))"

# Pasar argumentos a un script
latino mi_script.lat arg1 arg2

# Dentro del script los recuperas con:
# args = sis.argumentos()
```

> 💡 **Consejo Multiplataforma (PowerShell y Bash):** Al ejecutar código con `-e`, envuelve siempre el argumento en comillas simples exteriores (`latino -e 'escribir("Hola")'`) para evitar que el shell elimine las comillas dobles internas.

### 💻 Manejo de Salida y Códigos de Error

Latino.NET se integra de forma nativa con shells de automatización (Bash, PowerShell, CMD) y flujos de integración continua (CI/CD, Docker, Makefiles) mediante códigos de salida estándar del sistema operativo:

| Situación | Código de Salida (`EXIT`) | Descripción |
| :--- | :---: | :--- |
| **Ejecución exitosa** | `0` | El script finalizó todas sus instrucciones sin errores. |
| **`sis.salir()`** (sin argumento) | `0` | Salida voluntaria indicando éxito predeterminado. |
| **`sis.salir(codigo)`** | `codigo` | Salida voluntaria con código personalizado (ej: `sis.salir(42)`). |
| **Error de sintaxis** | `1` | El código no pudo analizarse por errores gramaticales. |
| **Error de runtime no atrapado** | `1` | Excepción fatal (`lanzar()`, división por cero, etc.) no capturada. |
| **Archivo no encontrado** | `1` | El archivo `.lat` especificado no existe en el disco. |

#### 🔗 Encadenamiento en Terminal y Pipelines (CI/CD)

Al emitir códigos de retorno estandarizados, puedes controlar el flujo de tareas encadenadas utilizando los operadores lógicos del shell (`&&` y `||`):

```bash
# En Bash / Linux / macOS:
latino build.lat && echo "✅ Compilación exitosa" || echo "❌ Falló el build"

# Inspeccionar el código exacto en Linux/macOS:
latino script.lat; echo "Código: $?"

# Inspeccionar el código exacto en PowerShell:
latino script.lat; Write-Host "Código: $LASTEXITCODE"
```

#### 🎨 Diagnóstico Visual de Errores

En caso de fallo, la CLI muestra mensajes enriquecidos con emojis e información de línea para facilitar la depuración rápida:

```text
❌ Error de Sintaxis [Línea 5]: Se esperaba 'fin'
❌ Error Runtime [Línea 12]: División por cero.
```
