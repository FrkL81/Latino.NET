## 9.4 Librería `dic` (Diccionarios)

Los diccionarios son colecciones mutables de pares **Clave-Valor**. En Latino.NET, las claves pueden ser cualquier tipo de objeto, aunque lo más común son `cadenas` o `números`.

### 🔑 Operaciones Básicas

| Función | Parámetros | Descripción |
| :--- | :--- | :--- |
| `dic.agregar(d, k, v)` | `dic, clave, valor` | Agrega un nuevo par o actualiza el valor de una clave existente. |
| `dic.contiene(d, k)` | `dic, clave` | Verifica si la clave existe en el diccionario. |
| `dic.fusionar(d1, d2)` | `dic1, dic2` | Retorna un nuevo diccionario combinando ambos (sobrescribe d1 con d2). |
| `dic.llaves(d)` | `dic` | Retorna una `lista` con todas las claves. |
| `dic.longitud(d)` | `dic` | Retorna la cantidad de pares clave-valor. |
| `dic.obtener(d, k, [def])` | `dic, clave, defecto` | Retorna el valor de la clave. Si no existe, retorna el valor `defecto`. |
| `dic.valores(d)` | `dic` | Retorna una `lista` con todos los valores. |

- 📋 **Ejemplos: Pruebas de Humo (Básicas)**

```latino
persona = { "nombre": "Ana", "edad": 25 }

# Agregar/Actualizar
dic.agregar(persona, "pais", "Panama")
persona["profesion"] = "Ingeniera" # Sintaxis literal alternativa

# Obtener seguro
salario = dic.obtener(persona, "salario", 0) # → 0

# Iterar llaves
para k en dic.llaves(persona)
    escribir(k .. ": " .. persona[k])
fin
```

### 🎯 Programación Funcional (NUEVO)

A partir de la v1.0.81, los diccionarios soportan potentes métodos de transformación:

| Función | Parámetros | Descripción |
| :--- | :--- | :--- |
| `dic.filtrar(d, fn)` | `dic, fn(k, v)` | Retorna un nuevo dic. con los elementos que cumplan la condición. |
| `dic.invertir(d)` | `dic` | Intercambia llaves por valores (los valores deben ser únicos). |
| `dic.mapear(d, fn)` | `dic, fn(k, v)` | Transforma llaves y valores (el callback debe retornar `{ "llave": k2, "valor": v2 }`). |
| `dic.transformarLlaves(d, fn)` | `dic, fn(k)` | Retorna un nuevo dic. con las claves transformadas por la función. |
| `dic.transformarValores(d, fn)` | `dic, fn(v)` | Retorna un nuevo dic. con los valores transformados por la función. |

🎯 **Ejemplo: Transformaciones**

```latino
precios = { "manzana": 10, "pera": 20, "uva": 30 }

# 1. Aplicar descuento (Transformar Valores)
precios_oferta = dic.transformarValores(precios, funcion(v) retornar v * 0.9 fin)
# → { "manzana": 9, "pera": 18, "uva": 27 }

# 2. Solo productos caros (Filtrar)
caros = dic.filtrar(precios, funcion(k, v) retornar v > 15 fin)
# → { "pera": 20, "uva": 30 }

# 3. Formatear llaves (Transformar Llaves)
etiquetas = dic.transformarLlaves(precios, cadena.mayusculas)
# → { "MANZANA": 10, ... }

# 4. Inversión (Buscar por valor)
indices = { "A": 1, "B": 2, "C": 3 }
reverso = dic.invertir(indices)
# → { 1: "A", 2: "B", 3: "C" }
```

> **💡 Tip:** Usa `dic.mapear()` cuando necesites cambiar la estructura completa del diccionario en un solo paso. Recuerda que el callback debe devolver un diccionario con las llaves `"llave"` y `"valor"`.
