## 9.5 Librería `tupla` (Tuples)

Las tuplas son colecciones **inmutables** y heterogéneas. Son ideales para representar registros fijos (como coordenadas o resultados de funciones) que no deben cambiar durante la ejecución.

### 📌 Operaciones Básicas

| Función | Parámetros | Descripción |
| :--- | :--- | :--- |
| `tupla.crear(...)` | `items...` | Crea una tupla. También se pueden crear con paréntesis: `(1, 2, 3)`. |
| `tupla.longitud(t)` | `tupla` | Retorna el número de elementos. |
| `tupla.obtener(t, i)` | `tupla, i` | Accede al elemento en el índice indicado. |

🎯 **Ejemplos: Pruebas de Humo**

```latino
# Creación literal
punto = (10, 20, "Z")

# Acceso
x = tupla.obtener(punto, 0) # 10
y = punto[1] # También soporta acceso directo (solo lectura)

# Inmutabilidad
# punto[0] = 99 # ERROR: Las tuplas son inmutables
```

### 🎯 Caso de Uso: Retorno Múltiple de Funciones

Las tuplas son excelentes para retornar varios valores desde una función:

```latino
funcion ObtenerUsuario(id)
    # Simular base de datos
    retornar ("Juan Perez", "juan@test.com", 25)
fin

info = ObtenerUsuario(1)
escribir("Nombre: " .. info[0])
escribir("Email: " .. info[1])
```

> **💡 Tip:** A diferencia de las `listas`, las `tuplas` ocupan menos memoria y son seguras para usar como llaves en un `diccionario`.
