## 9.2 Librería `cadena` (Strings)

Manipulación experta de texto, análisis y expresiones regulares. Latino.NET utiliza codificación **UTF-8** por defecto.

### 📏 Información y Medición

| Función | Parámetros | Descripción |
| :--- | :--- | :--- |
| `cadena.contar(s, sub)` | `c, sub` | Cuenta cuántas veces aparece la subcadena. |
| `cadena.contarPalabras(s)` | `cadena` | Retorna el número de palabras en el texto. |
| `cadena.es_alfa(s)` | `cadena` | Verifica si contiene solo caracteres alfanuméricos. |
| `cadena.es_numero(s)` | `cadena` | Verifica si el texto representa un número (decimal o entero). |
| `cadena.esta_vacia(s)` | `cadena` | Retorna `verdadero` si es `""` o `nulo`. |
| `cadena.longitud(s)` | `cadena` | Retorna el número de grafemas visuales (Unicode). Los emojis y caracteres compuestos cuentan como 1. |

### 🔍 Búsqueda y Verificación

| Función | Parámetros | Descripción |
| :--- | :--- | :--- |
| `cadena.contiene(s, sub)` | `cadena, sub` | Verifica si la subcadena existe en el texto. |
| `cadena.indice(s, sub)` | `cadena, sub` | Posición de la primera aparición (-1 si no existe). |
| `cadena.inicia_con(s, pref)` | `cadena, pref` | Verifica si el texto comienza con el prefijo. |
| `cadena.termina_con(s, suf)` | `cadena, suf` | Verifica si el texto termina con el sufijo. |
| `cadena.ultimo_indice(s, sub)` | `cadena, sub` | Posición de la última aparición. |

| `cadena.partir(s, sep, lim)` | `c, sep, lim` | Divide el texto con un límite máximo de partes. |

| `cadena.subcadena(s, i, l)` | `c, ini, lon` | Extrae una porción del texto. |

### 🔧 Expresiones Regulares (Regex)

Latino.NET integra un motor Regex potente para validaciones complejas:

| Función | Parámetros | Descripción |
| :--- | :--- | :--- |
| `cadena.extraer(s, modo)` | `c, modo` | Extrae patrones predefinidos (`emails`, `urls`, `digitos`, etc.). |
| `cadena.reemplazarRegex(texto, patron, reemplazo_o_funcion, [limite])` | `texto, patrón, reemplazo_o_funcion, [limite]` | Reemplaza coincidencias de Regex en una cadena. |
| `cadena.regex(s, patron)` | `c, patrón` | Match de extracción: retorna `lista` de coincidencias. |
| `cadena.regexl(s, patron)` | `c, patrón` | Match lógico: retorna `verdadero` si hay coincidencia. |

### 🔎 Criptografía y Seguridad

Funciones para garantizar la integridad y codificación segura de datos.

| Función | Parámetros | Descripción |
| :--- | :--- | :--- |
| `cadena.codificarBase64(s)` | `texto` | Codifica una cadena a formato Base64. |
| `cadena.decodificarBase64(s)` | `base64` | Decodifica una cadena Base64 a texto plano. |
| `cadena.hash(s, [alg])` | `texto, [alg]` | Calcula el hash (MD5, SHA1, SHA256, SHA512). |

```latino
# Hash SHA256 (default)
seguro = cadena.hash("latino_2026")
escribir(seguro) # → 1909d7be533f0b39b6240041cb405a6e5c437f4bcc3a69ddf9dad7edfd0b4474

# Base64
b64 = cadena.codificarBase64("Hola")
escribir(b64) # → SG9sYQ==
```

```latino
# Validar email simple
email = "test@latino.org"
si cadena.regexl(email, "@.*\\.")
    escribir("Email válido")
fin

# Extraer números
texto = "Tengo 2 perros y 3 gatos"
numeros = cadena.regex(texto, "\\d+")
escribir(numeros) # → ["2", "3"]
```

### 🔍 Comparación Avanzada (`es_igual`)

`cadena.es_igual(s1, s2, [modo])` permite comparaciones inteligentes:

| Modo | Descripción |
| :--- | :--- |
| `"exacta"` | Por defecto. Sensible a mayúsculas y acentos. |
| `"ignora_caso"` | Ignora diferencias de MAY/min. |
| `"normalizada"` | Ignora acentos/tildes y MAY/min. |
| `"comodin"` | Soporta `*` (varios) y `?` (uno). |

```latino
# Comodines
si cadena.es_igual("archivo.lat", "*.lat", "comodin")
    escribir("Es un archivo Latino")
fin

# Normalización
si cadena.es_igual("José", "jose", "normalizada")
    escribir("Nombres coinciden")
fin
```

#### 🔍 Los límites reales del modo `"comodin"`

El modo `"comodin"` es un **glob propio de Latino.NET**, no un motor de Regex y no el `glob` de los sistemas de archivos. Sus límites exactos, verificados contra
`StringLib.CompararConComodines`:

**✅ Funciona** (comprobado ejecutando):

```latino
cadena.es_igual("archivo.txt", "*.txt", "comodin")          # cierto
cadena.es_igual("log_2026_01", "log_????_??", "comodin")     # cierto
cadena.es_igual("a1c", "a?c", "comodin")                    # cierto
```

**❌ NO es Regex — las clases de caracteres no funcionan:**

```latino
cadena.es_igual("abc", "[a-z][a-z][a-z]", "comodin")         # falso  ✗
```

Si necesitas clases de caracteres, anclas o grupos, usa `cadena.regexl()`, que sí es un motor Regex real. `comodin` solo reconoce `*` y `?`.

**❌ No hay forma de escapar un comodín.** No existe un carácter de escape, así que
**es imposible comparar contra un `*` o un `?` literal**:

```latino
cadena.es_igual("a*b", "a*b", "comodin")     # cierto — pero no prueba que el * sea literal
cadena.es_igual("axxb", "a*b", "comodin")    # cierto — mismo resultado: es ambiguo
```

Ambos casos devuelven `cierto`, así que el resultado no distingue "coincidencia exacta" de "el `*` hizo de comodín". Para un `*` literal, la única vía es usar el modo `"exacta"`.

**Nota sobre acentos:** `comodin_insensible` ignora mayúsculas pero **no** ignora tildes. Verificado: `cadena.es_igual("José", "jose", "comodin_insensible")` devuelve `falso`. Para ignorar acentos usa el modo `"normalizada"`, que sí devuelve `cierto` para ese caso.

> **¿Por qué importa?** `*.txt` devuelve `cierto` tanto para `a.txt` como para `archivo_2026_final_v2.txt`: el `*` absorbe **todo** lo que precede al punto, incluidas las palabras. Si necesitas verificar que un archivo termina en `.txt`, el comodín es suficiente; pero si necesitas **saber qué extensión tiene** o **comparar contra un `*` literal**, el comodín no sirve. Para eso usa el modo `"exacta"` con la extensión ya aislada.
