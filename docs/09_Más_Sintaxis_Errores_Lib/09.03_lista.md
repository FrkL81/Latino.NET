## 9.3 Librería `lista` (Arrays)

Las listas son colecciones ordenadas, mutables y heterogéneas de elementos. Se definen usando corchetes `[...]`.

### 📏 Información Básica

| Función | Parámetros | Descripción |
| :--- | :--- | :--- |
| `lista.aleatorio(l)` | `lista` | Retorna un elemento al azar de la lista. |
| `lista.contar(l, item)` | `lista, valor` | Cuenta cuántas veces aparece el elemento. |
| `lista.contiene(l, item)` | `lista, valor` | Verifica si el elemento existe en la lista. |
| `lista.longitud(l)` | `lista` | Retorna el número de elementos. |

### ➕ Modificación: Agregar y Eliminar

| Función | Parámetros | Descripción |
| :--- | :--- | :--- |
| `lista.agregar(l, item)` | `lista, valor` | Añade un elemento al final de la lista. |
| `lista.eliminar(l, item)` | `lista, valor` | Elimina la **primera** ocurrencia del valor. |
| `lista.eliminar_indice(l, i)` | `lista, pos` | Elimina el elemento en la posición indicada. |
| `lista.insertar(l, it, i)` | `lista, valor, pos` | Inserta un elemento en la posición especificada. Si el índice está fuera de rango, se ajusta al inicio o al final. |

### 🔄 Transformación

| Función | Parámetros | Descripción |
| :--- | :--- | :--- |
| `lista.aplanar(l)` | `lista` | Aplana listas anidadas recursivamente. |
| `lista.invertir(l)` | `lista` | Invierte el orden de los elementos in-place. |
| `lista.ordenar(l, [fn])` | `lista, [fn]` | Ordena los elementos. Puede recibir una función comparadora. |
| `lista.unicos(l)` | `lista` | Retorna una nueva lista sin duplicados. |
| `lista.zip(l1, l2, ...)` | `listas` | Combina múltiples listas en tuplas. Longitud = lista más corta. |

🎯 **Ejemplo: Ordenar**

```latino
numeros = [5, 2, 8, 1]
lista.ordenar(numeros) # → [1, 2, 5, 8]

# Orden personalizado (descendente)
lista.ordenar(numeros, funcion(a, b) retornar a > b fin) # → [8, 5, 2, 1]
```

### ✂️ Slicing y Selección

| Función | Parámetros | Descripción |
| :--- | :--- | :--- |
| `lista.saltar(l, n)` | `lista, n` | Omite los primeros N elementos. |
| `lista.tomar(l, n)` | `lista, n` | Retorna los primeros N elementos. |

### 📊 Agregación y Estadística

| Función | Parámetros | Descripción |
| :--- | :--- | :--- |
| `lista.promedio(l)` | `lista` | Calcula el promedio de los elementos. |
| `lista.sumar(l)` | `lista` | Suma todos los elementos numéricos. |

### 🎯 Programación Funcional

Latino.NET promueve el uso de funciones de orden superior para procesar listas:

| Función | Parámetros | Descripción |
| :--- | :--- | :--- |
| `lista.alguno(l, fn)` | `lista, función` | Retorna `verdadero` si alguno cumple la condición. |
| `lista.filtrar(l, fn)` | `lista, función` | (Filter) Crea una nueva lista con los elementos que devuelvan `verdadero`. |
| `lista.particionar(l, fn)` | `lista, función` | Divide la lista en dos grupos (cumplen y no cumplen). |
| `lista.reducir(l, fn, [ac])` | `l, fn, init` | (Reduce) Acumula los elementos en un solo valor. |
| `lista.todos(l, fn)` | `lista, función` | Retorna `verdadero` si todos cumplen la condición. |
| `lista.transformar(l, fn)` | `lista, función` | (Map) Crea una nueva lista aplicando la función a cada elemento. |

🎯 **Ejemplo: Pipeline Funcional**

```latino
numeros = [1, 2, 3, 4, 5, 6]

# 1. Solo pares
pares = lista.filtrar(numeros, funcion(x) retornar x % 2 == 0 fin) # [2, 4, 6]

# 2. Elevar al cuadrado
cuadrados = lista.transformar(pares, funcion(x) retornar x * x fin) # [4, 16, 36]

# 3. Sumar todo
total = lista.reducir(cuadrados, funcion(acc, x) retornar acc + x fin, 0) # 56
```

### 🧮 Operaciones Matriciales (NUEVO)

A partir de la versión 1.0.8x, la librería `lista` incluye soporte nativo para crear y manipular matrices bidimensionales (listas de listas), optimizadas para trabajar en conjunto con el plugin `formulas`.

| Función | Parámetros | Descripción |
| :--- | :--- | :--- |
| `lista.dimensiones(m)` | `matriz` | Retorna una `tupla` `(filas, columnas)`. Verifica rectangularidad. |
| `lista.diagonal(m)` | `matriz` | Extrae la diagonal principal como un vector 1D. |
| `lista.columna(m, j)` | `matriz, col` | Extrae todos los elementos de la columna `j`. |
| `lista.identidad(n)` | `entero` | Crea la matriz identidad (1s en diagonal, 0s en el resto) de tamaño `n×n`. |
| `lista.llenar(f, c, v)` | `fil, col, val` | Crea una matriz de `f×c` rellenada con el valor `v`. |
| `lista.submatriz(m, f1, f2, c1, c2)` | `m, fI, fF, cI, cF` | Extrae un bloque rectangular de la matriz (índices inclusivos). |

🎯 **Ejemplo: Construcción y Extracción**

```latino
# Crear matriz de 3x3 llena de ceros
ceros = lista.llenar(3, 3, 0)

# Crear matriz identidad de 4x4
I = lista.identidad(4)
dim = lista.dimensiones(I)
escribir("Filas: " .. dim[0] .. ", Columnas: " .. dim[1])

# Extraer datos de una matriz existente
matriz = [[1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]

col_central = lista.columna(matriz, 1) # →[2, 5, 8]
diagonal    = lista.diagonal(matriz)   # → [1, 5, 9]
```

> **💡 Tip:** `lista.transformar()` y `lista.filtrar()` NO modifican la lista original, retornan una nueva. `lista.agregar()` y `lista.eliminar()` SÍ modifican la lista original.
