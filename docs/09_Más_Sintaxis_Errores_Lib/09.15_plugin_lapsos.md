# Capítulo: 09_Más_Sintaxis_Errores_Lib

## 9.15 Plugin lapsos (Fecha/Hora Avanzada)

`lapsos` es el plugin oficial para la gestión robusta de fechas, tiempos y duraciones. Proporciona precisión de 100 nanosegundos y manejo automático de zonas horarias.

**Requiere carga explícita:** `incluir("lapsos")`

### 📅 Creación y Obtención

| Función | Parámetros | Descripción |
| :--- | :--- | :--- |
| `lapsos.ahora()` | - | Retorna un objeto `fecha` con el momento actual exacto. |
| `lapsos.analizar(texto)` | `texto` | Intenta convertir texto a fecha usando formatos comunes. |
| `lapsos.convertir(valor)` | `texto/num/obj` | Convierte cadenas ISO, timestamps Unix o Ticks en objeto fecha. |
| `lapsos.fecha(a,m,d,[h,min,s])` | `y, m, d...` | Crea una fecha específica. |
| `lapsos.hoy()` | - | Retorna la fecha actual con la hora en ceros (00:00:00). |

### 🔄 Formateo y Conversiones

| Función | Parámetros | Descripción |
| :--- | :--- | :--- |
| `lapsos.formato(fecha, fmt)` | `fecha, fmt` | Convierte la fecha a texto usando patrones como `yyyy-MM-dd`. |
| `lapsos.ticks(fecha)` | `fecha` | Retorna el valor en Ticks (100ns desde el año 0001). |
| `lapsos.unix(fecha)` | `fecha` | Retorna el timestamp Unix (segundos desde 1970). |

#### Patrones de Formato Comunes

- `yyyy-MM-dd`: 2026-02-11
- `dd/MM/yyyy HH:mm`: 11/02/2026 19:54
- `dddd, MMMM dd`: Miércoles, febrero 11
- `hh:mm tt`: 07:54 PM

### ➕➖ Aritmética Temporal

| Función | Parámetros | Descripción |
| :--- | :--- | :--- |
| `lapsos.comparar(f1, f2)` | `f1, f2` | Retorna `-1` (f1 anterior), `0` (igual), `1` (f1 posterior). |
| `lapsos.diferencia(f1, f2)` | `ini, fin` | Retorna un `diccionario` con el desglose de la duración. |
| `lapsos.restar(f, cant, uni)` | `f, n, unidad` | Resta tiempo a la fecha proporcionada. |
| `lapsos.sumar(f, cant, uni)` | `f, n, unidad` | Suma `dias`, `meses`, `años`, `horas`, `minutos`. |

#### Estructura del Diccionario `diferencia`

La función retorna un mapa con llaves como:

- `dias`, `horas`, `minutos`, `segundos` (Fragmentos individuales).
- `total_dias`, `total_horas`, `total_minutos` (Acumulados decimales).
- `signo`: `-1` si la fecha 1 es mayor a la 2.

### 🔍 Validación y Calendario

| Función | Parámetros | Descripción |
| :--- | :--- | :--- |
| `lapsos.diasEnMes(f)` | `fecha` | Retorna 28, 29, 30 o 31 según el mes/año. |
| `lapsos.esBisiesto(f)` | `fecha` | Verifica si el año de la fecha es bisiesto. |
| `lapsos.esFuturo(f)` | `fecha` | Verifica si es posterior al momento actual. |
| `lapsos.esPasado(f)` | `fecha` | Verifica si es anterior al momento actual. |
| `lapsos.esValido(txt, [fmt])` | `txt, fmt` | Verifica si el texto es una fecha sin lanzar error. |
| `lapsos.zonaHoraria()` | - | Retorna el nombre y el desfase UTC de la zona local. |

🎯 **Ejemplo: Recordatorio con Alerta**

```latino
incluir("lapsos")

vencimiento = lapsos.fecha(2026, 12, 31)
hoy = lapsos.ahora()

si lapsos.comparar(hoy, vencimiento) > 0
    escribir("🚨 Tu suscripción ha vencido")
sino
    dif = lapsos.diferencia(hoy, vencimiento)
    escribir("Te quedan " .. mate.piso(dif.total_dias) .. " días de servicio")
fin
```

🎯 **Ejemplos: 📋 Pruebas de Humo Rápidas**

```latino
incluir("lapsos")

# Creación y obtención
f1 = lapsos.ahora()
f2 = lapsos.hoy()
f3 = lapsos.fecha(2026, 6, 15)
f4 = lapsos.analizar("2026-06-15")
f5 = lapsos.convertir(1700000000)  # Unix → fecha

# Formateo y conversiones
lapsos.formato(f1, "yyyy-MM-dd")
lapsos.unix(f1)
lapsos.ticks(f1)

# Aritmética temporal
lapsos.sumar(f1, 30, "dias")
lapsos.restar(f1, 1, "meses")
dif = lapsos.diferencia(f1, f2)
lapsos.comparar(f1, f2)

# Validación y calendario
lapsos.esValido("2026-06-15")
lapsos.esFuturo(f1)
lapsos.esPasado(f1)
lapsos.esBisiesto(f1)
lapsos.diasEnMes(f1)
lapsos.zonaHoraria()
```
