## 9.1 Funciones Globales

Las funciones globales están integradas directamente en el lenguaje y no requieren ningún prefijo de librería.

### 📤 Salida de Datos

| Función | Parámetros | Descripción |
| :--- | :--- | :--- |
| `escribir(...)` | `valores` | Imprime uno o más valores seguidos de un salto de línea. |
| `imprimir(...)` | `valores` | Alias de `escribir`. |
| `poner(...)` | `valores` | Alias de `escribir`. |
| `escribirf(fmt, ...)` | `fmt, vars` | Formateo estilo .NET (ej: `{0:F2}`). |
| `imprimirf(fmt, ...)` | `fmt, vars` | Formateo estilo C (ej: `%.2f`). |

### 📥 Entrada de Datos

| Función | Parámetros | Descripción |
| :--- | :--- | :--- |
| `leer([prompt])` | `mensaje` | Detiene la ejecución para leer una línea del teclado. |
| `pedir([prompt])` | `mensaje` | Alias de `leer`. |

```latino
# Entrada simulada: Ana
nombre = leer("¿Cómo te llamas? ")
escribir("Hola " .. nombre)
```

### 🔄 Conversión de Tipos

| Función | Parámetros | Descripción |
| :--- | :--- | :--- |
| `tipo(obj)` | `objeto` | Retorna el nombre del tipo del objeto (cadena, decimal, lista...). |
| `acadena(obj)` | `objeto` | Convierte cualquier objeto a su representación en texto. |
| `anumero(obj)` | `objeto` | Intenta convertir a número. Retorna `nulo` si falla. |
| `alogico(obj)` | `objeto` | Convierte a valor lógico (basado en existencia/nulidad). |

### 🔗 Compositor de Cadenas (`ç`)

El compositor `ç` permite inyectar variables directamente en una cadena usando tuberías `|...|`.

```latino
x = 10
escribir(ç("El valor de x es |x|"))
```

> **Limitación:** Solo admite nombres de variables, propiedades de objetos (`p.nombre`) o índices de listas (`lista[0]`). No admite operaciones matemáticas ni llamadas a funciones.

### 🔢 Otras Utilidades

| Función | Parámetros | Descripción |
| :--- | :--- | :--- |
| `evaluar(codigo)` | `cadena` | Ejecuta código Latino dinámicamente y retorna el resultado. |
| `incluir(ruta)` | `cadena` | Carga un script `.lat` o un plugin `.dll`. |
| `limpiar([modo])` | `cadena` | Limpia la consola. Modos: `"pantalla"`, `"todo"`, `"cursor"`. |
| `rango([ini], fin, [paso])` | `num` | Crea una `lista` de números o descompone una `cadena`. |

#### Uso de `rango()`

```latino
para i en rango(5) # 0, 1, 2, 3, 4
    escribir(i)
fin

caracteres = rango("Hola") # ["H", "o", "l", "a"]
```

#### trocar(coleccion, a, b)

Intercambia (*swaps*) los valores ubicados en las posiciones `a` y `b` de una estructura de datos mutable (como una `lista` o un `diccionario`). Modifica la colección original directamente en memoria (operación rápida O(1)) y retorna la colección resultante.

**Parámetros:**

* `coleccion`: La lista o diccionario a modificar.
* `a`, `b`: Los índices numéricos (para listas) o las claves (para diccionarios) cuyos valores se van a intercambiar. Admite índices negativos en listas.

> ℹ️ **Los índices decimales se truncan, no se redondean ni fallan.** Como todo número es `decimal` internamente, `trocar(lista, 1.8, 3.2)` intercambia las posiciones `1` y `3`: el motor descarta la parte fraccionaria. Verificado ejecutando en v1.0.81.

**Ejemplos:**

```latino
# Intercambio en listas (Bubble sort seguro)
mi_lista = [10, 20, 30]
trocar(mi_lista, 0, 2)
escribir(mi_lista) # Salida: [30, 20, 10]

# Intercambio usando índices negativos
trocar(mi_lista, 0, -1) # Intercambia el primero con el último

# Intercambio en diccionarios
mi_dic = {"juan": 100, "maria": 500}
trocar(mi_dic, "juan", "maria")
escribir(mi_dic) # Salida: {"juan": 500, "maria": 100}
```

> **Versión:** Latino.NET v1.0.81 | Última actualización: 2026-09-16
