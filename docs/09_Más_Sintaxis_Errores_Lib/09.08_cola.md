## 9.8 Librería `cola` (Queue)

La librería `cola` implementa la estructura de datos **FIFO** (First-In-First-Out), donde el primer elemento en entrar es el primero en ser procesado. Es ideal para sistemas de turnos, gestión de tareas y buffers.

### 📤 Operaciones Básicas

| Función | Parámetros | Descripción |
| :--- | :--- | :--- |
| `cola.alista(c)` | `cola` | Convierte la cola en una `lista` tradicional (Inicio → Fin). |
| `cola.crear()` | - | Crea una cola nueva y vacía. |
| `cola.desencolar(c)` | `cola` | Extrae y retorna el elemento al inicio de la cola. |
| `cola.encolar(c, item)` | `cola, valor` | Agrega un elemento al final de la cola. |
| `cola.limpiar(c)` | `cola` | Elimina todos los elementos de la cola. |
| `cola.longitud(c)` | `cola` | Retorna el número de elementos en la cola. |
| `cola.siguiente(c)` | `cola` | Retorna el primer elemento sin extraerlo (Peek). |
| `cola.vacia(c)` | `cola` | Retorna `verdadero` si la cola no tiene elementos. |

🎯 **Ejemplos: Pruebas de Humo (Operaciones Básicas)**

```latino
tickets = cola.crear()

# Encolar clientes
cola.encolar(tickets, "Ana")
cola.encolar(tickets, "Beto")
cola.encolar(tickets, "Carla")

escribir("Total en espera: " .. cola.longitud(tickets)) # → 3
escribir("Primero en fila: " .. cola.siguiente(tickets)) # → Ana

# Atender (desencolar)
atendido = cola.desencolar(tickets)
escribir("Atendido: " .. atendido) # → Ana
escribir("Quedan: " .. cola.longitud(tickets)) # → 2
```

🎯 **Ejemplo: Sistema de Procesamiento de Mensajes**

```latino
funcion ProcesarCola()
    mensajes = cola.crear()
    
    # Simular llegada de mensajes
    cola.encolar(mensajes, { "tipo": "email", "u": "admin@test.com" })
    cola.encolar(mensajes, { "tipo": "sms", "u": "+5071234567" })
    
    mientras !cola.vacia(mensajes)
        msg = cola.desencolar(mensajes)
        escribir("Enviando " .. msg.tipo .. " a " .. msg.u)
    fin
    
    escribir("✅ Procesamiento completado")
fin

ProcesarCola()
```

🎯 **Ejemplo: Spooler de impresión con inspección previa (Peek)**

```latino
impresora = cola.crear()

cola.encolar(impresora, "Factura_001.pdf")
cola.encolar(impresora, "Contrato_Laboral.docx")
cola.encolar(impresora, "Plano_Arquitectura.dwg")

# Inspeccionamos qué documento está en turno sin sacarlo de la cola
proximo = cola.siguiente(impresora)
escribir("📄 En espera de impresión: " .. proximo)
escribir("Documentos pendientes en cola: " .. cola.longitud(impresora))

# Procesamos todos los documentos en estricto orden de llegada
mientras no cola.vacia(impresora)
    doc = cola.desencolar(impresora)
    escribir("🖨 Imprimiendo documento: " .. doc .. " ... [OK]")
fin
```

🎯 **Ejemplo: Distribución de turnos entre ventanillas de banco**

```latino
fila_clientes = cola.crear()

cola.encolar(fila_clientes, "Ticket-01 (Depósito)")
cola.encolar(fila_clientes, "Ticket-02 (Apertura)")
cola.encolar(fila_clientes, "Ticket-03 (Consulta)")
cola.encolar(fila_clientes, "Ticket-04 (Retiro)")

ventanillas = ["Caja 1", "Caja 2"]
turno_caja = 0

mientras no cola.vacia(fila_clientes)
    cliente = cola.desencolar(fila_clientes)
    caja_actual = ventanillas[turno_caja % lista.longitud(ventanillas)]
    
    escribirf("{0} llama a: {1}\n", caja_actual, cliente)
    turno_caja++
fin

escribir("✅ Todos los clientes de la fila fueron atendidos.")
```

> **💡 Diferencia con Pila:** Mientras que una `cola` es FIFO (Ana entra primero, Ana sale primero), una `pila` es LIFO (Ana entra primero, pero si Beto entra después, Beto sale primero).
