# Capítulo: 09_Más_Sintaxis_Errores_Lib

## 9.14 Librería `web` (Cliente HTTP)

La librería `web` dota a Latino.NET de capacidades nativas para realizar peticiones HTTP, permitiendo consumir APIs REST, descargar archivos y enviar datos a servidores.

### 📡 Peticiones Rápidas

| Función | Parámetros | Descripción |
| :--- | :--- | :--- |
| `web.enviar(url, [data], [headers])` | `url, data, [dic]` | Realiza una petición **POST** simple (JSON por defecto). |
| `web.obtener(url, [headers])` | `url, [dic]` | Realiza una petición **GET** simple. |

### ⚙️ Petición Avanzada

| Función | Parámetros | Descripción |
| :--- | :--- | :--- |
| `web.solicitar(config)` | `diccionario` | Realiza una petición personalizada (GET, POST, PUT, DELETE, etc.). |

#### Diccionario de Configuración (`solicitar`)

| Clave | Requerido | Descripción |
| :--- | :--- | :--- |
| `"datos"` | No | Cuerpo de la petición (se serializa a JSON si es un objeto). |
| `"encabezados"` | No | Diccionario de cabeceras HTTP (ej: `{"Authorization": "Bearer ..."}`). |
| `"metodo"` | No | `"GET"`, `"POST"`, `"PUT"`, `"PATCH"`, `"DELETE"`. |
| `"timeout"` | No | Segundos de espera (default: 30). |
| `"url"` | Sí | Dirección de destino. |

### 📥 Descargas y Utilidades

| Función | Parámetros | Descripción |
| :--- | :--- | :--- |
| `web.codificarUrl(texto)` | `cadena` | Codifica texto para URL (URL Encoding). |
| `web.decodificarUrl(texto)` | `cadena` | Decodifica texto URL-encoded. |
| `web.descargar(url, destino)` | `url, path` | Descarga un archivo binario al disco. |

### 📄 Estructura de Respuesta

Todas las funciones de petición retornan un diccionario con:

| Llave | Tipo | Descripción |
| :--- | :--- | :--- |
| `"encabezados"` | Dic | Cabeceras de respuesta del servidor. |
| `"estado"` | Entero | Código HTTP (200, 404, 500, etc.). |
| `"json"` | Var | Contenido parseado automáticamente (si es JSON). |
| `"ok"` | Lógico | `verdadero` si el estado es 2xx. |
| `"texto"` | Cadena | Contenido bruto de la respuesta. |
| `"url"` | Cadena | URL final de la petición. |

🎯 **Ejemplo: Consumo de API JSON**

```latino
# Requiere conexión a internet activa
respuesta = web.obtener("https://jsonplaceholder.typicode.com/posts/1")

si respuesta.ok
    post = respuesta.json
    escribir("Título: " .. post.title)
sino
    escribir("Error: " .. respuesta.estado)
fin
```

🎯 **Ejemplo: Envío de Formulario**

```latino
# Requiere conexión a internet activa
# Usa un endpoint público de pruebas (jsonplaceholder) que acepta POST
# y responde 201. Sustitúyelo por tu API real: una URL ficticia fallaría.
datos = { "nombre": "LatinoBot", "mensaje": "Hola Mundo" }

intentar
    res = web.enviar("https://jsonplaceholder.typicode.com/posts", datos)

    si res.ok
        escribir("✅ Mensaje creado. Código: " .. res.estado)
    sino
        escribir("El servidor respondió con estado: " .. res.estado)
    fin
atrapar (error)
    escribir("Error de conexión (¿red o DNS?): " .. error)
fin
```
