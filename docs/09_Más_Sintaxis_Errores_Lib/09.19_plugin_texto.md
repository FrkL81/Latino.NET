## 9.19 Plugin texto (Manipulación Dinámica)

Las cadenas de texto en Latino.NET (`cadena`) son **inmutables**. Si necesitas construir archivos de texto gigantes (HTML, CSV, JSON) concatenando miles de líneas, usar el operador `..` consumirá mucha memoria RAM.

El plugin `texto` es un *wrapper* nativo de `StringBuilder` que permite manipular y construir textos masivos de forma dinámica, veloz y segura para múltiples hilos.

> **Requiere carga explícita:** `incluir("texto")`

### 🏗️ Operaciones de Buffer

| Función | Parámetros | Descripción |
| :--- | :--- | :--- |
| `texto.anexar(id, ...)` | `id, vals...` | Añade múltiples valores al final del buffer. |
| `texto.anexarLinea(id, ...)` | `id, [vals]` | Añade valores seguidos de un salto de línea. |
| `texto.crear([capacidad])` | `[bytes]` | Crea un buffer y retorna su ID. Opcionalmente reserva memoria. |
| `texto.eliminar(id)` | `id` | Destruye el buffer y libera la memoria RAM. |
| `texto.limpiar(id)` | `id` | Vacía el buffer para reutilizarlo sin destruirlo. |
| `texto.longitud(id)` | `id` | Retorna el número de caracteres en el buffer O(1). |
| `texto.obtener(id)` | `id` | Materializa y retorna todo el contenido como una `cadena`. |
| `texto.reemplazar(id, v, n)` | `id, viejo, nuevo` | Reemplaza texto DENTRO del buffer (altamente eficiente). |

### 🌊 Sintaxis Fluida (Pipeline)

Todas las funciones de modificación (`anexar`, `anexarLinea`, `reemplazar`, `limpiar`) retornan el ID del buffer. Esto permite aprovechar el operador Pipeline (`|>`) para lograr un código extremadamente limpio y fluido.

🎯 **Ejemplo: Constructor HTML Fluido**

```latino
incluir("texto")

# Pre-reserva memoria para mejor rendimiento
html = texto.crear(1024)

html |> texto.anexarLinea("<html>")
     |> texto.anexarLinea("  <body>")
     |> texto.anexarLinea("    <h1>Reporte de Ventas</h1>")
     |> texto.anexarLinea("    <p>Usuario: {{NOMBRE}}</p>")
     |> texto.anexarLinea("  </body>")
     |> texto.anexarLinea("</html>")
     |> texto.reemplazar("{{NOMBRE}}", "Frank")

# Obtener el resultado final y persistir
codigo_final = texto.obtener(html)
archivo.escribir("reporte.html", codigo_final)

# Higiene de recursos
texto.eliminar(html)
archivo.borrar("reporte.html")
```

🎯 **Ejemplos: 📋 Pruebas de Humo Rápidas**

```latino
incluir("texto")

# Crear y manipular buffer
id = texto.crear()
texto.anexar(id, "Hola ")
texto.anexarLinea(id, "Mundo")
texto.reemplazar(id, "Mundo", "Latino")
texto.longitud(id)
texto.obtener(id)  # ← Materializa el buffer como cadena
texto.limpiar(id)
texto.eliminar(id)
```

> **Nota:** La función para obtener el contenido es `texto.obtener(id)`, no `texto.texto(id)`.
